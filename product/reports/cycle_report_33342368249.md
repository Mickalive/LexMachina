## Bugs Fixed

### 1. Compound Language URL Separator (FIX-011a)
- **Issue:** `+` in URL query strings gets URL-decoded as space by `parse_qs`, so `language=de+fr` becomes `language="de fr"` which fails to parse as compound language
- **Fix:** Changed separator from `+` to `,` in `search_decisions()` and `parse_qs`-safe processing (also handles `+` and space as separators)
- **Impact:** `GET /api/search?q=recht&language=de,fr` now correctly returns German and French results

### 2. _handle_cached HTTP Header Sequence (FIX-011b)
- **Issue:** `_handle_cached()` called `self.send_header("X-Cache", "MISS")` before `self._json_response()`, but `_json_response` calls `self.send_response(200)` which starts a new HTTP response — headers sent before `send_response` are ignored
- **Fix:** Refactored to inline the full response sequence: `send_response` → `send_header` (Content-Type, Access-Control-Allow-Origin, X-Cache) → `end_headers` → `wfile.write`
- **Impact:** `/api/corpus/stats/languages` and all cached endpoints now return data correctly with X-Cache header
