## New Features

### 1. Zoom Coherence Integration
- **Module**: `product/app/zoom_coherence_loader.py`
- **API endpoints**:
  - `GET /api/zoom_coherence` - Overall zoom coherence summary
  - `GET /api/zoom_coherence/flat_baseline` - Flat baseline metrics at different resolutions
- **Data**: Loaded from fractal-map lane's zoom coherence experiment results

### 2. Language Dominance Analysis
- **Module**: `product/app/language_analyzer.py`
- **API endpoints**:
  - `GET /api/cluster_language_analysis?representation=&zoom=&cluster_id=` - Language dominance for a cluster
  - `GET /api/cross_language_neighbors?id=&n=` - Cross-language neighbors for a decision
- **Features**:
  - Detects language-dominant clusters (>90% single language)
  - Finds spatially close decisions in different languages
  - Provides language filter recommendations

### 3. TF-IDF Proximity
- **Module**: `product/app/tfidf_proximity.py`
- **API endpoints**:
  - `GET /api/text_similarity?id_a=&id_b=` - Text-based similarity between decisions
- **Features**:
  - Builds TF-IDF model from corpus (22,852 terms)
  - Computes cosine similarity between decisions
  - Returns top shared terms ranked by importance
