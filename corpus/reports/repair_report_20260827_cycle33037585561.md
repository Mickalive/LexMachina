## Fix 1: Citation Graph Metrics

### Audit Finding
- **State claimed:** `citation_graph_edges: 2105`, `citation_graph_nodes_cited: 1628`
- **Actual artifact:** `citation_graph.json` exists with `outgoing` text-reference structure (2,105 refs, 1,628 unique targets) but **no pipeline code builds it** — not from resolved `decision_id` edges, not from `outgoing_citations`/`incoming_citations`, and no test verifies construction.

### Fix Applied
```json
"citation_graph_edges": 0,
"citation_graph_nodes_cited": 0,
"citation_graph_note": "citation_graph.json exists with 'outgoing' text-reference structure (2105 refs, 1628 unique targets) but is not pipeline-built; no code constructs resolved decision_id citation graph"
```

### Rationale
The `cited_decisions` field in canonical decisions contains text references (e.g., "BGE 140 III 86") not resolved to `decision_id` edges. The existing file appears to be a static export of these text references. Without pipeline code to build and maintain a resolved citation graph, claiming 2,105 edges / 1,628 nodes misrepresents the system's capabilities. The note preserves transparency about what exists.
