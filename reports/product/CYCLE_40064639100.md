## Vertical Slice Delivered

### 1. Server & API (product/server.py, product/query_app.py)
- Threaded HTTP server boots in **query mode** without loading the 174k corpus (<3s startup)
- Progressive job API: `/api/query/start` → map_ready bundle → background expansion → `/api/query/enrich` → answer + counter-authorities
- Response cache with retrieval-mode-aware keys (fixture never served for live)
- Static assets served with correct content types

### 2. Retrieval (frontier-query-retrieval/ocl_adapter)
- OpenCaseLaw public REST API via accepted adapter v2 (charter v2)
- Multi-stage: search (lexicon-expanded) → lang (DE/FR/IT server-side) → leading-cases → citations
- Deterministic fixture replay from canonical cache (zero network)
- Identity merge on court+docket prevents duplicate decisions on map

### 3. Query-Conditioned Map (product/query/qmap.py)
- TF-IDF + TruncatedSVD + KMeans clustering over retrieved decisions
- Deterministic coordinates in [-1, 1] × [-1, 1]
- MapModel enables progressive expansion without moving rendered points
- 8 clusters with reproducible labels (TF-IDF term means, 9-decimal rounding)
- Outlier detection (top 10% by distance to cluster centroid)

### 4. Sourced Generative Answer (frontier-generative-audit)
- Contract v2.2: `run_generative_audit(bundle)` → audited bundle with answer + counter statuses
- Free model probing (opencode/mimo-v2.6-flash-free, space-bunny-free, longcat-2.5-preview-free)
- Extractive fallback on writer abort (e_EMISSION_WRITER_ABORT disclosure)
- Answer coverage contract fills omitted conditions from verbatim decision text
- Zero-citation contract surfaces uncovered concepts honestly

### 5. Independent Counter-Authority Pass
- **Adversarial retrieval** (product/query/adversarial_retrieval.py): answer-conditioned probes for contrary/limiting/exception/minority/older-line/language-branch
- Appends unseen rows, freezes rendered geometry byte-for-byte
- **Counter-surface scan** (direction v63 item 7a): pool-wide heuristic surface over rendered decisions, mode-aware hydration budget (8 live / 24 cached), invariants hold
- **Counter-evidence span selection** (direction v65): verbatim span selection for frozen confirm-or-abstain gate, 6/20 rows emitted with verified quotes
- **Anchor classifier** (frontier-counter-anchor-classifier Outcome A): confirm-or-abstain on adversarial findings under frozen rubric

### 6. Interactive UI (product/static/query.html)
- Single page: search input → sourced answer panel → interactive Canvas map
- Cluster labels, counter-authority toggle, adversarial discovery panel
- Decision detail panel with relations, citations, counter-evidence, provenance
- Relation-channel disclosure (measured, not inferred)
- Owner-gate 4-question card (Master Prompt questions 1-4)
- LexGateSwitch harness for map vs ranked-list comparison (same bundle, no re-retrieval)
