# Report of Record: Cycle 39986094168

Factory direction **v65**, product lane. This cycle implements the first remedy
named by the frozen counter-evidence-span charter itself: an
**extract-verify-abstain** span step between the accepted adversarial pass and
the accepted frozen confirm-or-abstain gate. It is a product-owned seam, not a
re-freeze: the frozen `decide_label` gate still decides, and a span is selected
only when that gate confirms it.

## 1. What changed (runnable delta)

- `product/query/counter_evidence_span.py` (new): deterministic, network-free
  span selection over the row's own named text fields (`full_text`, `regeste`,
  `snippet`, `title`). It preserves raw offsets, re-joins sentences torn after
  legal abbreviations (`Art.`, `Abs.`, `Ziff.` …), and returns only byte-exact
  slices (`text[start:end] == quote`).
- `product/query/pipeline.py`: the seam runs **before**
  `apply_counter_emission_repair` and **before** `apply_anchor_labels`, exactly
  where the accepted label path already runs. Kill-switch:
  `LEXMACHINA_COUNTER_SPAN=off`.
- `product/query/counter_anchor.py`: `counter_evidence_verified=True` is now
  written only when the span record itself is verified; an abstention clears
  the flag. A proposed quote the frozen gate rejects can no longer claim
  verbatim support, and an emission with no verified span metadata is not
  upgraded. This can only remove unverified claims; it never adds one.
- `product/measure_counter_span_selection.py` (new): reproducible measurement
  over packet-of-record v3.
- `product/tests/test_counter_evidence_span.py` (new, 12 tests).

No frozen rubric, bar, threshold, geometry, rank, cluster or relation was
touched. The packet bundles are read-only inputs.
