## 3. Instrument defect found and repaired

`product/audit_readiness.py::check_audit_namespace` checks that the producer
minted no auditor-namespace path. It built the gate/report names from the
`--run-id` argument. When the dossier was regenerated **for the accepted run**
(`--run-id 40284658455`, profile `40283048553`), it found the *auditor-owned*
accepted gate `results/audit/product/CYCLE_40284658455_GATE.json` already
committed in the base and reported a producer mint. That is the sole reason the
41184474509 snapshot committed `overall_status=FAIL`.

The repaired rule:

- the **accepted pointer's** gate/report is auditor-owned evidence in the base
  and is never counted as a producer mint;
- every **non-accepted** checked run id (the dossier run id and the resumed run
  id) still fails closed if a gate/report exists for it;
- every **pending** path under `results/audit/product/` or
  `reports/audit/product/` still fails closed.

New helper `audit_namespace_ids(run_id, resumed_run_id, accepted_run_id)` is a
pure function and is pinned by the cycle test. No gate logic, threshold, frozen
predicate or verdict contract is touched.

A second reader defect surfaced while generating this dossier. The
`observed_step_failure` branch of `check_resumed_diagnosis` required the
hand-enriched alias `mechanism.status = OBSERVED_LANE_CYCLE_STEP_FAILED` and
top-level `failed_step` / `audit.skipped` fields. The committed raw instrument
`product/audit_step_diagnosis.py` deliberately emits `UNOBSERVED` for a 403
log endpoint (a frozen contract), and `resume_snapshot_diagnosis.py` passes that
block through unchanged, so a reproducible dossier failed on field shape even
though every fact it needed was present. The check now reads the step fact from
the canonical `team.failed_step` block and derives `audit.skipped` from
`audit.conclusion` when the enriched alias is absent. It still requires
`logs_available=false`, HTTP 403, `quantum_expired=false`, the pinned exit
code, and the raw snapshot cross-check, so the fail-closed bar is unchanged.
