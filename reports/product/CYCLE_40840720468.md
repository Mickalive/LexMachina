## 2. The regression and the repair

`e2a5b599` added a content-level supplement to `frozen_content_defects`:

```python
_LEADHEAD_INDICATORS = frozenset({
    "kantonsgericht", "gericht", "tribunal", "court", "bge", "tf", ...
})
...
if any(tok in ev.lower() for tok in _LEADHEAD_INDICATORS) and field == "full_text":
    defects.append("D2_letterhead_zone")
```

Two independent defects followed:

1. **Duplicate defect class.** For a quote grounded in `full_text` below the
   frozen 400-character letterhead offset, the frozen offset predicate and the
   token supplement both appended `D2_letterhead_zone`. The v68 contract test
   asserts the exact frozen class list, so it failed twice
   (`assert ['D2_letterhead_zone', 'D2_letterhead_zone'] == ['D2_letterhead_zone']`).
2. **Invented defect class / false rejects.** Any substantive sentence that
   discusses the court (`Gericht`, `court`, `tribunal`, `BGE`) but is grounded
   outside the letterhead zone would be marked defective. The frozen D1–D4
   predicate set is closed; a filter may narrow which spans are offered to the
   gate, but may not invent a new rejection rule.

No observed defect motivated the supplement. The committed fixed-path family
was already clean before it: `CYCLE_40823586491.json` recorded 61 bundles,
6100 decisions, 76 verified rows, D1=D2=D3=D4=0 and 0 false rejects. The
supplement was therefore removed in this cycle and replaced with a regression
test that pins the closed predicate set on the exact shape it mis-scored.

Preserved from `7393042a`: the `_content_rejection_sweep` change that applies
the frozen content filter whether or not a span record exists, and the
`live_slice/20261029T061941Z` evidence. Preserved from history, not reverted:
the `e2a5b599` commit itself remains in git history and is disclosed here; the
working tree no longer contains the over-broad supplement.
