## 2. Instrument delta (what this cycle changed)

1. **`product/audit_step_diagnosis.py`** now reports the *persist step's own
   conclusion*. The old code derived `team_snapshot_persisted` from
   `team_ok and persist_ok`, which reports **“no snapshot” for a snapshot the
   `if: always()` step actually published**. It also classifies a failed
   producer step at *Run lane cycle* explicitly, and reports
   `producer_state_validation_step_conclusion` /
   `write_scope_step_conclusion` rather than silently collapsing skipped steps
   into `False`.
2. **`gate_file_written` is now true only when the gate step itself
   succeeded.** A skipped audit job has no gate steps, so the old
   `not gate_skipped and not snapshot_skipped` expression could report a gate
   that never existed.
3. **`product/resume_snapshot_diagnosis.py`** (new) combines, read-only:
   orchestration classification from the committed run/jobs snapshot, the
   durable-delta fact from local git refs, both halves of factory-wide
   requirement 4, and the auditor-namespace inventory. It never fetches,
   never writes a gate, and never labels a run accepted or rejected.
4. **`product/tests/test_cycle_40188639817.py`** amendment: the historical
   classifier-reproduction assertion now compares every key the historical
   artifact published instead of requiring exact dict equality, because the
   classifier gained additive fields. An existing key that changes value still
   fails.
