### 4b. Reproducibility-scope disclosure — `results/product/gate_packet/REBUILT_39027045675_REPRODUCIBILITY_SCOPE.json`

**Finding (measured this run).** The committed bundle bytes and `packet.json` are the
artifact of record and their own `content_sha256` are stable file hashes. But a
from-source rebuild via `apply_adopted_config(source_bundle)` is **not**
byte-identical across numeric environments: `query_similarity` drifts at
~1e-4…1e-3 and reassigns `cluster_id` on **fr 98/217** and **de 112/214** rows
(it 0/211; hash still differs). This is the documented BLAS/TF-IDF reduction-order
sensitivity class (frontier-served-packet-falsification FIX-2), **not** data
tampering and **not** a frozen-rule change.

**Why disclosed, not "fixed":** rounding `query_similarity` before clustering would
change the committed bytes and the frozen-scored layout, which is ceded to Core
Evaluation. Recording the numeric environment alongside the shas is the sanctioned
action; pinning BLAS build + thread count is required before any cross-machine
byte-identity claim. The frozen 11-criteria rule runs on the committed bytes, whose
hash is stable.
