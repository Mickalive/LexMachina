## 1. F1 — the D2 guard is now machine-independent, and cannot come back

**Defect.** `product/tests/test_v52_endgame_delivery.py:331` asserted
`str(REBUILT) in h["packet_path"]` — the committed *producer* prefix
(`/home/runner/work/LexMachina/LexMachina/...`) compared against the *running* checkout's root. It passed only
where the tree sits at the producer's CI path.

**Reproduced this cycle, before the fix:** `1 failed / 21 passed` at `/tmp/opencode/lex_second_root`, with
exactly the assertion the audit named.

**Fix.** The predicate is now `Path(h["packet_path"]).is_absolute()`, plus a tail assertion
(`parts[-3:] == ("gate_packet", "rebuilt-39027045675", "packet.json")`) so the test establishes what it is
named for: *the recorded path is absolute **and** points at the rebuilt packet* — reading the committed
artifact alone, never this machine's paths.

**Anti-regression, two halves** (`test_path_assertions_are_machine_independent`):

1. **Behavioural.** The module's own D1 and D2 path guards are re-executed with `ROOT`/`REBUILT`/`SOURCE`
   monkeypatched onto a temp checkout that is not the producer path. They must pass there — and a tampered
   foreign tree must then be caught. This is the exact failure shape F1 had, run as a test.
2. **Static.** `_machine_coupled_assertions()` rejects, at the AST level, any `assert` in the module that
   reaches for `str(ROOT|REBUILT|SOURCE)`. The detector is proved non-vacuous on a synthetic bad snippet and
   on a good one, so it cannot pass by finding nothing.

**Non-vacuity, measured.** Re-introducing the exact defective line in a foreign-root tree makes **both** the
module-level D2 guard and the new static tripwire fail (`2 failed / 21 passed`). The module is green at two
distinct roots: **25 passed** at `/home/runner/work/LexMachina/LexMachina`, **25 passed** at
`/tmp/opencode/lex_repaired_rootB`. All 25 are non-vacuous (three tamper/absence reproductions inside the
module itself).

prose:

* every number is tagged with the checkout root, the baseline tree and the control-plane mount;
