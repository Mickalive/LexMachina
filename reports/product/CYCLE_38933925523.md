## 1. Problem addressed

The durable reality-check workflow (`.github/workflows/product-reality-check.yml`, control-plane
scope) re-assigns `paths.DEFAULT_FREE_MODELS` **after** the product seam runs, with the two models
the 2026-10-16 health snapshot proved dead (`nemotron-3-ultra`, `nemotron-3.5-lightning`) **first**:

```python
paths.DEFAULT_FREE_MODELS[:] = [
    "opencode/nemotron-3-ultra-free",
    "opencode/nemotron-3.5-lightning-free",
    "opencode/space-bunny-free",
    "opencode/mimo-v2.6-flash-free",
]
```

With no `state/model_health.json` on the branch, `paths.healthy_models()` returned that list
verbatim, so the durable gate burned a 120 s answer + 180 s adversarial timeout per dead model
before reaching a healthy one — the observed ~316–469 s full-answer latency band and a direct
breach of the 300 s gate. The prior cycle's fix (pinning `DEFAULT_FREE_MODELS` at apply time) was
necessary but not sufficient, because the workflow overrides it afterwards.

## 2. Code delta (product-owned paths only)

### `product/query/audit_seam.py`
`apply()` now also wraps `paths.healthy_models` and `paths.preferred_model` so
`KNOWN_DEAD_MODELS` are filtered from the **result at call time**, no matter what the caller last
wrote into `DEFAULT_FREE_MODELS`. If filtering would empty the list, the wrapper falls back to
`MODEL_ORDER` so a healthy model is always available. Idempotence uses the same `_lex_original`
sentinel as the existing `__init__` wrapper, so the `query.*` / `product.query.*` module identities
cannot stack a second wrapper. The wrapping is recorded in bundle provenance
(`healthy_models_wrapped`, `preferred_model_wrapped`, `known_dead_models`).

### `product/reality_check.py`
Added a `--workflow-override` flag that reproduces the durable workflow's exact post-seam model-list
override (dead models first) before running a leg. A green local run under this flag is evidence the
durable gate's model condition is now harmless. The override is recorded per-report
(`workflow_override: true`).

## 3. Tests added (non-vacuous)
