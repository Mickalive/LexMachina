## 3. One real self-contradiction in the artifact: disclosed, not laundered

The reference artifact's `bundle_summary.n_counter` is **4**. The product
definition (`gate_admissibility.counter_ids()` / `NON_COUNTER_STATUSES`) counts a
row as a counter finding only when it carries a counter-authority status; a row
whose status is `cited` is not a counter finding. The reference instead counted
the four rows the answer *cited*.

Why it matters: the **same artifact's own `admissibility` block correctly warns
`no_counter_authority`** (zero rows carry a counter-authority status). The
artifact therefore contradicted itself — four counters and zero counters in the
same file.

The rebuild tool does **not** silently match or silently "fix" the reference. It
publishes a `counter_count` block with both numbers and the explanation, and a
test pins both, so the divergence can neither be laundered nor quietly dropped:

```json
"counter_count": {
  "product_definition_n_counter": 0,
  "legacy_artifact_definition_counter_status_not_none": 4,
  "note": "... the reference counted the answer's own cited rows ..."
}
```

No threshold, rubric, gate or frozen bar was touched. This is a disclosure and a
reproducibility instrument.
