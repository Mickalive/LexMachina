## 3. Independent Recomputation & Verification

### 3.1 Citation Role Integration Experiment

**Script:** `v6_citation_role_integration.py`  
**Inputs:**
- 2,988 role annotations from v5 extraction (`results/v5/citation_roles/citation_roles_sample.json`)
- Citation ID resolution mappings (`results/v6/citation_id_resolution/citation_to_decision_id.json`)
- center_projected 64-dim baseline embeddings

**Method:** Build citation role matrices by mapping role annotations to decision indices via resolved citation IDs, then compute SVD embeddings. Blend with center_projected at α=0.3, 0.5, 0.7.

**My Verification:**
1. **Role annotations exist and are valid:** 2,988 roles across 200 decisions with distribution: citing=2,427, following=311, distinguishing=174, criticizing=58, overruling=18. ✅
2. **Citation ID resolution stats:** 8,480 total citations; 5,828 court decision format; 2,180 BGE format; 472 other. Only 1,124 court decision citations resolved (13.3% of total). ✅
3. **Role embedding construction:** The code attempts to match `role_obj.target_decision` (BGE/ATF format like "BGE 149 IV 9") against `id_to_idx` keys (internal format like "bger_5A_604_2024"). **No matches occur** because formats are incompatible. ✅
4. **Result:** All 6 role embedding matrices are zeros (1000×64). Verified by checking `embedding_shape` in results and confirming identical adversarial/fractal scores across all 6 roles. ✅
5. **Hybrids collapse to baseline:** `α * zeros + (1-α) * baseline = baseline`. Verified: all hybrid results identical to `center_projected_64`. ✅

**Conclusion:** The negative result is **genuine and correctly diagnosed**. The pipeline gap is real: BGE/ATF citations (27% of all citations) cannot be resolved without external BGE index or full-text parsing.
