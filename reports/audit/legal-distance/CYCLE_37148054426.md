**Finding**: Dense semantic embeddings **do not pass jurist gate at any scale**. Performance degrades catastrophically at 20yr then partially recovers. The 165k result (JP=0.418) is consistent with the 22yr result (JP=0.4265).

### 4.2 Language Dominance PASS is a Boilerplate Artifact
- LangDom < 0.85 threshold PASSES for all dense variants
- But cross-language retrieval recall@10 = 0.038-0.049 (FAIL, threshold 0.2)
- Boilerplate neighbor rate = 94-95% (FAIL)
- **Interpretation**: Neighbors are same-language boilerplate → cross-language boilerplate → low language dominance score. This is **not** legal semantic alignment.

### 4.3 Zero-Shot Cross-Language Transfer — Misleading PASS
- Zero-shot NMI > in-domain NMI (negative transfer gap)
- But absolute NMI values are very low (0.22-0.24)
- Language-specific branch NMI: de=0.34, fr=0.33, it=0.30 (marginal)
- **Interpretation**: Transfer "works" because both are near noise floor. Not a meaningful capability.

### 4.4 Hierarchy Coherence — FUNDAMENTAL LIMITATION
- Level 1 (16 legal areas) NMI: 0.35-0.37 vs 0.7 threshold
- Level 0 (4 branches) NMI: 0.197 — near random
- **Consistent with v18 coarse hierarchy negative result**: Even at 4-label branch level, best purity 0.65 < 0.7
- Dense embeddings **do not align with legal taxonomy** at any granularity
