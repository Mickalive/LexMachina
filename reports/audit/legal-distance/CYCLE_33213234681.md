## Cross-Cutting Issues Identified

### 1. **Evaluation Metadata Alignment Issue (Minor)**
The comprehensive evaluation loads metadata from `/tmp/lex_accepted/fractal-map/results/fractal_map/baseline/metadata.json` (1000 decisions) but loads `center_projected_full` embeddings from `/tmp/lex_team/legal_distance/results/v5/center_projected_full/embeddings_center_projected.npy` (1200 decisions). It aligns by taking the first 999 valid embeddings. This works but is slightly inconsistent — the embeddings were computed on a different corpus than the metadata. However, results match the v2 benchmark (which used the correct center_projected transform on the baseline embeddings), so the practical impact is minimal.

### 2. **Signal Ablation Hybrids Not Re-evaluated Against Adversarial Gates**
The v5 scale test identified 3 promising hybrids (legal_issues_outcomes, legal_area_tfidf, hybrid_erwaegungen_03) with excellent fractal quality metrics. The comprehensive evaluation did **not** re-test these against the two critical adversarial gates. The report correctly notes they "remain promising untested candidates." This is a gap for the next cycle.

### 3. **Overclustering Pathology Correctly Diagnosed**
Both pure citation roles and ft_multilingual_e5_small_pretrained pass adversarial gates through structural artifacts (overclustering or collapse), not genuine legal-semantic structure. The audit confirms:
- Citation roles: 4.5% citation ID resolution rate → sparse matrices → each decision isolated
- ft_e5_small: All embeddings nearly identical → single cluster
The adversarial PASS for these is a **false positive** correctly flagged by the hierarchical_advantage=0.0 metric.
