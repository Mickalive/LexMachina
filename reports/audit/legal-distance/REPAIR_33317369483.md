## 2. Required Fixes → Applied Fixes (traceability)

### Required Fix 1 — Fix model selection to use the TRAIN set; re-run both arms; re-derive claims from clean OOS

**Prior defect (confirmed):** the original `v11_oos_hybrid_stabilized.py` selected
the best checkpoint by maximizing **HOLD-OUT** JuristPref, then reported final metrics
on that same holdout (selection-on-test-set / data snooping). This made the "beats v10
baselines", "hierarchy loss load-bearing +0.055", and product-default claims invalid.

**Applied fix:** a corrected experiment,
`legal_distance/experiments/v11_oos_hybrid_stabilized_fixed_selection.py`, was written
that:

- Selects the best checkpoint using **TRAIN-set adversarial metrics** during training
  (best train JuristPref among train-both-passing checkpoints), exactly as v10 does.
- After training, loads the train-selected checkpoint and evaluates the **true
  200-decision holdout exactly once**.
- Runs **both** the hierarchy and no-hierarchy ablation arms under the corrected
  selection, so the hierarchy-loss ablation remains a controlled comparison.

**Re-ran** both arms (seeded, CPU, ~1.5 min each):

| Arm | Holdout LD | Holdout JP | CiteIndep | Both pass | Clean OOS |
|-----|-----------|-----------|-----------|-----------|-----------|
| hybrid (hierarchy) | 0.6015 | **0.5350** | 36.40% | ✅ | ✅ PASS |
| hybrid (no-hierarchy) | 0.6412 | **0.5050** | 33.50% | ✅ | ✅ PASS |

**Re-derived clean-OOS claims (from the corrected runs only):**

- *OOS hybrid PASSES all frozen gates on clean holdout* — **SUPPORTED**
  (LangDom=0.6015, JP=0.5350, CiteIndep=36.40%).
- *Hierarchy loss effect* — clean magnitude = **+0.030 JP** (0.535 vs 0.505). Both arms
  pass the jurist gate, so the old "load-bearing for crossing the jurist gate (+0.055)"
  claim is **NOT supported**; the +0.055 was inflated by selection-on-holdout.
- *Beats v10 OOS baselines* — now apples-to-apples (both train-selected): hybrid 0.535
  vs linear 0.525 / mahalanobis 0.530. The +0.005–0.010 gap is **within the noise floor**
  of the 200-decision proxy. Treated as **roughly tied**, not a demonstrated improvement.

**Provenance preserved:** the rejected (selection-biased) result outputs were **not
deleted**; they were moved to
`legal_distance/results/v11/_archived_SELECTION_ON_HOLDOUT_REJECTED_20260830/` and are
referenced in `state/legal-distance.json` as the archived rejected prior.
