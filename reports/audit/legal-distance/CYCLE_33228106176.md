**Root Cause Analysis (Validated):**

1. **Contrastive loss dominates**: As preservation loss decreases (structure becomes similar), contrastive loss continues pushing same-branch-diff-lang pairs closer, but without sufficient structural constraints this creates fragmented fine clusters that don't generalize.

2. **Pair distribution mismatch**: Contrastive pairs cover branch-level alignment but not finer legal structure (legal_area, chamber, outcome). The model overfits to branch/language pairs.

3. **No explicit hierarchy constraint during training**: The hierarchy loss (λ_h=0.5) is evaluated but **not backpropagated per-batch** — it's only computed at epoch evaluation. The training loop has `loss_h = torch.tensor(0.0)` during batch training.

## Cross-Cutting Issues Identified

### 1. **Hierarchy Loss Not Backpropagated — Critical Implementation Gap**

The training code defines `hierarchy_loss()` function but sets `loss_h = torch.tensor(0.0)` during batch training (line 539). The hierarchy loss is only computed at epoch-level for logging (line 567-568). This means **the hierarchy constraint is NOT actually constraining the training dynamics** — it's purely a monitoring metric. This likely explains the instability: the contrastive loss has no structural anchor during optimization.

### 2. **Adversarial vs. Fractal Gap Confirmed as Fundamental**

The work correctly identifies that cluster-level taxonomic alignment (fractal harness) and neighbor-level multilingual invariance + legal relevance (adversarial benchmarks) measure different properties. Legal signals excel at the former, fail at the latter. The hybrid objective narrows this gap but doesn't eliminate it — the trade-off at epoch 3 (better JP, worse improvement rate) reflects this fundamental tension.

### 3. **Contrastive Pair Distribution Mismatch**

Positive pairs: same branch, different language (~14,640). Negative pairs: same language, different branch (~12,448). These cover branch-level alignment but miss:
- Legal area level (Jurivoc taxonomy)
- Chamber level (within-branch specialization)
- Outcome level (procedural vs. substantive)
- Citation network structure

The model overfits to branch/language pairs, explaining why finer structure degrades.

### 4. **GPU Blocker for Full Fine-tuning (Real, Honest)**

- Environment lacks CUDA, PyTorch GPU, nvidia-smi
- Fine-tuning code complete (`v6_finetune_multilingual_e5.py` exists)
- Negative result preserved as evidence per Research Protocol
- **CPU-based hybrid objective on center_projected is the viable path** — 560K params, ~2 min/epoch

### 5. **Previous Overclaim Corrected (Prior Cycle)**

Initial cycle claimed "All 6 objectives completed." Repair cycle correctly identified: 3 COMPLETED, 2 PARTIAL, 1 BLOCKED. This correction is evidence of audit responsiveness.
