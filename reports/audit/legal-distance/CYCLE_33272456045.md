**Two different evaluation configurations produce contradictory results for the same representation:**

| Evaluation Harness | Decisions | Embedding Dim | LangDom | JuristPref | Both Gates |

| **standalone_benchmarks** (frozen harness v3) | 1200 | 128 | **0.596 ✅** | **0.616 ✅** | **PASS** |
| **adversarial_signal_validation** | 1000 (truncated) | 128 | **0.856 ❌** | **0.257 ❌** | **FAIL** |

**Root cause:** The standalone_benchmarks uses the full 1200-decision corpus with the frozen evaluation harness v3 (seed=42), while adversarial_signal_validation truncates to 1000 decisions and uses a different adversarial evaluation code path. The LangDom threshold is 0.85; standalone achieves 0.596 while adversarial_signal_validation achieves 0.856 (barely failing).

**Impact:** The factory direction objective mapping report claims "cited_decisions_tfidf: FIRST unsupervised signal passing BOTH gates (LangDom=0.596, JP=0.616)" citing standalone_benchmarks. The adversarial_signal_validation report shows it fails. **Both are valid measurements on different configurations.**

**Required disclosure:** The report must explicitly state which evaluation configuration produced the cited numbers. The standalone_benchmarks (16-benchmark frozen harness v3) is the primary benchmark for factory direction v6; adversarial_signal_validation is a supplementary validation.
