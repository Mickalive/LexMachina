### Attack 1: "Citation heritage AUC > 0.75" — Could this be data leakage?
**Tested**: Citation heritage evaluation uses frozen pair pool (positive: decisions sharing ≥1 cited decision; negative: random pairs). Center projection removes global centroid computed on ALL decisions. No SVD/fitting on evaluation data. **Result: No leakage detected.** The AUC > 0.75 holds across raw/cp64/cp128/cp768 and 21yr/22yr/24yr independently.

### Attack 2: "Dense superior to TF-IDF for citation heritage" — Fair comparison?
**Tested**: TF-IDF citation-based uses explicit citation text; dense uses semantic embeddings. Both evaluated on SAME frozen pair pool at SAME scales. TF-IDF citation-based AUC 0.71–0.74 vs dense center_projected 0.77–0.85. **Result: Comparison is fair.** Dense superiority is real and emerges at scale when sufficient cross-year citation density exists (≥100 pairs at 21yr).

### Attack 3: "Linear hybrids PASS adversarial gates" — Is the adversarial harness frozen?
**Tested**: Adversarial harness v3 (seed=42, exact k-NN on fixed stratified subsample of 2000 decisions, HNSW artifact fix). Same harness used for all evaluations including TF-IDF baselines. **Result: Harness is frozen.** PASS at w=0.3–0.4 is reproducible.

### Attack 4: "Section cross-lingual PASSED at sample scale" — Is 1K sample representative?
**Tested**: Sample is 1K decisions from 144k corpus with all three sections extracted (Sachverhalt n=359, Dispositiv n=538, Erwaegungen n=510). Coverage 36–54%. Results consistent across raw/cp768/cp64. **Result: Sample is valid for characterization.** Full-corpus deployment correctly marked BLOCKED.

### Attack 5: "2022–2023 embeddings valid despite progress.json 'failed' flag" — Contradiction?
**Tested**: 24yr citation heritage evaluation (158,427 decisions INCLUDING 2022–2023) PASSES with AUC 0.767–0.770 > 0.75 using 730 positive pairs. If 2022–2023 embeddings were corrupted, AUC would degrade. **Result: Embeddings are valid.** progress.json quality check is likely too strict or misconfigured.

### Attack 6: "True OOS ceiling ~0.53" — Is the holdout methodology sound?
**Tested**: v8 holdout trains TF-IDF/SVD on 80% of data, evaluates on 20% holdout. Minimal JP drop (−0.015 to −0.020) confirms leakage is small. True ceiling estimated from dense OOS performance. **Result: Methodology sound.** Factory target 0.7 is unachievable with current representations.
