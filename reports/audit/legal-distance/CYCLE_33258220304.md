## 3. Critical Findings

### 3.1 cited_decisions_tfidf Discrepancy Between Evaluation Harnesses (MAJOR)

**Two different evaluation configurations produce contradictory results for the same representation:**

| Evaluation Harness | Decisions | Embedding Dim | LangDom | JuristPref | Both Gates |
|-------------------|-----------|---------------|---------|------------|------------|
| **standalone_benchmarks** (frozen harness v3) | 1200 | 128 | **0.596 ✅** | **0.616 ✅** | **PASS** |
| **adversarial_signal_validation** | 1000 (truncated) | 128 | **0.856 ❌** | **0.257 ❌** | **FAIL** |

**Root cause:** The standalone_benchmarks uses the full 1200-decision corpus with the frozen evaluation harness v3 (seed=42), while adversarial_signal_validation truncates to 1000 decisions and uses a different adversarial evaluation code path. The LangDom threshold is 0.85; standalone achieves 0.596 while adversarial_signal_validation achieves 0.856 (barely failing).

**Impact:** The factory direction objective mapping report claims "cited_decisions_tfidf: FIRST unsupervised signal passing BOTH gates (LangDom=0.596, JP=0.616)" citing standalone_benchmarks. The adversarial_signal_validation report shows it fails. **Both are valid measurements on different configurations.**

**Required disclosure:** The report must explicitly state which evaluation configuration produced the cited numbers. The standalone_benchmarks (16-benchmark frozen harness v3) is the primary benchmark for factory direction v6; adversarial_signal_validation is a supplementary validation.

### 3.2 multilingual_e5_contrastive_projection — Overclustering Artifact

The comprehensive evaluation includes `multilingual_e5_contrastive_projection` which **passes both adversarial gates** (LangDom=0.459 ✅, JP=0.850 ✅) but **fails fractal quality**:
- n_coarse=1, n_fine=1000 (overclustering)
- coarse_purity=0.466, fine_purity=1.0
- hierarchical_advantage=0.0
- overclustering=true, valid_representation=false

**Assessment:** This is correctly flagged in the fractal_quality section of comprehensive_evaluation_results.json with `"valid_representation": false`. However, the adversarial PASS could mislead if viewed in isolation. The negative results report should include this as a fifth negative result (adversarial PASS due to overclustering artifact).

### 3.3 JuristPref Metric Sensitivity Across Configurations (CONFIRMED)

As noted in previous audit, JuristPref varies significantly by configuration:
- center_projected: standalone (1200 dec, 64-dim) → JP=0.982; validation (1000 dec, 384-dim) → JP=0.528
- linear_metric: validation (1000 dec, 128-dim) → JP=0.707
- mahalanobis: validation (1000 dec, 128-dim) → JP=0.689

**Assessment:** The metric is not invariant to embedding dimension, dataset size, or harness version. The factory direction objective mapping report correctly uses validation_breakthrough numbers (1000 dec, 128-dim) for breakthrough representations, avoiding the 64-dim standalone discrepancy.
