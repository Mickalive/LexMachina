## Methodological Rigor Assessment

### ✅ Strengths

1. **Frozen Harness**: All evaluations use fixed config hash (`1674829901d55e83`) and seed (42) for baselines; independent seed (137) for reproduction
2. **Exact k-NN**: Adversarial evaluation uses `sklearn_exact` on fixed stratified subsample (2000 decisions) — eliminates HNSW approximation artifacts
3. **Paired Delta Analysis**: v14 independent rerun computes paired deltas per fold, not just aggregate means — proper statistical comparison
4. **Explicit Success Rules**: `min_mean_jp_delta=0.02`, `max_jp_delta_std=0.03` defined upfront
5. **Negative Results Preserved**: All failures documented with same rigor as successes
6. **Scale Sweeps**: 15yr, 19yr, 20yr, 21yr, 22yr systematically evaluated
7. **Independent Reproduction**: v14 rerun with independent seed confirms key finding
8. **Leakage Acknowledgement**: TF-IDF baseline JP=0.78 acknowledged as evaluated on same data used for SVD fitting; v8 holdout showed minimal impact (-0.015 to -0.020)

### ⚠️ Limitations (Acknowledged in Reports)

1. **Simulated Jurist**: `jurist_pairwise_preference` is a proxy metric (legal neighbor rate), not human evaluation
2. **Subsample Evaluation**: Adversarial suite runs on 2000-decision stratified subsample, not full 144k
3. **Branch Labels as Ground Truth**: Cross-language evaluation uses branch labels (4 branches) as legal taxonomy proxy — coarse granularity
4. **Section Cross-Lingual at Sample Scale Only**: Full corpus evaluation blocked by data dependencies
5. **TF-IDF Baseline Leakage**: SVD fit on full corpus before evaluation; holdout validation partial

### ❌ No Evidence Of

- Data leakage in dense embedding evaluations (embeddings computed independently)
- Benchmark gaming (success criteria fixed, negative results reported)
- Weak baselines (TF-IDF citation hybrids are strong, well-tuned baselines)
- Prettiness-as-quality (reports are technical, not polished marketing)
- Unsupported product claims (claims match evidence, limitations explicit)
