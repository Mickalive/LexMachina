## 3. Critical Findings

### 3.1 Center_Projected Methodology Discrepancy (MAJOR)

**The report claims center_projected achieves JuristPref=0.9817, LangDom=0.5310.**  
This comes from `standalone_benchmarks` (1200 decisions, 64-dim embeddings, different evaluation harness).

**Independent validation (`validation_breakthrough`) and comprehensive evaluation show: JuristPref=0.5275, LangDom=0.763** (999/1000 decisions, 384/768-dim embeddings).

**Root cause:** The "64-dim MiniLM-L12-v2" in the report refers to a *different embedding pipeline* (center projection on 64-dim sentence embeddings) vs. the 384-dim/768-dim pipelines used in comprehensive evaluation. The standalone benchmarks used a cached 64-dim center_projected embedding; validation_breakthrough and comprehensive_eval used fresh 384-dim center_projected embeddings.

**Impact:** The report presents these as the same representation. They are not. The 0.9817 JuristPref is **not reproducible** on the full adversarial harness with the same dimensionality as the breakthrough representations.

**Recommendation:** Disclose the dimensionality/evaluation-set difference explicitly. Do not claim "center_projected_64dim achieves 0.982 JuristPref" without qualifying that this is on a different evaluation configuration than the breakthrough representations (which were validated on 1000 decisions at 128-dim).

### 3.2 Fractal Validation Gap in Independent Validation

`validation_breakthrough/validation_results.json` shows `"fractal": { "error": "No module named 'igraph'" }` for **all four breakthrough representations** (center_projected, linear_metric, hybrid_stabilized, mahalanobis).

**The claim "meaningful fractal structure" for breakthrough representations is NOT independently validated in the validation_breakthrough run.** Fractal metrics come only from training-time evaluations (metric_learning_results.json, hybrid_objective_stabilized/training_results.json) which use the same code path as training — not an independent harness.

**Assessment:** The fractal structure claims rely on training-internal evaluation. The independent validation harness lacks igraph dependency. This is a reproducibility gap, not a falsification.

### 3.3 Jurist Preference Metric Sensitivity

The JuristPref metric varies significantly by evaluation configuration:
- 1200 decisions, 64-dim, standalone harness → center_projected: 0.9817
- 1000 decisions, 384-dim, comprehensive harness → center_projected: 0.5275
- 1000 decisions, 128-dim, validation harness → linear_metric: 0.7067

**The metric is not invariant to embedding dimension, dataset size, or harness version.** The report should not present JuristPref as an absolute quality score comparable across configurations.

### 3.4 Citation Role Negative Result — Correctly Handled

2,988 multilingual role annotations extracted successfully. Embedding construction failed silently due to BGE/ATF citation format mismatch with internal decision_ids. Pipeline fixed for court decisions (1,124 resolved) but BGE citations (2,180) remain unresolved.

**Assessment:** This is a data engineering gap, not a research failure. The negative result (zero matrices → overclustering artifacts) is preserved as first-class evidence. ✅

### 3.5 Jurivoc Alignment Limitation — Correctly Documented

All representations fail Jurivoc hierarchy alignment (NMI ~0.31–0.46, threshold=0.5) due to chamber-vs-Jurivoc label mismatch, not representation failure. Report correctly attributes this. ✅

### 3.6 Signal Ablation Hybrids — Correctly Failed

All v5 signal ablation hybrids (legal_issues_outcomes, legal_area_tfidf, hybrid_erwaegungen_03, etc.) FAIL adversarial gates on full corpus (1200 decisions) — only cited_decisions_tfidf passes. Report correctly states this. ✅
