## 4. Critical Findings Requiring Attention

### 4.1 Unverifiable External Dependencies
The following critical results depend on artifacts in `/tmp/lex_accepted/` which **do not exist in this environment**:
- v25 TF-IDF 174k formal suite results (8/8 PASS claim)
- v8 holdout zero-shot validation (true OOS ceiling ~0.53)
- v18 coarse hierarchy (purity 0.65 < 0.7)
- v17b label normalization

**This is an orchestration failure**, not a lane failure. The factory direction claimed corpus mount path gap was resolved but it was not.

### 4.2 20-Year Catastrophic Failure Unexplained
The drop from 19yr JP=0.3685 to 20yr JP=0.0475 (cp_768) then recovery to 22yr JP=0.4265 (cp_64) is reported but not explained. Could indicate:
- Checkpoint corruption for 2019 data
- PCA model fitting artifact
- Real scale transition phenomenon

**Recommendation**: If corpus lane resumes, re-run 20yr and 21yr center_projected evaluations to clarify.

### 4.3 Section Cross-Lingual Thresholds Arbitrary
The thresholds (>0.2 for Sachverhalt, >0.1 for Dispositiv) appear post-hoc. The Erwaegungen result (0.094) narrowly misses 0.1. Should be explicitly acknowledged as exploratory thresholds.

### 4.4 Linear Hybrid "Complement" Overstated
The report characterizes linear hybrids as "complementary" but they:
- Don't beat TF-IDF on jurist preference at any weight
- Only improve cross-lingual recall from 0.124 → 0.160 (still below 0.2 useful threshold)
- Optimal weight is 60-70% TF-IDF, 30-40% dense — i.e., **TF-IDF dominant**

This is honestly reported in the detailed findings but the "complementary mode" framing in product integration could mislead. The gate correctly marks it "exploratory mode."
