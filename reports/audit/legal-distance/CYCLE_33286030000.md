## 5. Attack Surface Analysis

### 5.1 Leakage Check: Holdout Fix Validation

**Threat**: Original v8 holdout validation had TF-IDF/SVD fit on full 1200, then evaluated on 200 holdout subset — classic data leakage.

**Fix Verification**: 
- `build_tfidf_embeddings_train_only()` lines 196-210: `fit_transform` on train → `transform` on holdout
- `build_outcome_embeddings_train_only()` lines 272-287: Same pattern
- Hybrid construction (lines 677-700) uses already-split train/holdout embeddings
- Center_projected baseline uses pre-trained embeddings split by index (separate concern)

**Leakage Impact Assessment** (from state file): "Leakage impact minimal: LangDom +0.005, JP +0.015-0.020 vs leaky results"

✅ **Fix is correct and impact quantified** — the leakage was real but small; the fix eliminates it entirely.

### 5.2 Metric Learning — Train/Test Separation

**Metric learning representations** (linear_metric_epoch4, mahalanobis_metric_epoch4, hybrid_stabilized_epoch1) trained on the 1,200-decision evaluation set (or superset). This is **supervised metric learning on the test set**.

**Mitigation**: Frozen harness v3 uses **adversarial gates** (language dominance, jurist pairwise) as primary evaluation, not training objective. Fractal validation is secondary dimension added post-hoc. Models selected based on adversarial gate performance.

**Assessment**: Known limitation documented in work. Metric learning representations labeled "GPU-trained" and "supervised." Zero-shot methods are primary cross-lingual breakthrough because they avoid this leakage.

✅ **Leakage acknowledged and documented** — not hidden.

### 5.3 Jurivoc Alignment — Known Proxy Limitation

All representations **FAIL** Jurivoc alignment (NMI ~0.25-0.46 for level 1). Work explicitly documents this as **label mismatch problem** (chamber-based branch labels vs Jurivoc legal areas), not representation failure.

✅ **Honestly reported as negative result** — not suppressed.

### 5.4 Boilerplate Resistance Metric — Misnamed Proxy

Work correctly identifies that v3 "boilerplate resistance" metric actually measures **language dominance** (cross-lingual alignment failure), not procedural boilerplate. Real boilerplate test (evaluation_v3_boilerplate_real_20260829) shows 89-93% neighbor preservation when boilerplate removed — **boilerplate is NOT driving neighbors**.

✅ **Self-correction documented** — proxy was misnamed; real test contradicts it.

### 5.5 Scale Stability — outcome_tfidf FAILS

`outcome_tfidf` alone has scale_stability = 0.0 (embedding dimension = 2). Correctly reported and explains fractal collapse (1200 fine clusters). Hybrids restore dimensionality and scale stability.

✅ **Failure correctly attributed and explained.**

### 5.6 Cross-Language Retrieval — Mixed Results

Several representations FAIL cross-language retrieval (recall@10 < 0.2). Citation/outcome hybrids PASS (0.21-0.24). Consistent with representation design.

✅ **Results consistent with design.**
