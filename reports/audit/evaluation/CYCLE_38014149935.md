- **No evidence of test data leakage**: Adversarial gates use fixed stratified subsample (n=2000) from 174k corpus with known branch labels. The subsample is fixed by seed=42 and deterministic group sorting.
- **Cross-lingual evaluation**: Uses section-level embeddings (Sachverhalt/Dispositiv/Erwaegungen) with explicit coverage reporting (36-54%). No leakage from full-text to section-level.
- **Citation heritage**: Uses citation pairs (positive/negative) with explicit pair counts (344 positive, 500 negative). No evidence of pair selection bias.

### 4.2 Post-Hoc Metrics / P-Hacking
- **Thresholds frozen since v3**: Language Dominance < 0.85, Jurist Preference > 0.5 — not tuned to results.
- **Dense acceptance criteria defined BEFORE validation**: Criteria set (AUC > 0.75, cross_lang > 0.20/0.10) then validated at max available scale.
