## 5. Methodological Concerns & Audit Findings

### 5.1 Cluster Coherence Metric — **MISLEADING PASS**
**Severity**: HIGH
The `cluster_coherence_rating` benchmark returns PASS for dense 3-year representations based solely on `mean_branch_purity` (~0.87–0.90), while `mean_language_purity` is **0.995–0.996**. Clusters are almost perfectly language-segregated. A jurist would see language clusters, not legal clusters. The metric should either:
- Require language_purity < threshold (e.g., < 0.8) for PASS, OR
- Report a composite score (branch_purity - language_purity), OR
- Return FAIL with explanatory note.

**Current behavior**: Reports PASS with note "High language purity = language-dominated clusters" — this is contradictory.

### 5.2 Boilerplate Resistance Metric — **MEASURES LANGUAGE DOMINANCE, NOT BOILERPLATE**
**Severity**: MEDIUM (Acknowledged)
The metric `resistance_score = legal_neighbor_rate - boilerplate_neighbor_rate` uses cross-language neighbors as "boilerplate" proxy. Consistently negative scores (-0.97 to -0.83) reflect language dominance, not procedural boilerplate. Report acknowledges: "confirming this proxy measures language dominance/cross-lingual alignment failure, not procedural boilerplate." This is honest but the metric name is misleading.

### 5.3 Citation Heritage Recall@10 = 0.0 at All Scales — **KNOWN LIMITATION**
**Severity**: LOW (Properly Disclosed)
Despite AUC > 0.65 for citation-based representations, Recall@10 = 0.0 because citation graph covers only 0.1% of corpus. This is a fundamental coverage limitation, not a representation failure. Honestly reported.

### 5.4 HNSW Artifact Fix — **VALID METHODOLOGICAL IMPROVEMENT**
**Severity**: INFO
Adversarial benchmarks use exact k-NN (sklearn) on fixed stratified subsample (n≈2000) instead of HNSW approximate search. This avoids HNSW masking representation differences. Correctly documented with config hash. Reproducibility verified.

### 5.5 State File Inconsistencies — **MINOR BUGS**
1. Citation heritage: `passing_representations: 3` should be 4 at AUC≥0.65 threshold.
2. 15-year dense: marked `"status": "COMPLETE"` but report says "checkpointed pending audit".
3. 3-year citation heritage: included in summary with AUC=0.79 but only 2 positive pairs — should be flagged as unreliable.

### 5.6 No Data Leakage, Benchmark Gaming, or Prettiness-as-Quality Detected
- Frozen harness v3 with fixed thresholds and seed=42
- Exact k-NN on stratified subsample prevents HNSW artifacts
- Citation heritage pair pool frozen (137k pairs)
- Negative results (dense FAIL, v17b NEGATIVE, Recall@10=0) preserved as first-class evidence
- No cherry-picking of metrics or representations
- Scale extrapolation clearly labeled as extrapolation, not measurement
