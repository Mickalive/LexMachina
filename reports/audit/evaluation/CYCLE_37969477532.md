## Root Cause Analysis

### Possible Causes Ruled Out
- ❌ **Embeddings differ**: Embedding files in producer workspace match metadata (173,963 decisions, 128-dim) and have stable timestamps (2026-09-25 creation).
- ❌ **Metadata differs**: Metadata files in producer workspace and checkout are identical (173,963 decisions, same ordering).
- ❌ **Code differs**: The evaluation harness (evaluation_v3_harness.py, scalable_nn.py) is frozen in the control plane.

### Likely Causes
1. **Different subsample**: The stratified subsample (n=2000, seed=42) depends on metadata iteration order. The code comment acknowledges a fix for "non-determinism introduced when control plane mount updated metadata_174k.json at 2026-10-08T23:40". If the NEW results were computed *before* this fix, the subsample would differ.

2. **Different metadata version**: The committed results may have been produced with a different metadata file (different ordering or content) that is no longer in the producer workspace.

3. **Different evaluation code**: The commit may have been produced with a version of the evaluation code that differs from the current control plane.

4. **Missing provenance**: The committed JSON files contain no embedding hashes, metadata hashes, config hashes, or git commit hashes — making it impossible to verify what artifacts produced them.

## Structural Issues

### 1. No Provenance in Committed Results
The verification JSON files lack:
- Embedding file hashes (SHA256)
- Metadata file hash
- Evaluation config hash (from `get_config_hash()`)
- Git commit hash of evaluation code
- Subsample indices used

### 2. Artifacts Not Versioned
Embeddings (175k × 128 float32 ≈ 90 MB each) are not in git. The producer workspace is ephemeral. There is no immutable link between committed results and the artifacts that produced them.

### 3. Non-Determinism Not Fully Fixed
The stratified subsample fix (sorting groups by key) was added *after* the metadata update at 2026-10-08T23:40. If the NEW results were computed before this fix, they used a different subsample.
