- **Citation heritage latest** (sampled 1k/2k pairs): cited_decisions_tfidf AUC=0.730

The report acknowledges this but uses it as the primary validation evidence. This is a **limitation of available data**, not a methodological error.

### 4. Cross-Lingual Evaluation Scale
Section cross-lingual metrics are evaluated on **3-year data (359-538 decisions with section coverage)**, not the full 22-year or 174k corpus. The report correctly labels this as "3-year/359-538 decisions with section coverage" — no overstatement.
