## 3. Critical Issues Identified

### 3.1 No Variant Beats Baseline on Composite Score
The baseline `center_projected` remains the **best overall performer**:
- Only variant with PASS on language dominance AND competitive jurist pairwise (0.4912)
- Best Jurivoc hierarchy separation (0.0956)
- Best cross-language retrieval (0.1456, though still FAIL)
- Strong L2 NMI (0.4298)

No signal ablation variant improves on the baseline; hybrids at α=0.3 approach but don't exceed it.

### 3.2 Jurist Pairwise Threshold Unachievable
**All 15 variants FAIL** the legal_neighbor_rate > 0.5 threshold. The threshold appears infeasible given the data distribution. This should be recalibrated or reported as a known limitation.

### 3.3 Cross-Language Retrieval Threshold Unachievable
**All 15 variants FAIL** mean_cross_language_recall_at_k > 0.2. Baseline achieves 0.1456. The threshold may be too aggressive for this corpus/slice.

### 3.4 Citation Weights Degeneracy
The `citation_weights` variant produces:
- All-zero zero-shot transfer NMI/ARI
- All-zero language-specific quality NMI/ARI
- All-zero Jurivoc metrics
- Single-cluster KMeans (branch purity 0.4737)
This indicates the citation graph SVD produces degenerate embeddings for this slice. The variant should be flagged as invalid.

### 3.5 Scale Stability Test Lacks Discriminative Power
Projecting all embeddings to 64-dim frozen PCA before testing position drift/neighbor preservation makes all variants appear perfectly stable (cosine=1.0). The test should either:
- Use native dimensionality with Procrustes alignment, or
- Be replaced with a more sensitive stability metric

### 3.6 Italian Language Underrepresented
Only 62 Italian decisions (vs 402 FR, 735 DE). Results for `it` are unstable (NMI=0.0 for several variants). Per-language reporting masks this; aggregate metrics should weight by language support.

### 3.7 Inconsistent PASS/FAIL Logic in Cross-Language Summary
The `cross_language.summary` shows `total_benchmarks: 4` but the pass/fail criteria differ per sub-benchmark:
- `adversarial_language_dominance`: threshold 0.85 (lower better)
- `zero_shot_transfer`: status PASS if zero_shot_mean_nmi > in_domain_mean_nmi? (unclear)
- `language_specific_quality`: status PASS if mean_nmi > ? (unclear)
- `cross_language_neighbor_quality`: no explicit status field

This makes the summary `passed/failed` counts unreliable for comparison.

### 3.8 Boilerplate Resistance Completely Absent
A key adversarial benchmark is skipped for all variants. This should be documented as a limitation, not silently skipped.
