## Detailed Findings

### 1. TF-IDF 174k Formal Suite — Fully Reproduced

All 8 representations evaluated against frozen v16 benchmark suite (config hash `4323f833fa72366a`, seed 42) using HNSW backend (hnswlib, M=16, ef_construction=200, ef_search=100). Results are deterministic and match the report exactly.

**Adversarial Gates (critical for production):**
- **Citation-based reps PASS both gates:** cited_decisions_tfidf (LangDom=0.602, BranchCoh=0.354), cited_outcome_hybrid_0.5 (0.578, 0.352), cited_outcome_hybrid_0.7 (0.569, 0.356)
- **Full-text/regeste reps FAIL language_dominance:** ~0.998–0.999 (language dominates neighbors)
- **outcome_tfidf FAILS branch_coherence:** 0.146 < 0.3 threshold
- **regeste_tfidf PASSES both gates** but lacks citation signal (citation_heritage AUC=0.4865)

**Universal FAILs (corpus/label limitations, correctly attributed):**
- `hierarchy_coherence`: best purity 0.08–0.47 << 0.7 threshold
- `legal_area_clustering`: purity 0.003–0.08 << 0.5 threshold
- `boilerplate_resistance_real_corpus`: correlation ~-0.0005 to +0.09 (proxy for language dominance)

**Universal PASSes:** `collapse_check`, `multilingual_invariance` (citation reps), `cross_language_pairs` (citation reps), `adversarial_falsification` (citation reps + regeste_tfidf)

### 2. Citation Heritage Benchmark — Strong Validation

Frozen 137,314 positive + 137,314 negative pairs from 174k citation-ID resolution (2,019/2,105 resolved, 95.9%). Citation-based representations excel:
- cited_decisions_tfidf: AUC=0.9731, nn_citation_rate@10=0.487
- cited_outcome_hybrid_0.7: AUC=0.9605, nn_citation_rate@10=0.490
- cited_outcome_hybrid_0.5: AUC=0.9193, nn_citation_rate@10=0.476

Full-text hybrids show moderate citation recovery (AUC 0.84–0.87, nn_rate≈0.44). regeste_tfidf FAILS as expected (no citation IDs in regeste text).

### 3. v17b Normalization Generalization — Partially Generalizes with Nuance

**Label-level:** 213 raw → 163 normalized labels (23.5% reduction), 49.3% of labels changed (85,819 decisions), 32 cross-lingual canonical concepts. Verified.

**Clustering-level (hierarchy subsample 15k, seed 42):**
- **Citation-based reps:** 1.5–1.6× hierarchy purity gains (0.13→0.20, 0.13→0.20, 0.13→0.20) but **cited_outcome_hybrid_0.5 worsens 16% on zoom_coherence** (26.2%→22.0% improvement_pct), exceeding 10% threshold. cited_decisions_tfidf (-6.7%) and cited_outcome_hybrid_0.7 (+7.2%) within threshold.
- **Full-text/regeste hybrids:** Purity metrics IDENTICAL raw vs normalized (coarse_purity=0.225, fine_purity=0.458, hierarchy_purity=0.465) — **BUT NMI changes** (hierarchy NMI 0.577→0.418, legal_area NMI 0.600→0.454). Claim "no change" is inaccurate; label normalization merges areas, reducing NMI even when cluster assignments stable.
- **regeste_tfidf:** Improves on hierarchy (0.08→0.13) and legal_area (0.08→0.13) — contradicts "no change" claim.
- **Even normalized, best hierarchy purity = 0.47** (full_text_tfidf_light) < 0.7 threshold — fundamental granularity limit persists.

**Conclusion:** v17b partially generalizes; hierarchy-family FAILs at 174k are NOT purely label artifacts.

### 4. Dense Embedding Pipeline — Operational with Minor Reporting Error

`run_full_corpus_evaluation.py` with HNSW backend validated on accepted dense embeddings from legal-distance lane:
- center_projected_64dim: **PASS both gates** (LangDom=0.7664, Jurist=0.5121) ✅
- center_projected_768dim: FAIL jurist_pref (0.491) but PASS LangDom (0.774) — **not** the 0.954/0.095 reported
- The 0.954/0.095 figures belong to `embeddings_768` (raw 768-dim, not center_projected)
- linear_metric_epoch4: PASS both gates (LangDom=0.6805, Jurist=0.6847) per state file

**Infrastructure confirmed:** HNSW (hnswlib) operational, citation heritage pairs frozen, v17b test infrastructure ready, monitor auto-evaluation ready.
