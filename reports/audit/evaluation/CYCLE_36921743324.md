## 5. Root Cause Assessment

The failure is **not a defect in the evaluation code**. It is a **fundamental property of the data**:

1. The Swiss Federal Supreme Court (BGer) citation graph has very few intra-citations within the 2000-2014 period.
2. Most citations point from recent decisions (2019-2024) to older precedents, or between recent decisions.
3. The dense embeddings (from legal-distance lane) are only available for 2000-2015 (16 years) in checkpointed form.
4. Evaluating citation heritage on a temporal slice that contains almost no citation pairs is statistically invalid.

**Conclusion:** The "FAILED" result is the **only correct output** given the data constraints.

---

## 6. Recommendations

1. **Do not weaken the minimum-pair threshold** — it protects against spurious AUC claims.
2. **Do not re-run this evaluation** — it will produce the same result until the dense embedding coverage extends to 2019+.
3. **Consider alternative benchmarks** for the 2000-2014/2018 dense subsets (e.g., cluster coherence, temporal stability, cross-language alignment) that don't require citation pairs.
4. **Document this limitation** in the evaluation harness so future cycles don't waste compute on this configuration.
