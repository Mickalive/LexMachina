## 4. Methodology Audit

### 4.1 Synthetic Corpus Generator (`data/synthetic.py`)

**Design:** Generates decisions with known structure:
- 10 legal areas → 50 Jurivoc concepts (5 per area)
- 3 languages (DE/FR/IT), 10% multilingual parallel versions
- Citation graph: 70% same-area, 30% cross-area
- Embeddings: Jurivoc centers + noise (cluster_separation=2.0, noise_level=0.1)
- Text: 70% boilerplate, 30% legal content templates

**Strengths:** Known ground truth enables infrastructure validation. Multilingual parallel versions share docket_number (fixed in Cycle 2).

**Limitations:** 
- Oracle embeddings make neighbor_relevance/hierarchy_coherence tautological
- Cross-language pairs share Jurivoc centers → positive similarity by construction, not alignment
- Same-language different-case pairs have independent noise → near-zero similarity
- This makes multilingual separation **positive for the wrong reason** (language pairs dissimilar because different cases, not because of language)

**Assessment:** Fit for purpose as infrastructure stress test. Correctly bounded in claim ceiling.

### 4.2 Boilerplate Resistance Test (`tests/boilerplate_resistance.py`)

**Cycle 1:** Placeholder returning hardcoded 0.5.

**Cycle 2 Fix:** Implements actual perturbation measurement:
1. Extracts boilerplate terms from corpus (pattern-based + frequency)
2. Builds TF-IDF text embedding function from corpus
3. Injects boilerplate into text, measures cosine similarity change
4. Resistance = 1 - mean(cosine_similarity)

**Issue:** On synthetic data, the test uses TF-IDF embeddings while the main representation is oracle embeddings. The reported resistance score (0.1402) is for TF-IDF, not the oracle embeddings. The results table in Cycle 2 report lists "Boilerplate Resistance: FAILED, Resistance: 0.1402" alongside oracle embedding results for other benchmarks. This is **confusing but documented**.

**Assessment:** Test now functional. Real corpus test (Cycle 3) uses TF-IDF consistently and shows catastrophic failure (0.0113). Honest result.

### 4.3 Multilingual Invariance Test (`tests/multilingual_invariance.py`)

**Design:** Finds parallel versions via docket_number, computes cross-language similarity vs same-language different-case control.

**Cycle 1:** Only 1 multilingual docket found (docket_number missing from ground truth).

**Cycle 2 Fix:** Added `docket_number` to ground truth metadata. Now 50 dockets, 150 pairs.

**Synthetic Data Quirk:** Cross-lang pairs share Jurivoc centers → similarity ~0.4. Same-lang different-case pairs have independent noise → similarity ~0.015. Separation = 0.38 > 0.1 threshold, but invariance_score = 0.397 < 0.7 threshold. **FAILED correctly** — synthetic embeddings lack true multilingual alignment.

**Real Corpus (Cycle 3):** TF-IDF cross-lang similarity 0.0268, same-lang 0.2642, separation -0.2374. Language dominates.

**Neural (Cycle 5):** Cross-lang 0.8681, same-lang 0.9236, separation -0.0555. Language dominance reduced but still negative.

**Assessment:** Test correctly discriminates. Synthetic quirk is a known limitation of the generator, not the test.

### 4.4 Corpus Stability Test (`tests/stability.py`)

**Design:** Retrains/recomputes embeddings on growing corpus subsets, tracks anchor decision position drift.

**Synthetic (Cycles 1–2):** Static oracle embeddings → drift ~0. **PASSED** (tautological).

**TF-IDF (Cycle 3):** Retrained on growing subsets → drift 0.8733. **FAILED** as expected.

**Neural (Cycle 5):** Pre-computed static embeddings → drift ~0. **PASSED**.

**Assessment:** Test correctly distinguishes static vs retrained representations. The pass/fail threshold (drift < 0.3) is reasonable.

### 4.5 Hierarchy Coherence Test (`tests/hierarchy_coherence.py`)

**Design:** Agglomerative clustering (cosine/average) at multiple resolutions, evaluates Jurivoc purity and NMI, checks hierarchy consistency.

**Synthetic (Cycles 1–2):** Oracle embeddings built from Jurivoc centers → purity 0.51, NMI 0.82, consistency 1.0. **PASSED** (tautological).

**TF-IDF (Cycle 3/4):** Low NMI (0.028–0.049), moderate purity (0.42–0.70). **FAILED** — language dominates.

**Neural (Cycle 5, repaired):** NMI 0.067, purity 0.83. **FAILED** on NMI (>0.3 required), PASSED on purity (>0.7).

**Assessment:** Test discriminates correctly. Cycle 5 repair fixed label mismatch (branch vs legal_area), making NMI comparable to TF-IDF.

### 4.6 New Benchmarks (Cycle 4)

**Citation Proximity:** Tests shared cited precedents → AUC 0.6354 (TF-IDF), 0.5004 (Neural). Both FAIL (>0.7 required). Neural loses to TF-IDF — citation heritage not captured by general multilingual embeddings.

**Legal-Area Clustering:** Tests branch recovery → NMI 0.0487 (TF-IDF), 0.0572 (Neural). Both FAIL (>0.3 required). Neural slightly better NMI, much better purity (0.88 vs 0.70).

**Assessment:** Both benchmarks are functional, discriminating, and ready for legal-distance lane targeting.
