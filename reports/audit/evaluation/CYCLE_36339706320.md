## Sub-Question 2: Citation Heritage Benchmark at 174k

### Critical Finding: Methodology Discrepancy

Two citation heritage evaluations exist with **materially different results**:

**Evaluation A (2,040 pair pool, reported in cycle report):**
- AUC range: 0.48–0.90 across representations
- Some PASS AUC ≥ 0.65, all FAIL recall@10 ≥ 0.2

**Evaluation B (137,314 pair pool, HNSW k=20, full corpus, reported in state/evaluation.json):**
- AUC range: 0.4999–0.5340 (near random, AUC=0.5)
- Positive recall@20: 0.00–0.07
- **ALL representations FAIL**

### Audit Analysis

The state/evaluation.json (updated in this commit) reports Evaluation B as the current finding: *"NEGATIVE FINDING: Citation heritage AUC ~0.50-0.53 for ALL 8 TF-IDF representations at 174k scale using HNSW k=20 on full corpus with frozen 137k pair pool. Near random (AUC=0.5). Previous AUC 0.66-0.90 was from different methodology."*

**This transparency is correct and commendable.** The evaluation does not hide the discrepancy; it explicitly flags the methodology difference and the negative result at production scale.

**Root Cause:** The 2,040 pair pool (1,020 positive + 1,020 negative, balanced sampling) evaluates a different regime than the 137k pair pool with HNSW on full 174k corpus. At production scale with approximate NN, TF-IDF does not encode citation structure in nearest neighbors above chance.

**No defect in evaluation methodology.** The newer, more rigorous evaluation (full corpus, HNSW, larger pair pool) supersedes the earlier one. The cycle report should be updated to reflect this, but the state file already does.
