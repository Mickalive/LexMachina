## Methodological Critique: Real Boilerplate Resistance Benchmark

The `run_boilerplate_resistance_real.py` introduces a valuable **real text perturbation test** that goes beyond the harness proxy (chamber/legal_area). Key observations:

**Strengths:**
- Uses actual full_text from expanded 1200-decision slice
- Removes procedural boilerplate via pattern matching (headers, footers, standard phrases, article citations)
- Measures neighbor preservation (full vs clean) — direct test of whether boilerplate drives neighbors
- Reports mean reduction ~5.9% — plausible for Swiss court decisions

**Limitations (Acknowledged in Code):**
- Section extraction not implemented — uses full text for all signal configs rather than isolating sachverhalt/erwaegungen/outcome
- Pattern-based boilerplate removal is approximate (regex-based, multilingual)
- Neighbor preservation ~0.93 means neighbors are STABLE when boilerplate removed — suggests boilerplate is NOT the primary driver (language is)
- Language dominance proxy shows 100% boilerplate_dominated_rate — confirms language, not procedure, drives neighbors

**Interpretation:** The real test CONFIRMS the harness proxy finding but refines the diagnosis: neighbors are language-dominated, not boilerplate-dominated. This is a more precise negative result.
