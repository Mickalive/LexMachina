### 1.4 Benchmark Non-Determinism — FIXED and VERIFIED

**Issue Identified:** Stratified subsampling used `groups.items()` iteration order, sensitive to metadata JSON insertion order. Control plane mount updated `metadata_174k.json` at 2026-10-08T23:40, causing different stratified subsamples from identical embeddings/config/seed.

**Fix Applied:** Sort group keys by `(branch, language)` before sampling in `create_stratified_subsample()`.

**Files Fixed:**
- `evaluation/verify_frozen_baseline.py`
- `evaluation/run_174k_tfidf_formal_suite.py`
- `evaluation/verify_frozen_baseline_37399175524.py`

**Verification:** 3 consecutive runs (2026-10-10T00:39:30, 00:39:37, 00:39:43) produce **IDENTICAL** results:
- 6/8 PASS
- Production baseline JP=0.5925, LangDom=0.3481
- All per-representation metrics identical to 4 decimal places

**Cross-Environment Discrepancy Documented:**
- Environment A (numpy 2.5.3, sklearn 1.9.1): 6/8 PASS, JP=0.5925
- Environment B (older numpy/sklearn): 7/8 PASS, JP=0.659
- Root cause: k-NN tie-breaking behavior differences across library versions
- **Production baseline PASSES both gates in ALL verified environments** (JP > 0.5, LangDom < 0.85)
