## 3. Critical Findings

### 3.1 Boilerplate Confounding — Benchmark Threshold Too Weak (HIGH SEVERITY)

**Finding**: The `boilerplate_resistance_real_corpus` benchmark uses threshold `corr > 0.1`, which is **trivially easy** and permits representations dominated by boilerplate text to PASS.

**Evidence**:
- `full_text_tfidf_light`: text_emb_correlation = **0.914** (PASS) — near-perfect correlation with raw text overlap
- `regeste_full_text_hybrid_0.5`: text_emb_correlation = **0.790** (PASS)
- `regeste_full_text_hybrid_0.7`: text_emb_correlation = **0.602** (PASS)
- These same representations **FAIL** `adversarial_falsification` with `language_dominance_mean ≈ 0.998-0.999` (threshold 0.85)

**Assessment**: The boilerplate benchmark threshold (0.1) is **two orders of magnitude too permissive**. A correlation of 0.914 indicates the embedding is essentially a text-similarity proxy, not a legal-semantic representation. The adversarial benchmark correctly catches this, but the boilerplate benchmark gives false confidence.

**Recommendation**: Raise threshold to `corr < 0.1` (invert: PASS if correlation is LOW) or remove this benchmark as currently designed.

### 3.2 Structural Benchmarks Systematically Fail (MEDIUM SEVERITY)

**Finding**: `hierarchy_coherence` (purity > 0.7, NMI > 0.3) and `legal_area_clustering` (purity > 0.5) **FAIL for ALL 8 representations**.

**Evidence**:
- Best hierarchy purity: 0.465 (full_text_tfidf_light, regeste_full_text_hybrid_*)
- Best legal_area purity: 0.0106 (full_text_tfidf_light), 0.0805 (regeste_tfidf)
- NMI scores: 0.577 (best for hierarchy), 0.599 (best for legal_area)

**Assessment**: This is not a benchmark design flaw — it correctly reveals that **no TF-IDF representation captures legal_area or branch hierarchy structure** at the required level. The thresholds are reasonable; the representations are insufficient.

**Note**: The `zoom_coherence` benchmark (improvement_pct > 0) **PASSES** for full-text hybrids (103% improvement) but this is a low bar — any positive improvement passes.

### 3.3 Citation Heritage vs. Structural Semantics Disconnect (MEDIUM SEVERITY)

**Finding**: Representations with excellent `citation_heritage` AUC (0.96-0.97 for cited_decisions_tfidf and hybrid_0.7) **FAIL** branch_knn, tf_metadata, hierarchy_coherence, and legal_area_clustering.

**Evidence**:
- `cited_decisions_tfidf`: citation_heritage AUC = 0.973 (PASS), but branch_knn@5 = 0.389 (FAIL, threshold 0.633)
- `cited_outcome_hybrid_0.7`: citation_heritage AUC = 0.960 (PASS), but hierarchy purity = 0.128 (FAIL)

**Assessment**: The representations capture **citation graph proximity** but not **legal-semantic structure**. This is a known limitation of citation-based TF-IDF. The benchmark suite correctly exposes this tradeoff.

### 3.4 Temporal Instability of Citation-Based Representations (MEDIUM SEVERITY)

**Finding**: All citation-based representations **FAIL** `temporal_stability` (std > 0.1 threshold).

**Evidence**:
- `cited_decisions_tfidf`: std = 0.182 (split scores: 0.35, 0.82, 0.35, 0.63, 0.45)
- `cited_outcome_hybrid_0.5`: std = 0.175
- `cited_outcome_hybrid_0.7`: std = 0.153
- Only `full_text_tfidf_light` and `regeste_full_text_hybrid_*` PASS (std ≈ 0.0003)

**Assessment**: Citation patterns vary significantly across time periods; full-text representations are more temporally stable. This is a valid finding.

### 3.5 Benchmark Thresholds — Some Trivially Permissive (MEDIUM SEVERITY)

| Benchmark | Threshold | Issue |
|-----------|-----------|-------|
| `zoom_coherence` | improvement_pct > 0 | Any positive improvement passes; no minimum effect size |
| `cross_language_pairs` | separation > 0 | Any positive separation passes; no minimum |
| `collapse_check` | mean_sim < 0.99, std > 0.01 | Extremely permissive; only catches total collapse |
| `boilerplate_resistance` | corr > 0.1 | **Wrong direction** — should be corr < 0.1; passes boilerplate-dominated reps |

**Assessment**: These thresholds appear to be **legacy frozen values** that were never calibrated for 174k scale. They create false PASS signals for weak representations.

### 3.6 Multilingual / Cross-Lingual Benchmarks — Directional Issues

**Finding**: `multilingual_invariance` and `cross_language_pairs` FAIL for full-text representations because `separation` is negative (cross_branch > cross_lang_same_branch).

**Evidence**:
- `full_text_tfidf_light`: separation = -0.227 (cross_lang_same_branch=0.059, cross_branch=0.287)
- This means decisions from **different branches but same language** are more similar than **same branch different language** — language dominates.

**Assessment**: The benchmark correctly identifies language dominance. The FAIL is valid. However, the threshold `separation_min: 0` is binary — a more graded threshold would be more informative.

### 3.7 Boilerplate Benchmark — "Insufficient Pairs" Skip (LOW SEVERITY)

**Finding**: `cited_outcome_hybrid_0.5` SKIPs boilerplate_resistance with note "insufficient pairs".

**Cause**: The benchmark samples 200 random pairs from the corpus, but the citation-hybrid representation may have sparse text coverage for sampled pairs.

**Assessment**: This is a data coverage issue, not a benchmark flaw. The skip is honestly reported.

## 9. Required Fixes (Protocol-Level, Not Execution)

The following are **protocol design issues** that should be addressed in the next protocol version (v26+), not bugs in this run:

1. **Boilerplate threshold**: Change `corr > 0.1` to `corr < 0.1` (PASS if low correlation) OR replace with adversarial-only check.
2. **Zoom coherence**: Require minimum improvement_pct (e.g., > 10%) not just > 0.
3. **Cross-language pairs**: Require minimum separation (e.g., > 0.05) not just > 0.
4. **Collapse check**: Tighten to `mean_sim < 0.5, std > 0.05` for meaningful discrimination.
5. **Document known limitations**: Add explicit notes that hierarchy_coherence and legal_area_clustering are expected to fail for TF-IDF family.
