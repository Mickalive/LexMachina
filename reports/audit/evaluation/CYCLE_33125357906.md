### 4.1 Root Cause of Discrepancy

The verification script tests **different representations on potentially different samples**:
- **Authoritative v2 alternatives**: Tests `center_projected` (from fractal-map) with `citation_blended` as the debiased baseline
- **Verification script**: Tests `center_projected` (from fractal-map) with `debiased_citation_blended` (n_pca=1, alpha=0.7) as baseline

The `debiased_citation_blended` representation was the v1 winner (14/14 benchmarks PASS) but was **not included in v2 alternatives testing**. The verification script reintroduces it, but on a different alignment (1000 vs 999 decisions), yielding different jurist pairwise rates.

### 4.2 Implication

The verification result claiming `center_projected` jurist pairwise **FAIL (0.451)** contradicts the authoritative v2 result **PASS (0.5215)**. Since the verification cannot be reproduced, **the authoritative v2 alternatives results remain the evidence of record**.
