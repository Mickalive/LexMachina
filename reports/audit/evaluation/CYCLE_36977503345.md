## Fix 1: Citation Heritage Threshold Alignment

### Prior Issue
The citation heritage benchmark used threshold `auc_roc > 0.65` which was inconsistent with the documented standard of AUC-ROC ≥ 0.7 for PASS. This caused `regeste_full_text_hybrid_0.7` (AUC=0.6595) to incorrectly PASS.

### Fix Applied
**File:** `/tmp/lex_team/evaluation/run_citation_heritage_174k.py` line 104
- **Before:** `'status': 'PASS' if auc_roc > 0.65 else 'FAIL'`
- **After:** `'status': 'PASS' if auc_roc >= 0.7 else 'FAIL'`

### Independent Verification
Recomputed PASS/FAIL using the corrected threshold (≥ 0.7) against the frozen AUC values from `citation_heritage_174k_tfidf_latest.json`:

| Representation | AUC-ROC | Status (≥0.7) | Prior Status (>0.65) |
|----------------|---------|---------------|---------------------|
| `cited_decisions_tfidf` | 0.7426 | **PASS** | PASS |
| `cited_decisions_tfidf_outcome_hybrid_0.7` | 0.7290 | **PASS** | PASS |
| `cited_decisions_tfidf_outcome_hybrid_0.5` | 0.7163 | **PASS** | PASS |
| `regeste_full_text_hybrid_0.7` | 0.6595 | **FAIL** | PASS (incorrect) |
| `regeste_full_text_hybrid_0.5` | 0.6365 | FAIL | FAIL |
| `outcome_tfidf` | 0.6262 | FAIL | FAIL |
| `full_text_tfidf_light` | 0.6257 | FAIL | FAIL |
| `regeste_tfidf` | 0.5030 | FAIL | FAIL |

**Result:** **3/8 PASS** (citation-based signals only), **5/8 FAIL** (text-based signals). The fix correctly fails `regeste_full_text_hybrid_0.7` at the 0.7 threshold.

### Producer Workspace Verification
The producer workspace's `citation_heritage_174k_tfidf_latest.json` has been updated with corrected `status` fields matching the above recomputation. All 8 representations show accurate PASS/FAIL status.

### State File Error Identified
The producer workspace `state/evaluation.json` claims: *"4/8 PASS AUC-ROC ≥ 0.7 (citation-based), 4/8 FAIL (text-based)"*

**Actual count is 3/8 PASS**, not 4/8. The three passing representations are all citation-based (`cited_decisions_tfidf` family). This is a minor reporting error in the state file summary but does not affect the benchmark results themselves, which are correct.

## Fix 2: v17b Label Normalization Regimes Clarification

### Prior Issue
Previous reports conflated two distinct v17b normalization experiments at 174k scale, citing Experiment A's large purity ratios (4-10x) without acknowledging Experiment B's different normalization function and results (1.0x-1.67x).

### Fix Applied
**Document:** `/tmp/lex_team/evaluation/reports/v17b_174k_normalization_regimes_clarification.md`

### Independent Verification of Both Experiments

#### Experiment A: `test_v17b_174k_generalization.py`
- **Normalization:** Inline v17b keyword method (~16 coarse categories)
- **Labels:** 213 raw → 111 normalized (1.9x compression)
- **Subsampling:** Stratified by legal_area (15k)
- **Purity ratios (norm/raw):** 4.7x – 10x across all 8 representations
- **NMI change:** Decreases for all representations
- **Generalization:** FAIL — does not replicate v17b 1K (15-25% gain)

#### Experiment B: `run_v17b_174k_tfidf.py` + `legal_area_normalize.py`
- **Normalization:** `legal_area_normalize.py` keyword mapping (different from inline)
- **Labels:** 157 raw → 107 normalized (1.5x compression) — *filtered to decisions with known branch*
- **Subsampling:** Stratified by branch (15k)
- **Purity ratios (norm/raw):** 1.0x – 1.67x
- **NMI change:** Decreases for most metrics
- **Uniform improvement:** FALSE — NMI consistently decreases

### Audit Assessment
The clarification document **accurately characterizes** both experiments with correct metrics, label counts, and normalization functions. The key findings are honestly represented:

1. **Different normalization functions** produce different compression ratios (1.9x vs 1.5x)
2. **Different label populations** (all legal_area vs branch-filtered subset)
3. **Both regimes show NMI decreases** — semantic coherence is not improved by normalization at 174k fine-grained scale
4. **Neither regime generalizes** the v17b 1K finding of 15-25% uniform purity gain

This is a **valid negative result** honestly documented. No overstatement of positive findings.
