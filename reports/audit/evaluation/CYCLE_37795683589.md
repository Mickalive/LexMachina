### 1.2 Adversarial Benchmark Methodology

The adversarial suite tests two threat models (from `evaluation/tests/jurist_usability.py` and `evaluation/tests/cross_language_benchmarks.py`):

1. **Language Dominance** (`adversarial_language_dominance`): Fraction of k=20 nearest neighbors sharing the same language. Threshold: < 0.85 (lower is better). All representations pass.
2. **Jurist Pairwise Preference** (`simulate_pairwise_preference`): For each decision, checks if top-k contains (a) same-branch-different-language neighbor (legally relevant) vs (b) same-language-different-branch neighbor (language artifact). Jurist succeeds if (a) present. Threshold: legal_neighbor_rate > 0.5.

### 1.3 Critical Finding: outcome_tfidf Systematic Failure

The `outcome_tfidf` representation **consistently fails** jurist pairwise preference (legal_neighbor_rate = 0.391, jurist_forced_wrong_rate = 0.516). This is not a flaky result — it is structurally expected because outcome text (e.g., "approved", "dismissed", "partially upheld") is highly formulaic and language-specific, providing minimal legal reasoning signal. The failure is **honestly reported** with FAIL status — this is correct behavior.
