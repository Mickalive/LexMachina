## 3. Information Leakage Analysis

**Claim:** Full-slice evaluation is misleading because SVD fit on full data inflates hybrid performance relative to combinations.

**Verification:** VALID.

- Full-slice: hybrid wins by +0.061 over best combo (ridge)
- CV: combo wins by +0.075 over hybrid
- Difference in gaps: 0.136 (full-slice biases comparison toward hybrid by 0.136 JP)

**Mechanism:** When SVD is fit on all 1200 documents, it captures variance from the full corpus. The hybrid representation (citation + outcome features) benefits more from this full-corpus SVD than the combination representations (which add citation features to cp64). In CV, the SVD is fit on train only (~960 docs), preventing this bias.

**Additional factor:** k-NN neighbors differ between full-slice (1200 docs) and CV test folds (~240 docs). This also contributes to the JP discrepancy but does not affect the validity of the CV comparison (all representations evaluated on same test folds).

**Conclusion:** The 5-fold CV (v15b) is the correct methodology. The full-slice result is correctly identified as misleading and preserved as a negative result.

## 4. Code Quality Issue: Train Hybrid Mismatch

In `run_v15b_combination_vs_hybrid_cv.py` lines 287-290:

```python
hybrid05_train = build_cited_outcome_hybrid(cite_train_raw[:len(train_idx)], np.zeros((len(train_idx), 2)), alpha=0.5)
hybrid05_test = build_cited_outcome_hybrid(cite_test, outcome_test, alpha=0.5)
```

`hybrid05_train` uses `np.zeros` for outcome features instead of actual train-fitted outcome features. This means the TRAIN representation for `linear_hybrid05_concat` is effectively just citation features (the zero outcome features are normalized away).

**Impact assessment:** NOT a methodological defect.

1. No model is trained on these representations (except Ridge, which uses citation+cp64, not the hybrid)
2. Only TEST embeddings are evaluated for adversarial benchmarks
3. The evaluation is valid because test embeddings properly combine citation + outcome features

**Recommendation:** Fix for code clarity in a future cycle. Not blocking.
