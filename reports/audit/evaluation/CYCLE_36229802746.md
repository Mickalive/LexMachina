### 3.3 HNSW Methodological Artifact (Critical Finding)

**Evidence from monitor state and evaluation reports**:
- v3 harness (HNSW on full 174k): All 8 TF-IDF reps show **identical** jurist_pairwise=0.122, lang_dom≈0.606
- Exact k-NN on valid subset (1,199 decisions with known branch): jurist_pairwise=0.73-0.80, varies by representation
- 1200-scale exact k-NN (prior baseline): jurist_pairwise=0.79-0.80

**Root Cause**: HNSW with fixed parameters (M=16, ef_construction=200, ef_search=100, seed=42) produces nearly identical approximate neighbor graphs across different TF-IDF representations at 174k scale. The graph topology is dominated by index structure, not embedding geometry.

**Impact**: 
- Jurist pairwise collapse 0.79→0.12 is an **artifact**, not representation failure
- HNSW benchmarks at 174k are **invalid for adversarial evaluation** (language_dominance, jurist_pairwise)
- Scale benchmarks using HNSW are also affected

**Lane Response**: Correctly identified, documented, and fix specified (exact k-NN for adversarial on valid subset; HNSW only for full-corpus scale benchmarks). Fix NOT yet implemented in harness — correctly flagged as blocker for dense 174k evaluation.

**Assessment**: **Honestly reported critical defect**. No attempt to hide or minimize. This is exemplary negative-result preservation.
