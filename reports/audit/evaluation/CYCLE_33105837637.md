## Critical Findings

### 1. LANGUAGE DOMINANCE = 0.999 (CATASTROPHIC)
The v1 adversarial test used k=10 and threshold 0.85, masking the true extent. The v2 test with k=20 reveals:
- **99.9% of nearest neighbors share the same language**
- **Zero cross-language same-branch neighbors** in top-10 for any decision
- Cross-language retrieval recall = 0.119 (threshold > 0.2)

**Root Cause**: PCA debiasing (n_pca=1) removes only the first principal component. Remaining 767 dimensions still encode language strongly. Citation graph blending (alpha=0.7) doesn't help because the citation graph itself is language-segregated.
