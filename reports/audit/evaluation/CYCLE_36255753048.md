### Assessment: REPRODUCIBILITY VARIATION DETECTED — QUALITATIVELY BENIGN

**Finding**: The exact k-NN on fixed stratified subsample (n=2000, seed=42) produced **non-bit-identical results** across two independent runs. Language dominance increased by ~0.04 for `outcome_tfidf` and `regeste_tfidf`; jurist preference decreased by ~0.03 for `regeste_tfidf`.

**Root Cause**: Floating-point non-determinism in sklearn's brute-force k-NN across environments (BLAS library, hardware, sklearn version). The "fixed stratified subsample" uses seed=42 for sampling, but the k-NN computation itself has no seed and is sensitive to floating-point operation order.

**Impact Assessment**: **ZERO qualitative impact**.
- All 5 citation-based representations still PASS both adversarial gates (lang_dom < 0.85, jurist_pref > 0.5)
- All 3 text-based representations still FAIL both adversarial gates (lang_dom = 1.0, jurist_pref = 0.0)
- Fundamental two-mode tradeoff persists
- Universal 174k failures persist
- No PASS→FAIL or FAIL→PASS transitions

**Recommendation**: For future runs, consider pinning sklearn/numpy/BLAS versions or using a deterministic k-NN implementation if bit-for-bit reproducibility is required. Current variation is acceptable for scientific evaluation (qualitative conclusions stable).
