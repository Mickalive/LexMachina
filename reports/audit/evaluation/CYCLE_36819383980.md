## 3. Attack Surface Analysis

### 3.1 Leakage Checks

- **Stratified subsample for adversarial benchmarks**: Fixed seed (42), n=2000. No leakage — subsample is drawn before evaluation, same across all reps.
- **Citation heritage pair pool**: Frozen 137k pairs, disjoint from training. No leakage.
- **HNSW vs EXACT backend discrepancy**: Adversarial benchmarks correctly use EXACT (sklearn_exact) on subsample. Full-corpus benchmarks use HNSW. This is documented and correct.
- **v17b reference ratios = 0**: The v17b reference run had insufficient sample for fine-grained labels, making "generalization" comparison invalid. This is honestly disclosed.

### 3.2 Benchmark Gaming / Prettiness-as-Quality

- **Cluster coherence PASS at 3yr dense**: High branch purity (0.87–0.90) but language purity 0.995+. The benchmark correctly flags this — "High language purity = language-dominated clusters." Not gaming.
- **Cross-language zero-shot NMI PASS for dense**: Measures language-invariant clustering, not legal equivalence retrieval. The separate cross-language retrieval benchmark (recall@10) correctly FAILS. Not gaming.
- **Citation heritage AUC vs recall**: AUC passes but recall fails. Both reported. Not gaming.

### 3.3 Weak Baselines

- **TF-IDF formal suite**: 8 representations, 12 benchmarks each. Strong baseline coverage.
- **Dense embeddings**: Only 3 center_projected dimensions + raw multilingual-e5. No metric learning, no fine-tuned legal embeddings, no citation role embeddings. This is a known gap (pending from legal-distance).
- **Citation heritage**: Only TF-IDF family tested. Dense/citation-role not yet available.

### 3.4 Unsupported Product Claims

- **Production default**: `cited_decisions_tfidf_outcome_hybrid_0.5` — validated at 174k, passes adversarial gates. **Supported.**
- **Two-map-modes claim**: Citation-based (adversarial + citation_heritage AUC) vs semantic (cross-language + hierarchy). **Supported by evidence** — but both modes have universal FAILs (boilerplate, cross-lang retrieval, hierarchy).
- **Dense embeddings ready for product**: **NOT SUPPORTED** — all FAIL jurist gate.
- **Hierarchy recoverable**: **NOT SUPPORTED** — v18 confirms fundamental limitation at branch level.
- **Label normalization improves TF-IDF**: **NOT SUPPORTED** — negative result honestly reported.
