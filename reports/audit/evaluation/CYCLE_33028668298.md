## 3. Code Inspection

### 3.1 Defect: Clustering Metric Inconsistency (MEDIUM)

**Location:** `run_cycle_6.py` line 341, `bench_legal_area()`:
```python
clustering = AgglomerativeClustering(n_clusters=n_clusters)
```

**Compare with cycle 5** `run_cycle_5.py` line 376:
```python
clustering = AgglomerativeClustering(
    n_clusters=n_clusters, metric="cosine", linkage="average",
)
```

Cycle 5 explicitly sets `metric="cosine"` and `linkage="average"`. Cycle 6 omits both, defaulting to Euclidean distance and Ward linkage (sklearn defaults).

**Impact:** Different distance metrics produce different cluster assignments. The NMI/purity values from cycle 6 are not directly comparable to cycle 5 baselines. However, the cycle 6 results are internally consistent (all representations use the same metric), and the hypothesis test (do section representations pass targets) is valid within cycle 6.

**Severity:** Medium. Does not affect the core finding (section representations pass 2/4 targets on legal area clustering). Does affect cross-cycle comparability of absolute NMI values.

### 3.2 Defect: Citation Graph Benchmark is Degenerate (KNOWN)

**Location:** All 10 representations show `num_positive: 1, num_negative: 0, num_embedded: 2`.

The citation_graph_neighborhood benchmark is mathematically degenerate: AUC-ROC with 1 positive pair and 0 negative pairs is meaningless (defaults to 0.5). The state file correctly identifies this: "Citation graph benchmark is invalid due to data coverage (only 1 positive pair in embeddings)."

**Severity:** Low (already documented as invalid in state). The benchmark target `citation_graph_auc > 0.7` is untestable with current data. The report correctly shows all representations failing this target.

### 3.3 Defect: Section Representations Sample Size (KNOWN)

Section-based representations have 63 embeddings vs 1000 for the baseline. Legal area clustering uses 56 samples (section) vs 100 (baseline). This is a data limitation, not a code defect. The report does not misleadingly compare absolute NMI values across sample sizes.

### 3.4 Missing Branch in Section Representations

Section representations show only 3 branches (sozialversicherungsrecht, strafrecht, zivilrecht). The `oeffentliches_recht` branch has <10 decisions with section embeddings, falling below the `valid_branches` threshold (line 309: `c >= 10`). This means section representations are evaluated on a 3-class problem while the baseline uses 4 classes, making NMI/purity values partially non-comparable.

### 3.5 Identical Results for sachverhalt and combined

`section_sachverhalt` and `section_combined` produce identical benchmark results (NMI=0.4782, purity=0.8571, CP AUC=0.6184). This is because: (a) both use the same metadata file, (b) the legal_area_clustering benchmark samples from the same 63 embeddings with the same random seed (42), (c) the combined representation includes sachverhalt content, and (d) TF-IDF on sachverhalt alone already captures the legal-area signal. This is a valid negative result, not a bug.
