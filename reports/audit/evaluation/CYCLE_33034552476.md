## 4. Methodology Audit

### 4.1 Debiased-Baseline → Citation Graph (Cycle 12)

**Implementation correctness:**
1. PCA debiasing on 768-dim baseline: fit PCA(n_components=2), zero top components, inverse transform, rescale norms — **correct** (lines 261-277 of run_cycle_12.py)
2. PCA projection to 64-dim: PCA(n_components=64) on debiased 768-dim — **correct** (lines 280-283)
3. Citation graph node2vec: random walks (walk_length=20, num_walks=5), co-occurrence matrix, TruncatedSVD — **correct** (lines 300-344)
4. Blending: alpha * debiased_64 + (1-alpha) * graph_embeddings — **correct** (lines 356-361)

**Key insight validated:** Removing 2 PCA components from 768 dims removes ~30.6% of variance spread across 768 dimensions (~0.04% per dimension), while removing 2 components from 64 dims removes ~34% of variance concentrated in 2 dimensions (~17% per dimension). This is mathematically sound and correctly explains why cycle 11 collapsed while cycle 12 did not.

### 4.2 Parameter Sensitivity Grid (Cycle 13)

**Grid design:** n_pca_components ∈ {1, 2, 3, 5} × alpha ∈ {0.3, 0.5, 0.7} = 12 combinations. This is a reasonable grid covering:
- Low debiasing (n=1) to moderate (n=5)
- Low blending (a=0.3) to high (a=0.7)

**Results:** 12/12 pass rate with very low parameter sensitivity:
- AUC range: 0.9058–0.9098 (delta 0.004)
- Language dominance range: 0.630–0.639 (delta 0.009)
- Branch k-NN range: 0.789–0.818 (delta 0.029)

**Assessment:** The grid search is well-designed and the results are genuinely robust. The low sensitivity across the parameter space is a meaningful finding — it means the approach is not fragile.

### 4.3 Cross-Language Benchmark

The negative cross-language gap (-0.043 for debiased_citation_blended) means cross-language pairs are slightly MORE similar than same-language pairs. The report correctly identifies this as unexpected and flags it for investigation. Possible explanation: language debiasing removes language-specific variation that normally differentiates same-language pairs, making cross-language decisions about the same legal topic appear more similar.

**Assessment:** This is an honest negative finding. The report does not over-interpret it.

### 4.4 Adversarial Benchmark — All Representations Falsified
