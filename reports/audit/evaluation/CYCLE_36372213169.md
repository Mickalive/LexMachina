## Issues Identified

### Issue 1: Conflation of Two Adversarial Benchmarks (Reporting Defect)
- **V25 formal suite** uses `adversarial_falsification` with metrics: `language_dominance_mean`, `branch_coherence_mean`
- **Harness v3** uses adversarial benchmark with metrics: `language_dominance_score`, `jurist_preference_rate`
- The monitoring report states "exact reproduction of adversarial results on production default (lang_dom=0.4867, jurist_pref=0.5349)" but the V25 formal suite shows (lang_dom=0.578, branch_coh=0.352) for the same representation.
- **Impact:** Low — the V25 formal suite results are valid and reproducible; the separate harness v3 verification is also valid but for a different benchmark. The report should explicitly distinguish them.

### Issue 2: nn_citation_rate@10 Discrepancy Between Benchmarks (Clarity Defect)
- V25 formal suite (HNSW, full 174k): cited_outcome_hybrid_0.5 → 0.476
- Citation heritage benchmark (exact k-NN, frozen 2,040 pairs): cited_outcome_hybrid_0.5 → 0.053
- The monitoring report cites "nn_citation_rate@10=0.1667 on production default" in the verification note without specifying which benchmark/methodology.
- **Impact:** Low — both numbers are correct for their respective methodologies. Report should label them clearly.

### Issue 3: Production Default Metrics in State Don't Match V25 Formal Suite (Consistency Defect)
- State `summary.production_default_lang_dom: 0.4867`, `production_default_jurist_pref: 0.5349`
- V25 formal suite for same representation: `language_dominance_mean: 0.578`, `branch_coherence_mean: 0.352`
- **Impact:** Low — different benchmarks. State should specify which benchmark the metrics come from.
