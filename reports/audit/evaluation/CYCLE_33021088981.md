## 6. Minor Issues Found

### 6.1 Branch Distribution Labeling (Low Severity)

**Issue:** The cycle 4 report shows branch distribution as `strafrecht: 306, zivilrecht: 311, oeffentliches_recht: 209, sozialversicherungsrecht: 374` which totals 1,200 (full corpus). However, the benchmark only used 400 sampled decisions. The report labels this as `branch_distribution` without clarifying it represents the full corpus, not the sample.

**Impact:** Misleading to readers who might think the benchmark used 1,200 decisions with that distribution. The actual sample had 400 decisions balanced across branches.

**Recommendation:** Clarify in report that branch distribution shows full corpus composition, not the sampled subset.

### 6.2 Target Inconsistency (Low Severity)

**Issue:** The cycle 4 report Section 5 recommends tighter targets (`AUC > 0.85, NMI > 0.5, purity > 0.8`) than the frozen criteria in Section 1 (`AUC > 0.7, NMI > 0.3, purity > 0.7`). The state file uses the frozen criteria.

**Impact:** Minor confusion about which targets apply. The frozen criteria are correct for this cycle; the recommendation targets are aspirational for future legal-distance representations.

**Recommendation:** Explicitly label recommendation targets as "aspirational for legal-distance lane" to distinguish from frozen criteria.
