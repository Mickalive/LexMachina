The `"verdict"` appears to be a legacy field from the formal suite runner. This is **not misleading** since `both_adversarial_pass` is the explicit gate used in state tracking and the cycle report.

The linear hybrids PASS adversarial at 19-year scale (LangDom 0.77, Jurist 0.54) but **have not been evaluated at 174k scale** (concatenation not done). The state correctly reflects this: `linear_hybrids_174k: "PARTIAL_EVIDENCE — CONFIRMED PASS at 19-year/122k scale... await 174k concatenation"`.

**Risk:** The 19-year PASS does not guarantee 174k PASS (the TF-IDF production default has LangDom 0.47 at 174k vs 0.47 at 19-year; linear hybrids may degrade). This is **correctly acknowledged** in the state.

### 4.3 Cross-Language Transfer "PASS" for Dense Embeddings

The `zero_shot_cross_language_transfer` status is "PASS" for center-projected dense (transfer_gap = -0.044, meaning zero-shot > in-domain). This is counterintuitive but reflects the metric definition (transfer_gap = zero_shot_mean_nmi - in_domain_mean_nmi). The low absolute NMI values (~0.25-0.30) indicate poor representation quality regardless. This is **not a false positive**—the status reflects the transfer metric, not absolute quality.
