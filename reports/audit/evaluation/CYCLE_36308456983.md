### 2.2 Citation Pairs: Substantive Change Confirmed

The `citation_pairs_174k.json` was completely rewritten. Both old and new files contain 8,175 lines (same pair count), but **every positive pair differs**. Examples:

| Old (base) | New (cycle 36308456983) |
|------------|-------------------------|
| `["bger_2C_398_2021", "bger_2C_753_2020"]` | `["bger_7B_1169_2024", "bger_7B_1169_2024"]` (self-citation) |
| `["bger_7B_877_2023", "bger_6B_574_2022"]` | `["bger_5A_883_2024", "bger_5A_883_2024"]` (self-citation) |

**Root cause:** The generator (`generate_citation_pairs_optimized.py`) uses random sampling for shared-citation pairs (lines 63-70: `np.random.seed(42)` + `np.random.choice`). The citation graph data may have been rebuilt, or the iteration order over dictionaries changed, causing different random samples despite the fixed seed. This is **expected non-determinism** in the pair generation strategy, not a defect.

**Impact on citation_heritage benchmark:** The benchmark uses these pairs as ground truth. Since the pair set changed, the benchmark metrics (AUC-ROC, nn_citation_rate@10) **would change** if re-run. However, the formal suite results in this commit are **identical to the prior run**, indicating the formal suite was **not re-run against the new pairs** — only the pair file was regenerated.

**Finding:** The formal suite results do not reflect the new citation pairs. This is a **pipeline gap** — the citation pairs are an input to the citation_heritage benchmark, but the formal suite was not re-executed after pair regeneration.

## 5. Critical Findings

### 5.1 Pipeline Gap: Citation Pairs Not Propagated to Formal Suite

**Severity:** MEDIUM  
**Evidence:** 
- `citation_pairs_174k.json` completely rewritten (all pairs differ)
- Formal suite `_suite_summary.json` shows identical `citation_heritage` metrics to prior run (e.g., cited_decisions_tfidf AUC=0.9731036129220959 vs 0.9731036104559242 — difference only in floating-point rounding from identical computation)
- The formal suite was **not re-run** after pair regeneration

**Impact:** The citation_heritage benchmark in the formal suite evaluates against stale pairs. If the new pairs are semantically different (more self-citations, different cross-citations), the AUC-ROC and nn_citation_rate@10 would change.

**Recommendation:** Either (a) re-run formal suite after pair regeneration, or (b) make pair generation deterministic and versioned so formal suite can reference exact pair set.

### 5.2 Systemic Representation Weaknesses (Not Defects — Honest Negative Results)

These are **honestly reported failures**, not audit defects:

1. **Hierarchy coherence fails universally** (max purity 0.47 for full_text hybrids). The legal hierarchy is not recoverable from TF-IDF embeddings at 128-dim.
2. **Legal area clustering fails universally** (max purity 0.018 for full_text, 0.004 for cited_decisions). 167 legal areas too fine-grained for these representations.
3. **Branch k-NN / metadata indexing fails** (max 0.48 accuracy). Branch labels (4 classes) not linearly separable in embedding space.
4. **Temporal instability for citation-based reps** (std 0.15–0.18). Citation patterns drift across time splits.

These negative results are **valuable evidence** — they correctly identify representation limits.

### 5.3 Boilerplate vs. Legal Signal Trade-off

**Full-text representations** (`full_text_tfidf_light`, `regeste_full_text_hybrid_*`) achieve:
- High branch_knn accuracy (0.996–0.999) ✓
- High tf_metadata_human_indexing recall (0.996–0.998) ✓
- High boilerplate resistance correlation (0.60–0.91) ✓
- **BUT** catastrophic adversarial language dominance (0.998–0.999) ✗

**Citation-based representations** (`cited_decisions_tfidf`, hybrids) achieve:
- Strong citation_heritage AUC (0.92–0.97) ✓
- Pass adversarial language dominance (0.53–0.60) ✓
- **BUT** fail boilerplate resistance (corr ≈ -0.0005 to 0.076) ✗
- **BUT** fail branch_knn / hierarchy / legal_area ✗

**No single representation passes all benchmarks.** This is correctly reported.
