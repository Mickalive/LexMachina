## 2. Benchmark Implementation Audit

### 2.1 Cross-Language Benchmarks (`cross_language_benchmarks.py`)
- **Adversarial language dominance**: Measures fraction of k=20 neighbors sharing same language. Threshold 0.85 (lower=better). Implementation correct.
- **Zero-shot transfer**: Trains PCA on one language, applies to another, measures branch NMI. Transfer gap = in_domain - zero_shot. Negative gap = PASS. Implementation correct but NMI values are low (0.13-0.45), suggesting weak cluster structure overall.
- **Language-specific quality**: Computes branch NMI per language after recomputing representation on language subset. Threshold mean NMI > 0.3, std < 0.2. Implementation correct.
- **Cross-language neighbor quality**: Measures `separation = cross_lang_same_branch - cross_branch`. No explicit threshold in code; report treats 0.057 as FAIL. This metric lacks a pre-declared threshold — **minor concern**.

### 2.2 Jurist Usability (`jurist_usability.py`)
- **Pairwise preference**: Simulates jurist choosing between same-branch-diff-lang (legal) vs diff-branch-same-lang (language artifact). Threshold legal_neighbor_rate > 0.5. Result 0.512 — **barely passes**. Threshold appears arbitrary; no statistical significance test.
- **Cluster coherence**: KMeans (n=16), measures branch purity. Threshold > 0.7. Result 0.873 PASS. Implementation correct.
- **Cross-language retrieval**: Recall@10 for same-branch cross-language decisions. Threshold > 0.2. Result 0.156 FAIL. Implementation correct.
- **Zoom task**: SKIPPED — depends on cluster assignments from 1000-decision baseline only. Correctly reported.

### 2.3 Jurivoc Benchmarks (`jurivoc_benchmarks.py`)
- **Descriptor recovery (NMI)**: Clusters embeddings to match descriptor count, computes NMI. Threshold 0.3. L1=0.243 FAIL, L2=0.441 PASS.
- **k-NN purity**: Fraction of k=10 neighbors sharing same descriptor. Threshold 0.4. L1=0.662 PASS, L2=0.498 PASS.
- **Hierarchy alignment**: Same-parent vs different-parent cosine similarity separation. Threshold > 0.05. Result 0.113 PASS.
- **Concern**: Jurivoc labels are **synthetic** (loaded from `jurivoc_labels.jsonl`), not human-annotated. This limits ecological validity but is acknowledged.

### 2.4 Scale Stability (`scale_benchmarks_frozen.py`)
- **Frozen PCA methodology**: Fits PCA (debias + 64-dim) on full 1200 corpus, applies to subsets. This is the **correct production methodology**.
- **Position drift**: Cosine similarity between subset and full positions. Result: 1.000000 at all sizes — **perfect**.
- **Neighbor preservation**: Improves monotonically 14% → 83% as corpus grows. Correct.
- **Cluster stability**: NMI=1.0, ARI=1.0 at all sizes. Correct.
- **No issues found** — this is the strongest result in the suite.

## 4. Threshold and Methodology Concerns

### 4.1 Arbitrary Thresholds
Several thresholds lack justification in the benchmark specifications:
- Jurist pairwise preference: > 0.5 (why not > 0.6 for meaningful preference?)
- Language dominance: < 0.85 (why not < 0.7 for stronger guarantee?)
- Cross-language retrieval: > 0.2 recall@10 (very low bar)
- Jurivoc L1 NMI: > 0.3 (coarse level expected to fail — post-hoc rationalization)

### 4.2 Cross-Language Neighbor Quality Threshold Missing
The `separation` metric (cross_lang_same_branch - cross_branch) has **no threshold** in the benchmark code. The report declares 0.057 as FAIL without a pre-declared threshold — this is **post-hoc judgment**.

### 4.3 Zero-Shot Transfer Status Logic
Code declares PASS if `zero_shot_mean_nmi > 0.2`. Result: 0.278 PASS. But in-domain NMI is only 0.256 — both are very low. The "negative transfer gap" (-0.022) is driven by noise, not meaningful transfer.

### 4.4 Sample Size for Hierarchy Alignment
Hierarchy alignment samples 500 decisions (25308 same-parent pairs, 99442 diff-parent pairs). This is adequate but the sampling is non-deterministic across runs (though seed=42 freezes it).
