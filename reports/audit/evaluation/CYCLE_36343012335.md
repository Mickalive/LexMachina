## Adversarial Attacks on the Work

### Attack 1: HNSW Artifact Masking Representation Differences
**Finding:** **FIXED AND VERIFIED.** The monitor detected that HNSW with fixed parameters (M=16, ef_construction=200, ef_search=100, seed=42) produced nearly identical k-NN graphs across different TF-IDF representations (jurist pairwise ~0.12 for all). The fix — exact k-NN on valid subset (1,199 decisions with known branch) using sklearn — correctly reveals true representation differences (jurist pairwise 0.73–0.80 for citation-based, 0.0 for text-based). **Reproduction verified 2026-09-27T18:49:26Z.** No residual artifact.

### Attack 2: Leakage from Citation Graph into Representations
**Finding:** **NO LEAKAGE.** TF-IDF representations are built from text fields only (cited_decisions, outcome, regeste, full_text). Citation heritage benchmark uses a *separate* frozen pair pool derived from resolved citation graph. The benchmark tests whether citation structure *emerges* in the embedding space — it does not (recall@10 ≈ 0.05). No circularity.

### Attack 3: Benchmark Gaming via Threshold Manipulation
**Finding:** **THRESHOLDS FROZEN.** Frozen harness v3 thresholds unchanged: language_dominance ≤ 0.85, jurist_pairwise ≥ 0.5, cross_lang_recall ≥ 0.2, cluster_coherence ≥ 0.7. Config hash `b51701f5a9c11692` stable across all runs. No threshold relaxation detected.

### Attack 4: Prettiness-as-Quality (Suppressing Negative Results)
**Finding:** **NEGATIVE RESULTS HONESTLY REPORTED.** Universal failures (hierarchy, temporal, boilerplate) explicitly documented as "corpus/label limitations, not representation defects." Citation heritage ALL FAIL reported without spin. v17b differential effect showing text-based degradation reported clearly. No cherry-picking.

### Attack 5: Weak Baselines / Missing Comparisons
**Finding:** **APPROPRIATE BASELINES.** The formal suite compares 8 representations within the TF-IDF family (citation-based vs text-based vs hybrids). The 1200-scale center_projected (which PASS adversarial) is correctly noted as non-comparable due to full-corpus center-projection vs partial. No straw-man baselines.

### Attack 6: Boilerplate Confounding
**Finding:** **MEASURED AND REPORTED.** Boilerplate resistance benchmark explicitly run (resistance_score = legal_neighbor_rate - boilerplate_neighbor_rate). All TF-IDF reps FAIL (scores -0.57 to -0.77). Full-text reps also FAIL. This is a known corpus property (Swiss decisions heavy on procedural boilerplate), correctly attributed.

### Attack 7: Scale Validity — Subsample Representativeness
**Finding:** **STRATIFIED SUBSAMPLE n=2000 VERIFIED.** Adversarial benchmarks use fixed stratified subsample (by language, branch, year) of decisions with known branch labels (1,199 valid). Exact k-NN on this subset produces consistent results. Full-corpus benchmarks (temporal_stability, hierarchy_coherence, cluster_coherence, cross_lang_retrieval_full, boilerplate) use HNSW on 15k-30k subsamples — acknowledged as approximate but directionally consistent.
