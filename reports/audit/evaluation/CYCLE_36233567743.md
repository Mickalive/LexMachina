### Sub-Question 2: Citation Heritage Benchmark ⚠️ DATA DEFECT FOUND

**Configuration**: Frozen 137,314 positive + 137,314 negative pairs (seed=42), 2,019/2,105 citations resolved (95.9%), AUC-ROC threshold ≥ 0.65.

**Reported results match formal evaluation output** for AUC-ROC values. However, **critical data quality defect discovered**:

| File | Positive Pairs | Self-Citations | Self-Citation Rate |
|---|---|---|---|
| `citation_pairs_174k.json` (subsample used for eval) | 1,020 | **174** | **17.1%** |
| `citation_pairs_174k_full.json` (full frozen pool) | 137,314 | **601** | **0.44%** |

**Examples of self-citations** (citing == cited): `bger_2C_1029_2021` → `bger_2C_1029_2021`, `bger_7B_1197_2024` → `bger_7B_1197_2024`, etc.

**Impact**: Self-citations trivially inflate AUC-ROC and nn_citation_rate@10 because a document is always its own nearest neighbor. The subsample file (used for evaluation) has **17% self-citations** — a severe contamination. The full pool has 0.44% which is still problematic for a frozen benchmark.

**Required Fix**: Regenerate citation pairs excluding self-citations; re-freeze pool with new seed; re-run citation_heritage evaluation on clean data. This is a **same-cycle repairable defect**.
