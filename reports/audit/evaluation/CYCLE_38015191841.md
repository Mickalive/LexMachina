## Independent Recomputation & Attack Analysis

### 1. Benchmark Reliability Fix Verification ✅

**Issue**: Stratified subsampling used `groups.items()` iteration order, which was sensitive to metadata JSON insertion order. Control plane mount updated `metadata_174k.json` at 2026-10-08T23:40, changing JSON ordering and causing non-deterministic adversarial gate results (6/8 vs 7/8 PASS with identical embeddings, config hash, and seed=42).

**Fix Applied** (commit e3c4f14d, cycle 37895708796):
```python
# BEFORE: for key, group_indices in groups.items():
# AFTER:  for key in sorted(groups.keys()):
```

**Verification in Cycle 38015191841**: 3 consecutive runs produce **identical results** — confirming the fix works for a given metadata version.
