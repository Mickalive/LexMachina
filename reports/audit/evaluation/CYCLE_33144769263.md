## 2. Benchmark Implementation Audit

### 2.1 Boilerplate Resistance (NEW in v4)
- **Method**: Jaccard word-overlap on full text vs. embedding cosine similarity, 500 random pairs
- **Threshold**: 0.1 < correlation < 0.4 (moderate = legal content captured without boilerplate dominance)
- **center_projected**: correlation=0.1257 → **PASS** — boilerplate resistant while capturing legal content
- **multilingual_e5_small**: correlation=0.7751 → **FAIL** — embeddings track boilerplate word overlap
- **Concern**: Threshold range (0.1-0.4) is **not theoretically justified**; appears heuristic. No statistical significance test on correlation.

### 2.2 Cross-Language Benchmarks
- **Adversarial language dominance**: Fraction of k=20 neighbors sharing same language. Threshold 0.85 (lower=better). Implementation correct.
- **Zero-shot transfer**: Trains PCA on one language, applies to another. Status PASS if `zero_shot_mean_nmi > 0.2`. **multilingual_e5_small: 0.617 PASS** (surprisingly high — note: zero-shot NMI > in-domain NMI, suggesting noise-driven "transfer").
- **Language-specific quality**: Recomputes representation per language, measures branch NMI. Threshold mean NMI > 0.3, std < 0.2. **multilingual_e5_small: mean=0.725 PASS**.
- **Cross-language neighbor quality**: `separation = cross_lang_same_branch - cross_branch`. **No explicit threshold in code** — report declares FAIL for all legal embeddings (separation ≈ -0.02 to -0.10). **Post-hoc judgment** without pre-declared threshold.

### 2.3 Jurist Usability
- **Pairwise preference**: Legal-relevant (same branch, diff lang) vs language-artifact (diff branch, same lang) in top-k. Threshold `legal_neighbor_rate > 0.5`. 
  - center_projected (v3): 0.512 PASS (barely)
  - multilingual_e5_small: 0.003 FAIL
  - paraphrase: 0.058 FAIL
  - xlm_roberta_base: 0.003 FAIL
  - Citation roles: 0.850 PASS — **but misleading**: `both_available=797` indicates **collapsed representation** (all decisions in one cluster)
- **Cluster coherence**: KMeans n=16, branch purity > 0.7 threshold. Legal embeddings PASS (high purity) but language purity also ~1.0 — **language-dominated clusters**.
- **Cross-language retrieval**: Recall@10 for same-branch cross-lang. Threshold > 0.2. All FAIL (0.0003–0.018).
- **Zoom task**: PASS for all — but uses **fixed cluster assignments from 1000-decision baseline**; not recomputed per representation.

### 2.4 Jurivoc Benchmarks
- **Descriptor recovery (NMI)**: Threshold 0.3. 
  - multilingual_e5_small: L1=0.346 PASS, L2=0.502 PASS
  - paraphrase: L1=0.203 FAIL, L2=0.384 PASS
  - xlm_roberta_base: L1=0.088 FAIL, L2=0.269 FAIL
  - Citation roles: **ALL NMI=0.0 FAIL** (degenerate)
- **k-NN purity**: Threshold 0.4. multilingual_e5_small PASS both levels.
- **Hierarchy alignment**: `separation > 0.05`. multilingual_e5_small FAIL (0.0097). xlm_roberta_base FAIL (7.9e-05). Citation roles FAIL (0.0).
- **Concern**: Jurivoc labels are **synthetic** (not human-annotated). Limits ecological validity but acknowledged.

### 2.5 Scale Stability
- **SKIPPED** for all non-center_projected representations (requires 768-dim embeddings for frozen PCA test). Correctly reported.

## 5. Threshold and Methodology Concerns

### 5.1 Arbitrary Thresholds (Unchanged from v3)
- Jurist pairwise preference: > 0.5 (barely meaningful — why not > 0.6?)
- Language dominance: < 0.85 (why not < 0.7 for stronger guarantee?)
- Cross-language retrieval: > 0.2 recall@10 (very low bar)
- Jurivoc L1 NMI: > 0.3 (coarse level expected to fail — post-hoc rationalization)
- Zero-shot transfer: > 0.2 NMI (multilingual_e5_small: 0.617 — but in-domain is 0.602, both low)

The `separation` metric has **no threshold** in benchmark code. All legal embeddings show negative separation (-0.02 to -0.10) — cross-language same-branch neighbors are **closer to cross-branch than to same-branch**. Report declares FAIL without pre-declared threshold.

### 5.4 Zoom Task Not Recomputed Per Representation
Uses fixed cluster assignments from 1000-decision baseline. All representations get identical PASS — **not a valid discriminant**.
