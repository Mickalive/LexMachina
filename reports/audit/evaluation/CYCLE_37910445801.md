| outcome_tfidf | 0.4578 | 0.4232 | -0.0346 | 0.3910 | 0.4325 | +0.0415 |

**Key observations:**
1. All numeric values differ between runs — the evaluation is **not fully deterministic** despite the sorted-group fix
2. `outcome_tfidf` FAILs jurist preference in **both runs** (0.391 and 0.4325) — qualitative conclusion is stable
3. Jurist preference rates vary by up to ~0.10 for some representations (regeste_tfidf: 0.64→0.54)
4. Language dominance is more stable (max Δ ~0.035)

### Root Cause Hypothesis
The stratified subsampling uses `np.random.choice` per group after setting `np.random.seed(42)`. While group iteration order is now sorted, the **consumption of random numbers varies** if group sizes or counts change between metadata versions. Since the metadata file (`metadata_174k.json`) is not versioned in the repo and may be regenerated, this introduces non-determinism.

**This is a known pathology** — the same issue was documented in CYCLE_37908537398 audit where the fix (sorted groups) was applied but did not fully eliminate variance.
