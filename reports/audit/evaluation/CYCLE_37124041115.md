### 3.3 P3: Probe Embedding Equality

**Claim:** For file-identical representations, probe embeddings (10k sample, seed 42) should match within 0.001.

**Result:** **6 WARNINGS** — Probe max abs diffs are LARGE (0.305–1.154) despite file identity.

| File Pair | Probe Max Abs Diff | Note |
|-----------|-------------------|------|
| full_text_tfidf_light ↔ regeste_full_text_hybrid_0.5 | 0.8506 | "file equality not explained by probe embedding equality" |
| full_text_tfidf_light ↔ regeste_full_text_hybrid_0.7 | 1.1541 | "file equality not explained by probe embedding equality" |
| regeste_full_text_hybrid_0.5 ↔ regeste_full_text_hybrid_0.7 | 0.3056 | "file equality not explained by probe embedding equality" |

**Analysis:** The warning note states "measurement provenance must be documented (degenerate-sample copy class)". This is a **known design pattern**: the three representations share embedding files but are evaluated with DIFFERENT benchmark probes/configurations (e.g., different k-values, different clustering objectives). The probe samples different aspects of the same embedding space.

**Verdict:** P3 warnings are **documented expected behavior**, not a failure. The protocol correctly flags this for documentation. The gate does not fail on P3 warnings — only on P1/P2/P4/NC.

| Category | Swaps Tested | Unexpected Passes |
