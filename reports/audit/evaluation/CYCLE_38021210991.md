### 1.4 Adversarial Gate Methodology — NO LEAKAGE DETECTED

The two adversarial gates test orthogonal properties:
- **Language Dominance:** Measures fraction of k-NN sharing same language (threshold < 0.85). Uses only language metadata, not branch/legal labels.
- **Jurist Pairwise Preference:** Simulates jurist choosing between same-branch-diff-lang (legal) vs diff-branch-same-lang (language artifact) neighbors. Uses branch + language metadata only.

No legal relevance labels (ground truth) leak into the embedding computation. The gates are valid adversarial tests of embedding quality.
