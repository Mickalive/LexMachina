### 2.3 Cross-Check: 64-dim vs 768-dim center_projected Discrepancy

The audit **confirms the critical finding** in the v6 report:

| Metric | v3 (64-dim PCA) | v6 (768-dim pre-PCA) | Status |
|--------|-----------------|----------------------|--------|
| Language Dominance | 0.7660 ✅ PASS | 0.7738 ✅ PASS | Consistent |
| Jurist Pairwise | **0.5121 ✅ PASS** | **0.4912 ❌ FAIL** | **MATERIAL REGRESSION** |
| Jurivoc L2 NMI | 0.4409 | 0.4298 | Slight degradation |
| Jurivoc Hierarchy Sep | **0.1128 ✅ PASS** | 0.0956 ❌ FAIL | **REGRESSION** |
| Cluster Coherence (branch NMI) | 0.3725 | 0.3774 | Similar |

**Root Cause:** The v6 adversarial benchmarks (`cross_language`, `jurist_usability`, `jurivoc`) are run on **raw embeddings** (768-dim for center_projected). The `scale_stability` benchmark internally applies **frozen PCA (→64-dim)** before testing. This means:
- Adversarial gates test the **wrong representation** (pre-PCA) vs production (post-PCA)
- The v3 evaluation correctly tested the **64-dim frozen PCA output** which is what fractal-map/product use

**This is a methodological inconsistency in v6, not a data error.** The v6 report correctly identifies it and recommends using the 64-dim version.

## 4. Findings Summary

1. **Negative Result: No signal ablation variant improves on center_projected** — All 12 signal variants fail at least one adversarial gate. This is a valid, reproducible negative finding.

2. **Center_projected 64-dim (v3) is the validated baseline** — Passes both adversarial gates (language_dom=0.766, pairwise=0.512). The 768-dim version tested in v6 fails pairwise (0.491).

5. **Scale stability holds for non-degenerate variants** — All show perfect position drift (cosine=1.0) with frozen PCA; neighbor preservation improves with corpus size as expected.
