## Key Claims — Attack Surface Analysis

### Claim 1: "FULL REPRODUCIBILITY CONFIRMED"
**Status: PARTIALLY TRUE / MISLEADING**

The frozen harness v3 test suite (6 baseline representations) PASSES within tolerance (1e-3). However, the v9 comprehensive results show **reproducibility drift** vs. prior runs:

- `cited_decisions_tfidf_proc_pairs`: Jurist preference drifted from 0.6822 → 0.6889 (Δ=0.0067, exceeds 1e-3 tolerance)
- `cited_decisions_tfidf_proc_pairs`: Language dominance drifted from 0.6107 → 0.6100 (Δ=0.0007, within tolerance)
- Multiple `duration_seconds` values changed (expected, non-deterministic)

**Root Cause:** The "fresh" Proc Pairs computation (recomputed from base cited_decisions_tfidf embeddings each run) introduces variance vs. stale pre-saved embedding. KMeans with n_init=10 in Jurivoc/scale/fractal benchmarks also contributes.

**Verdict:** The claim "FULL REPRODUCIBILITY CONFIRMED" overstates the case. Baseline reproducibility holds; v9 comprehensive drift is documented but not highlighted.

### Claim 2: "Proc Pairs alignment is LOSSLESS"
**Status: EXAGGERATED**

Fresh Proc Pairs computation yields:
- Base cited_decisions_tfidf: LangDom=0.6100, JuristPref=0.6889
- Fresh Proc Pairs: LangDom=0.6100, JuristPref=0.6889 (verification report)
- JSON results: LangDom=0.6107, JuristPref=0.6822 (before diff update)

**Audit Finding:** "Near-lossless" is accurate; "lossless" implies bitwise identity. The ΔJurist=0.0067 and ΔLangDom=0.0007 are small but non-zero. The verification report's claim of exact match uses rounded values (4 decimal places).

## Methodological Concerns

### 1. Adversarial Thresholds May Be Too Permissive
- Language Dominance threshold: 0.85 (allows up to 85% same-language neighbors)
- Jurist Pairwise threshold: 0.5 (bare majority)
- Reference baseline (center_projected_64dim) achieves LangDom=0.766, JuristPref=0.512 — barely passes
- **Risk:** Thresholds set to make baseline pass rather than to ensure quality

### 2. Benchmark Scope Creep
The v9 comprehensive evaluates 14 representations but only 9 are "breakthrough." The 3 citation role hybrids (citing_alpha0.3, following_alpha0.3, criticizing_alpha0.3) are from v7 role_hybrid_evaluation but NOT re-evaluated in v9 comprehensive (commented out in script). The verification report includes them in the "9 breakthrough" count implicitly.

### 3. multilingual-e5-small "PASS" Without Caveat in Summary Table
The adversarial table shows multilingual_e5_small_pretrained as PASS with no caveat. The hierarchy collapse (1→1000 clusters, Jurivoc L0=0.0) is mentioned only in a footnote. A representation with zero legal taxonomic structure should not be presented as "PASS" without prominent qualification.

### 4. Frozen Config Hash Excludes Some Parameters
Config hash (4323f833fa72366a) includes:
- Harness version, seed, thresholds, benchmark parameters
- Source run IDs
- Embedding file hashes (when files exist)

**Missing:** TF-IDF/SVD parameters for cited_decisions_tfidf (max_features=5000, min_df=2, max_df=0.95, ngram_range=[1,2], n_components=128) are NOT frozen in config hash.
