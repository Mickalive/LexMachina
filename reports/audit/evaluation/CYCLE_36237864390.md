## 3. Independent Recomputation & Attack

### 3.1 Citation Heritage Benchmark

**Script Analysis (`run_citation_heritage_174k_embeddings.py`):**

- Loads 174k metadata (173,963 decisions) and citation pairs from frozen pool
- Filters to pairs where both decisions exist in 174k corpus: **1,020 positive / 1,020 negative pairs** (not 137k as implied by "frozen 137k pair pool" — the 137k is the full graph; only 0.1% of corpus participates)
- Samples `min(5000, n_positive)` = 1,020 pairs per class (correctly handles small pool)
- Uses exact cosine distance (1 - dot product) for AUC/AP; builds scalable NN index (HNSW/exact) for recall@k
- **Threshold**: PASS if AUC > 0.6 AND recall@10 > 0.2

**Audit Findings:**
- ✅ All computations reproducible; AUC/recall values match independent spot-check
- ✅ Negative results honestly reported as FAIL (no threshold relaxation)
- ⚠️ **Report discrepancy**: Report states "137k pair pool" and "Sample of 1,020 pairs" — the 137k is the full citation graph size; only 1,020 positive pairs resolve within 174k corpus. This is correctly handled in code but misleadingly described.
- ⚠️ **Threshold stringency**: Recall@10 > 0.2 requires 20% of citing pairs to be mutual top-10 neighbors. With only 174/173,963 decisions (0.1%) in the citation graph, this is extremely strict. The threshold may be unrealistic for sparse citation graphs — but the audit standard is "honest computation against stated threshold," which is met.
- ✅ Negative recall = 0 for most representations at k≤50 indicates good separation (positive pairs closer than random negatives)
