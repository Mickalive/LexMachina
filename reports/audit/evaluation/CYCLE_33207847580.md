- v6 `results/evaluation/v6_signal_ablation/v6_baseline_center_projected_results.json`: `embedding_dim: 768`, pairwise=0.491, lang_dom=0.774

**Attack Finding:** This is a **material, unrepaired discrepancy**. The v3 evaluation used the PCA-reduced 64-dim embeddings (the actual production representation), while v6 evaluated the raw 768-dim pre-PCA embeddings. The fractal-map and product **MUST use the 64-dim frozen PCA version** validated in v3. The v6 evaluation silently swapped the representation under test without flagging this as a protocol deviation.

**Impact:** The "borderline failure" of center_projected in v6 is an artifact of evaluating the wrong dimensionality. The validated baseline (64-dim) passes both gates. The claim that "768-dim center_projected fails jurist pairwise" is technically true but **misleading** if presented as a regression of the validated baseline.

### 3.3 Citation Weights — Degenerate Pass

citation_weights passes both adversarial gates (lang_dom=0.459, pairwise=0.729) but is **structurally degenerate**:
- **Single cluster**: All 1,199 decisions collapse to one cluster (cluster_sizes = [1199])
- **Zero branch NMI**: `branch_nmi = 0.0` — no legal structure captured
- **Jurivoc NMI = 0.0**: Complete failure on legal taxonomy alignment
- **Jurivoc hierarchy separation = 0.0**: No hierarchical signal
- **Branch purity = 0.474**: Near-random branch assignment

**Attack Finding:** The "pass" is a **false positive** caused by the adversarial gates not checking cluster degeneracy. The language dominance gate passes because the degenerate embedding has no language structure either (mean_dom=0.459). The pairwise gate passes because with a single cluster, all neighbors are trivially "both available" and the simulated jurist always succeeds. This variant is **useless for the fractal map** and correctly flagged as degenerate in the report.

## 6. Material Defects Found

### DEFECT-001: Baseline Representation Swap (CRITICAL)
**Location:** `run_v6_signal_ablation_adversarial.py` line 119 (`embeddings_center_projected.npy` vs v3's `embeddings_center_projected_64.npy`)
**Nature:** Silent substitution of the validated 64-dim frozen PCA baseline with unvalidated 768-dim pre-PCA embeddings.
**Impact:** Reported "borderline failure" of center_projected is an artifact; the validated baseline passes both gates.
**Repairable:** Yes — but requires acknowledging the protocol deviation and re-validating the 768-dim version as a NEW baseline, or reverting to 64-dim for all claims.

### DEFECT-002: Missing Degeneracy Gate
**Location:** Adversarial benchmark suite (cross_language_benchmarks.py, jurist_usability.py)
**Nature:** The two adversarial gates do not detect single-cluster degeneracy. citation_weights passes both gates despite being useless.
**Impact:** False positive "pass" for degenerate representation.
**Repairable:** Yes — add cluster count / branch NMI / Jurivoc NMI as mandatory gate prerequisites.

### DEFECT-003: Jurist Pairwise Threshold Sensitivity
**Location:** `jurist_usability.py` line 172 (threshold > 0.5)
**Nature:** The 768-dim center_projected scores 0.491 — a 0.009 gap from passing. This threshold was pre-declared but the borderline result warrants uncertainty quantification.
**Impact:** Binary PASS/FAIL obscures near-threshold performance.
**Repairable:** Report confidence intervals or bootstrap uncertainty (not done).
