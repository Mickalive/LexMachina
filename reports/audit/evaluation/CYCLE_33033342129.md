### 3.5 Prettiness-as-quality

### 3.6 Boilerplate Confounding
**CONCERN (minor):** The `boilerplate_resistance_real_corpus` metric defines `resistance_score = 1.0 - abs(correlation)` between TF-IDF text similarity and embedding similarity. This metric has a degenerate case: the collapsed representation (`citation_blended_debiased`) scores the highest resistance (0.988) because all pairwise embedding similarities are identical (1.0), producing zero correlation with any text metric. The report does not flag this degeneracy.

**Recommendation:** The report should note that resistance scores > 0.95 on representations with near-zero embedding variance are uninformative. A minimum embedding variance threshold should gate the metric.

### 3.7 Unsupported Product Claims
**CLEAN.** Cycle 10 states "citation_blended is the best representation for the product" — supported by evidence (highest AUC, zero dead zones, excellent k-NN). Cycle 11 honestly reports the collapse and recommends alternative combination strategies. No inflated claims.
