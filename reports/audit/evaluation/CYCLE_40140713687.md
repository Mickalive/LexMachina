## 1. Scope of Audit

Per the audit instructions: *"For the query-map MVP, audit the shortest user-visible capability first: does real/cached OpenCaseLaw input produce a source-linked result bundle and clickable map, and are zero-cost/source-validity claims true?"*

The audit targets the **query-map cached-bundle falsification benchmark** (`evaluation/query_map/run_cached_bundle_benchmark.py`), which is the smallest executable vertical slice that answers:
- **Build half:** `bundle_producer.py` — turns cached OpenCaseLaw HTTP envelopes into a `query_result_bundle` (initial + final)
- **Falsify half:** `run_cached_bundle_benchmark.py` — scores bundles with the accepted `harness.py` and two regressed inputs that must be rejected

The benchmark has **three legs**:
1. **leg 1 (producer_baseline):** Build each frozen question's bundle from raw OpenCaseLaw response cache and run accepted harness. Every harness check must pass.
2. **leg 2 (falsification_blanked_counter_evidence):** Strip `counter_evidence` from counter-labelled decisions → `counter_classifications_supported` must go FALSE.
3. **leg 3 (falsification_broken_source_url):** Repoint one decision's `canonical_url` off `mcp.opencaselaw.ch` → `source_urls_valid` must go FALSE.

**Exit codes:**
- 0 = BENCHMARK_VALID_NO_FALSIFICATION
- 1 = BUNDLE_CONTRACT_VIOLATED (leg 1 failed)
- 2 = ENVIRONMENT_OR_VACUOUS (missing cache/spec, or falsification leg did NOT fire)

- **No data leakage:** The frozen spec is opened read-only and re-hashed before/after. The cache is read-only. No training/selection on the frozen questions.
- **No spec drift:** `spec_sha_before == spec_sha_after == FROZEN_SPEC_SHA256` verified.

- The layout is a **deterministic fixture-grade layout** (golden-ratio x, SHA256 y), explicitly disclosed as "NONE - this is a deterministic fixture-grade layout" with `geometry_claim: "NONE"`.
- No "prettier map" claim is made. The harness checks `geometry_preserved_after_enrichment` (structural stability), not aesthetic quality.

### 4.3 Benchmark Gaming
- The benchmark introduces **no new thresholds**. All rules (duplicate, id_match, marker, source_validity) are imported by reference from the frozen spec.
- The two falsification legs are **designed to fail if the checks are vacuous** — they are negative controls that must fire.
- The non-vacuity scaffold (`_ensure_one_counter_label`) is transparent: it injects a candidate label from the top real row's own snippet **only for leg 2**, and records `non_vacuity_label_injected: true`. The zero-yield measurement for leg 1 is reported unchanged.

### 4.4 Weak Baselines
- The baseline is "plain OpenCaseLaw search (baseline, no query-map/counter-authority machinery)" — explicitly the minimal retrieval.
- The counter channel uses a separate query with `norm_tokens`/`limitation_tokens` — a necessary-not-sufficient lexical proxy, disclosed as such.

### 4.5 Unsupported Product Claims
- **No claim** that Product builds this bundle (only that the *lane's producer* does from cached input).
- **No claim** that the map is useful to a jurist.
- **No claim** that counter_uncertainty=0.5 is calibrated (explicitly "fixture-grade constant").
- **No claim** about LABEL_SOUND/GEOMETRY_SOUND bars.
