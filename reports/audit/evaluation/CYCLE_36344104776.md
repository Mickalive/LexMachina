### 3.3 v17b Label Normalization (Claim 3)

**Verification Method:** Inspected `evaluation/results/v17b_174k_tfidf/v17b_174k_tfidf_latest.json`.

**Findings:**
- Raw labels: 214 → Normalized: 164 (23.4% reduction). But wait — the v17b JSON shows `raw_unique_labels: 157`, `normalized_unique_labels: 107`. The verification report says 214→164. **Discrepancy detected.**
- Labels changed: 85,819 decisions (matches).
- Cross-lingual concepts merged: 32 (matches).
- Differential effect:
  - Citation-based reps (cited_decisions_tfidf, outcome_tfidf, hybrids): hierarchy_purity ratio 1.42–1.67x improvement.
  - Text-based reps (full_text_tfidf_light, regeste hybrids): hierarchy_purity ratio 1.0x (no change), hierarchy_nmi ratio 0.70–0.80 (degradation).
  - Best normalized hierarchy_purity = 0.47 (cited_decisions_tfidf) < 0.7 threshold.

**Attack Surface Checked:**
- **Label count discrepancy**: The verification report says "214→164" but the v17b result JSON says "157→107". The 214 figure appears in earlier v17 (not v17b) runs. This is a **reporting inconsistency** but does not affect the *differential effect conclusion* which is computed from the v17b JSON data.
- **Post-hoc subgrouping**: The "citation-based vs text-based" split is a priori (based on embedding construction), not post-hoc.
- **Threshold gaming**: 0.7 hierarchy purity threshold is frozen from prior cycles.
- **Prettiness**: Report leads with "differential effect confirmed" but also states "Even normalized, best hierarchy purity = 0.47 < 0.7 threshold" — honest about ultimate failure.

**Verdict:** **MINOR REPORTING INCONSISTENCY** (label counts), **CORE FINDING VALID**. The differential effect is real and correctly characterized.
