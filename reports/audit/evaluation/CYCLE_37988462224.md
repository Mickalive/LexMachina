### 3.1 Determinism Verification (Attack Target: Non-determinism Claim)

**Claim:** "Sorted groups fix ensures deterministic subsampling regardless of metadata JSON ordering. Results are reproducible within this environment."

**Verification:** The two verification files in the commit are **byte-for-byte identical** (verified via diff). This confirms:
- Same 2000-decision stratified subsample selected in both runs
- Same k-NN results on that subsample
- Same adversarial gate outcomes for all 8 representations

**Attack:** The fix in `verify_frozen_baseline.py` sorts groups by `(branch, language)` key before sampling. This eliminates the metadata-ordering sensitivity that caused prior non-determinism (documented in state/evaluation.json as "metadata-ordering non-determinism: Stratified subsampling sensitive to JSON key order"). The fix is mechanically sound — `sorted(groups.keys())` imposes a total order independent of JSON serialization order.

**Finding:** **CONFIRMED.** Determinism achieved within the current environment (numpy 2.5.3, sklearn 1.9.1).
