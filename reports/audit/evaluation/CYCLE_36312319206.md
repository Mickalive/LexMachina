**Delta**: HNSW drops AUC by **0.25–0.40 points** across all representations vs exact k-NN.

### 2.4 Root Cause Analysis

The HNSW configuration in `scalable_nn.py` uses:
- `HNSW_M = 16`
- `HNSW_EF_CONSTRUCTION = 200`
- `HNSW_EF_SEARCH = 100`

For 173,963 high-dimensional sparse TF-IDF vectors (typically 10k–100k dimensions), `ef_search=100` is **insufficient** for k=20 neighbor recovery. The search explores only ~100 candidates per query, yielding poor recall on sparse vectors where true neighbors may be far in the graph. This is a known HNSW limitation on high-dimensional sparse data.

**Critical Observation**: The report honestly attributes the failure to HNSW approximation, not to the representations themselves. It correctly notes: *"At full 174k scale with HNSW (k=20), the TF-IDF representations do not encode citation structure in their nearest neighbors above chance level"* and recommends using exact k-NN or larger k/ef_search for this benchmark.

✅ **No fabrication**: Results match producer artifacts exactly.
✅ **Honest negative result**: AUC ~0.50 reported as FAIL, not spun as success.

⚠️ **Methodology shift**: The benchmark now measures *HNSW neighbor recovery* not *pairwise similarity AUC* (as in specification.json). The report is transparent about this.

| Aspect | Detail |

**NMI Behavior**: All 8 representations show NMI degradation with normalization (hierarchy_nmi ratios 0.70–0.95, legal_area_nmi ratios 0.79–0.88).

### 3.3 Key Findings (Verified)

1. **Citation-based reps (5/8)**: Consistent 4–10% purity improvement across all three hierarchy-family metrics. Pass frozen uniformity rule.

2. **Text-based reps (3/8)**: Zero hierarchy_purity improvement (ratio=1.00) and **30–34% zoom_fine_purity degradation**. Fail uniformity rule.

3. **NMI vs Purity divergence**: Purity improves but NMI degrades for citation-based reps, suggesting normalized labels create fewer, purer but less informative clusters.

4. **Best normalized hierarchy_purity = 0.554** (cited_decisions_tfidf) — well below the 0.7 threshold from specification.json.

### 3.4 Methodological Soundness

✅ **No data leakage**: Normalization rules fixed, embeddings pre-computed, frozen seed.
✅ **Honest negative result**: 3/8 FAIL uniformity, NMI degrades universally, best purity < 0.7 threshold.
✅ **Reproducible**: Fixed seeds, deterministic sampling.
⚠️ **Approximation stacking**: HNSW → sampling → KMeans introduces compounding approximation variance. However, the *pattern* (citation-based improve, text-based degrade) is consistent and large enough (>30% degradation) to exceed noise floor.
⚠️ **Sampling bias**: 15k/30k samples from 174k may not fully represent tail labels. But stratification by random seed provides consistency.
