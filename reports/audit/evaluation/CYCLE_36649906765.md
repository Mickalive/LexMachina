### 4.2 Minor: Cluster Size Discrepancy in jurist_usability.cluster_coherence_rating
- Some representations show `n_clusters: 16` but `cluster_sizes` array length varies (e.g., outcome_tfidf shows 5 sizes, regeste_full_text_hybrid_0.7 shows 16 sizes)
- **Cause**: KMeans with `n_clusters=16` can produce empty clusters; code in `simulate_cluster_coherence_rating` only appends non-empty clusters to `cluster_purities` and `cluster_sizes`
- **Impact**: None on metrics (mean_purity computed over non-empty clusters only). Cosmetic only.
