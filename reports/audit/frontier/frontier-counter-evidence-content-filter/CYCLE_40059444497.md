**Root cause (concrete, reproducible):** `is_letterhead_zone()` only returns `True` for a
court-header span when `first_offset is not None` (or with extra header conditions). The CLI builds
rows from `decision_id/language/counter_evidence/full_text/snippet/regeste` and never sets
`first_offset`; the committed fixtures do not carry it at row level either. Therefore D2 = 0 in every
end-to-end path, contradicting the headline claim of "all 14 rejected". Supplying a derived offset
(`full_text.find(counter_evidence)`) makes the same code reject 14/14 and reject `PLANT_LETTERHEAD_A`,
which shows the defect is real and narrow — but the shipped run did not do this and instead asserted
success.
