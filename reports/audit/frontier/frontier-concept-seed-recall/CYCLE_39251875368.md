  promote.

it is an acceptance-chain stall: no audit → no promotion → status stays RUN → resilience re-dispatches
→ each resume must emit a durable delta or validation exits 67 → pathology (`39241812486`'s overwrite).

- **REVISE would be the wrong instrument**: there is no same-cycle defect in the producer's work that
  a repair could address without violating the freeze (the only wording nits live in *frozen* RULES
  or in already-committed prose — see advisories). Issuing REVISE would add a sixth spin to the very
  loop this audit is meant to break.
- **BLOCKED would be wrong**: it requires no human/external decision, nothing is data-blocked or
  structurally invalid, and it would leave a complete, verified charter unpromoted with `status: RUN`.
- **PASS is the correct instrument**: it is truthful (all nine acceptance tests verified, §1–§5) and
  it is what breaks the loop — promote → director records the independently accepted OUTCOME_A →
