## Key Technical Observations

### Provider Abstraction (No Owner Cost)
- Three backends: OpenCode CLI (default), OpenAI-compatible local server (`LEX_GENAUDIT_BACKEND=openai`), deterministic fixture
- Model resolution from `state/model_health.json` (4 healthy free models confirmed)
- Fallback across models on failure; total failure returns structured error with per-model attempts

### Citation Constraint Enforcement
- Every generated citation validated against bundle `decision_ids`
- Hallucinated IDs rejected programmatically AND redacted from surfaced prose (`[citation removed: not in retrieved set]`)
- Unicode hyphen normalization handles live model output quirks (observed `CH\u2011001`)

### Adversarial Independence
- Separate `AdversarialPass` object, separate model call, challenge-only prompt
- `CHALLENGING_REASONS = {contradictory, limiting, distinguishing, exception, minority_line, language_branch}`
- `unclassified` findings kept in record but map to `counter_status="none"` (never displayed as challenges)
- Unknown finding IDs rejected and recorded in `rejected_ids`

### Evidence Source-Checking (Audit Repair Fix 3)
- Every `evidence_refs` quote checked verbatim (NFKC + hyphen-fold + whitespace-collapse + casefold) against cited decision's retrieved text
- Unverifiable quotes rejected before reaching `counter_evidence`; finding downgraded to uncertainty ≥ 0.95 but kept visible
- Boundary filter in `apply_to_product_bundle` provides defense-in-depth

### Live OpenCaseLaw Attestation
- Documented host `https://mcp.opencaselaw.ch/api` reachable from CI
- Routes verified: `GET /decisions/{id}`, `GET /integrity/{id}`, `POST /attest`, `POST /verify-claim`
- Sound verdict predicates: never `bool(payload)`; positive evidence keys required
- Opt-in via `LEX_OCL_ATTEST=1` / `run_e2e.py --attestation` so deterministic suite stays network-free

### Product Integration
- Input: product `query_result_bundle` v1.0 dict
- Output: new dict with `answer` replaced, `counter_status`/`counter_evidence`/`counter_uncertainty` on decisions, `provenance.generative_audit` block
- Guarantees: cited IDs ⊆ bundle IDs; counter-authorities discoverable (cited+limiting stays `candidate-limiting`); JSON-serializable; passes product validator
