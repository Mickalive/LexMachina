## Key Technical Achievements

### Provider Abstraction (Zero Owner Cost)
- **OpenCode CLI**: Uses free models from `state/model_health.json` (nemotron-3-ultra-free, mimo-v2.6-flash-free, etc.)
- **OpenAI-compatible local**: Any Ollama/LM Studio/vLLM endpoint via `LEX_OPENAI_BASE_URL`
- **Deterministic fixture**: Offline, repeatable, used by frozen test suite
- **Fallback logic**: Automatically tries next healthy model on backend failure

### Citation Integrity (Programmatic Enforcement)
- Every generated citation must exist in the retrieved `DecisionBundle`
- Hallucinated IDs are: (a) rejected from the cited set, (b) recorded in validation report, (c) redacted from surfaced prose with `[citation removed: not in retrieved set]`
- Handles live-model citation styles: `[ID]`, `(ID)`, nested `([ID])`, unicode hyphens (CH‑001 vs CH-001)

### Adversarial Independence (Structural, Not Rhetorical)
- Separate model call with separate prompt — never sees first-pass chain of thought
- Objective: **challenges only** (contradictory, limiting, distinguishing, exception, minority_line, language_branch)
- Unclassified findings preserved in record but map to `counter_status="none"` (never displayed as challenges)
- Unknown decision IDs in findings are rejected and recorded

### Evidence Boundary (Audit Repair Cycle 38181577763)
- Every adversarial `evidence_refs` quote checked verbatim against cited decision's retrieved text (NFKC + hyphen-fold + whitespace-collapse + casefold)
- Fabricated quotes **rejected before reaching `counter_evidence`**; finding uncertainty raised to ≥0.95
- Finding stays visible (product must never hide a possible counter-authority)
- Optional live OpenCaseLaw `audit_quotes` hook — never upgrades below offline floor

### OpenCaseLaw Attestation (Corrected & Sound)
- Live host: `https://mcp.opencaselaw.ch/api` (reachable from CI; documented OpenAPI spec)
- Retired wrong host: `https://opencaselaw.org/api` (TLS fails, not an API host)
- Sound verdict logic: HTTP 200 + JSON object + positive evidence keys + **ID echo match** = verified
- `200 {"error": "Provide draft_text to audit."}` → **unverified** (regression-tested)
- Empty/non-object/mismatched/non-2xx → unverified
- Opt-in via `LEX_OCL_ATTEST=1`; offline default for deterministic suite
