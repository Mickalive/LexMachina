introduced: `loader.py` hard-codes `/tmp/lex_accepted/core/{product,evaluation}`, so the
accepted, already-`PASS`ed `python -m frontier_query_concept_recall.cli` and
`python -m frontier_query_concept_recall.regression_suite` fail identically here. The charter's
own dependency line anticipates the absent mount ("otherwise fetch `origin lab/product` at tip
`453a873f`"); no code implements that fallback.

What *is* new is the **handling**. `run_harness.py` carefully reasons about loud failure for
the empty-cache case (an explicit `ABORT_MESSAGE`, exit 2) and `closure.py` implements an
`ENUM_SHALLOW_HISTORY` path for shallow history — but neither handles a missing *input bundle*.
`closure.py` therefore crashes in C4 **after** C1 and C3 have already been computed, discarding
them and emitting no record at all. That is a real gap against the team's own stated philosophy.
