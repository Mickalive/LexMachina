## Technical Architecture Review

### Strengths

1. **Clean separation of concerns**: Transport (HTTP/cached/fixture/scripted) → Client (typed endpoints) → Pipeline (stages) → Bundle (assembly/validation/bridge)
2. **Provenance-first design**: Every candidate carries `provenance` string + `provenance_events[]`; bundle provenance includes `searches[]`, `stage_notes`, `failures[]`, `degraded` flag
3. **Deterministic by construction**: Content-addressed cache keys (SHA-256 of canonical path+params), union-find dedupe with fixed sort keys, seeded variant IDs
4. **Rate-limit compliance**: `RateLimiter` (min-interval) + `RequestBudget` (hard cap) enforced at transport and client layers; `AdapterConfig` rejects `max_rps > 5.0`
5. **Graceful degradation**: Stage failures recorded in `provenance.failures`, bundle marked `degraded=true`, remaining stages continue; never raises on partial failure
6. **Zero third-party deps**: Stdlib only (`urllib`, `hashlib`, `json`, `dataclasses`, `unittest`)
7. **Product-ready bridge**: `to_product_bundle()` emits exact `REQUIRED_TOP` / `REQUIRED_DECISION` keys from accepted `product/query/bundle.py` with `pending_downstream` placeholders

### Risk Areas (None Blocking)

- **OpenCaseLaw API stability**: Adapter depends on public REST surface (`/decisions`, `/decisions/{id}`, `/structure/{id}`, `/citations/{id}`, `/leading-cases`, `/regeste/{id}`). Charter stop-promote rule correctly triggers TERMINATE if these become unavailable.
- **Citation confidence threshold**: Default `0.3` is reasonable but may need tuning per domain; exposed in config.
- **Language coverage**: Fixtures show `?` language for ~10% of candidates (server returns no language); adapter preserves `None` rather than guessing.
