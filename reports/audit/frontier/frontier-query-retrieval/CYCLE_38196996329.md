## Key Architectural Strengths

1. **No legacy baggage** — Does not rebuild the 174k corpus. Thin adapter over OpenCaseLaw's public REST API.
2. **Provenance-first** — Every candidate carries `provenance` string + `provenance_events` array with channel, endpoint, variant, page, score.
3. **Deterministic by design** — Union-find dedupe with sorted-group emission; content-addressed cache keys (SHA-256 of canonicalized path+params); fixed lexicon expansion.
4. **Graceful degradation** — Stage failures recorded in `provenance.failures`, bundle marked `degraded`, never crashes.
5. **Scope-safe** — CLI `--out`/`--product-bundle` constrained to team namespace; `verify_scope_safe.sh` enforces this from any working directory.
6. **Evidence freshness** — `run_live_evidence.py` requires `LEX_FRONTIER_RUN_ID` and fails `A0_fresh_live_network` on zero-network replays unless `LEX_ALLOW_CACHE_REPLAY=1`.
7. **Product bridge** — `to_product_bundle()` emits lossless bridge to accepted `product/query/bundle.py` contract with explicit `None`/`"unclassified"` placeholders for downstream-owned fields.

## Claim Ceiling

The adapter **honestly delivers** what the charter promises:
- Deterministic, provenance-preserving candidate bundles from OpenCaseLaw
- 100–300 decisions with multilingual expansion, citation/leading neighbourhoods
- Lazy hydration, offline fixtures, rate-limit compliance
- Product-ready bridge contract

It **does not** (and does not claim to):
- Generate answers, clusters, relations, or visual maps (explicitly `pending_downstream`)
- Translate queries (uses server-side language filters + accepted lexicon only)
- Replace evaluation benchmarks (fixtures frozen for eval consumption)

## Recommendation

**PROMOTE** to core product per charter `stop_promote_rule`. The adapter is integration-ready. Product should:
1. Import via `sys.path.insert(0, "frontier/frontier-query-retrieval")` → `from ocl_adapter import build_candidate_bundle, to_product_bundle`
2. Call `build_candidate_bundle(query, config=AdapterConfig(mode="live", target=150), hydrate_top=2)`
3. Transform via `to_product_bundle()` and fill `answer`/`clusters`/`relations` upstream

No further Frontier cycles required for retrieval. Evaluation may now freeze fixtures and benchmark against `LIVE_EVIDENCE.json`.
