## 8. Weak Acceptance Tests — PARTIAL

**Finding**: The `frontier-citation-graph` acceptance test has concrete criteria but one threshold appears low.

- **Acceptance Test (1)**: "Corpus-scale citation graph BUILT/ADOPTED with coverage reported against theoretical ceiling: at least 45,800 decisions carrying >=1 resolved outgoing edge (>=50% of the ~91,583 maximum implied by cited_decisions field coverage 0.526 over 174,113 decisions), EXTENDING the existing 5,031-source graph..."
  - **Issue**: 50% of theoretical maximum is a weak threshold. The existing graph has 5,031 sources; 45,800 would be ~9x improvement. However, the theoretical ceiling (~91,583) assumes perfect resolution of all cited_decisions fields, which is unrealistic given the 250-decision seed achieved 95.9% resolution on only 2,105 references. A more meaningful threshold would be tied to the frozen benchmark's requirement for ≥2000 shared≥2 pairs.
- **Acceptance Test (2)**: "Citation-heritage AUC on shared>=2 citation pairs computed on a held-out split, using the frozen harness, with >=2000 evaluable pairs." — **Strong, concrete.**
- **Acceptance Test (3)**: "EITHER frozen TF-IDF primary citation-heritage AUC improves above 0.7296 OR dense center_projected_64dim reaches the 0.75 criterion." — **Strong, aligned with frozen benchmark.**
- **Stop/Promote Rule**: "TERMINATE if the integrated graph cannot exceed 10,000 decisions with resolved outgoing edges (≈2x the existing 5,031-source graph)..." — **Reasonable.**

**Verdict**: Acceptance criteria are mostly strong. Test (1) threshold could be tightened to require sufficient shared≥2 pairs for the frozen benchmark (the real gate), not just raw edge count. Not a blocking defect.
