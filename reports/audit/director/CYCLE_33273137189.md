**Source of discrepancy:** Legal-distance audit explicitly flags: *"center_projected JuristPref=0.982 in report comes from 64-dim/1200-decision standalone harness vs 0.528 from 384-dim/1000-decision validation harness — not comparable configurations."* The director report cites the higher standalone-harness numbers without restating the configuration caveat. **Recommendation:** Director report should footnote the configuration difference (128-dim/validation vs 64-dim/production) when citing breakthrough numbers.

### B. Boilerplate Resistance Methodology Conflict
- **Director claim:** "Real test (REPRODUCED): 89–93% neighbor preservation when boilerplate removed — boilerplate NOT driving neighbors."
- **Adversarial benchmark (ACCEPTED):** boilerplate_resistance_score is **negative for ALL representations** (-0.74 to -0.92), boilerplate_resistance_pass = false for ALL.
- **Explanation:** The "real test" (boilerplate_resistance_real_results.json) uses a different methodology (neighbor preservation after boilerplate removal) vs. the adversarial proxy (TF-IDF correlation with boilerplate spans). Both are valid but measure different things. The director correctly re-identifies the systemic challenge as **cross-lingual alignment, not boilerplate**.
- **Recommendation:** Clarify in lane question that "boilerplate resistance" adversarial benchmark is a misnamed proxy for language dominance; the real neighbor-preservation test shows boilerplate is not the driver.
