## Changes in This Cycle

### 1. User Corpus Import with Map Position Computation (`navigation.py`)

**New Methods:**
- `_load_base_embeddings()` — Loads baseline embeddings (`embeddings.npy`) and metadata from fractal-map lane; initializes `sentence-transformers/paraphrase-multilingual-mpnet-base-v2` model
- `_load_imported_positions()` — Reads persisted positions from `user_imports/imported_positions.jsonl`
- `_save_imported_position()` — Appends position records to JSONL file
- `_compute_import_positions()` — k-NN placement for imported decisions:
  - Computes embeddings for new decisions using same model as base corpus
  - Finds k=5 nearest neighbors via cosine similarity in normalized embedding space
  - Assigns to majority cluster of neighbors
  - Positions at centroid of neighbor positions + Gaussian jitter (σ=0.01)
  - Persists record with `assigned_via: "knn_embedding"`

**Modified `import_corpus()`:**
- After successful corpus import, calls `_compute_import_positions()` for `debiased_citation_blended` at zoom level 1
- Returns `map_positions_computed` count and `default_representation` in result

### 2. Map Export Functionality (`navigation.py`)

- `export_map_data(representation, zoom_level, format, include_metadata)` — Exports all positions + cluster summaries as JSON or CSV
- `export_cluster_decisions(representation, zoom_level, cluster_id, format)` — Exports decisions in a specific cluster as JSON or CSV

### 3. API Endpoints (`server.py`)

- `GET /api/map/export` — Map export with `representation`, `zoom`, `format`, `include_metadata` params
- `GET /api/cluster/export` — Cluster export with `representation`, `zoom`, `cluster_id`, `format` params
- `POST /api/import` — Already existed; now triggers map position computation

### 4. Frontend UI (`static/index.html`)

- New "Export Map" section with JSON/CSV buttons
- New "Export Selected Cluster" section with JSON/CSV buttons
- JavaScript download handlers with status feedback

## Concerns & Tradeoffs (Non-Blocking)

| Issue | Severity | Details |
|-------|----------|---------|
| **Heavy model dependency** | Medium | `sentence-transformers/paraphrase-multilingual-mpnet-base-v2` (~1GB) downloads on first `_load_base_embeddings()` call. Adds cold-start latency and disk usage. |
| **Non-deterministic jitter** | Low | `np.random.normal(0, 0.01)` makes import positions non-reproducible across runs. Acceptable for visualization; problematic if positions used for deterministic downstream logic. |
| **Silent embedding load failure** | Medium | `_load_base_embeddings()` catches all exceptions and sets embeddings to `None`. Import positions silently become no-op if embeddings missing. Could mask configuration issues. |
| **Hardcoded parameters** | Low | k=5, jitter_scale=0.01, representation=debiased_citation_blended, zoom=1 are hardcoded. Limits flexibility for other representations/zoom levels. |
| **Baseline embeddings dependency** | Medium | Requires `baseline/embeddings.npy` from fractal-map lane. If missing, import positions disabled without error. |
| **No text quality validation** | Low | Uses `full_text` or `title + legal_area`; short/empty text yields poor embeddings and random-ish placement. |
| **Memory footprint** | Medium | Loads full embedding model + 1000×768 base embeddings (~6MB) in memory. Acceptable for current scale; may need optimization for larger corpora. |

**Assessment:** These are documented design tradeoffs, not defects. The core claim — "user corpus import with map position computation" — is delivered and tested. Future cycles could add configurability, deterministic seeding, and better error signaling.
