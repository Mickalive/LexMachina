## 3. Technical Analysis

### 3.1 NavigationAPI — Vectorized LOD & Culling Pipeline (`navigation.py`)

**Key Improvements**:

1. **Vectorized Position Array Construction** (lines 2108–2130):
   - Replaced per-item loop with list comprehensions → `np.array()`
   - Handles empty positions gracefully
   - Extracts `decision_ids`, `cluster_ids`, `has_section`, `languages` in vectorized fashion

2. **Vectorized LOD Color Assignment** (lines 2165–2200):
   - **Before**: O(lod_n × n_clusters) nested Python loop computing distances
   - **After**: `np.argmin(dists_sq, axis=1)` with broadcasting — `(lod_n, n_clusters)` distance matrix in single operation
   - Pre-computes `LOD_COLOR_PALETTE` as `(N_COLORS, 4)` float32 array
   - Vectorized radius: `np.clip(np.sqrt(lod_sizes) * 2, 3.0, 20.0)`

3. **Frustum Planes for GPU-Side Culling** (lines 2222–2235, 2458–2475):
   - Computes 4 world-space planes from viewport bbox: `ax + by + c >= 0`
   - Returns `frustum_planes` and `viewport_bbox` in WebGL response
   - Enables GPU vertex shader to discard out-of-viewport points before rasterization

4. **Vectorized Viewport Culling** (lines 2320–2350):
   - **Before**: Python list comprehension with set membership `did in visible_set`
   - **After**: `np.isin(decision_ids_arr, visible_arr)` — single vectorized operation
   - Boolean mask extraction for `decision_ids_v`, `languages_v` via `np.array(...)[mask].tolist()`

5. **Vectorized Color/Radius Assembly** (lines 2360–2410):
   - `cid_to_color_idx` array for O(1) cluster→color lookup
   - `COLOR_PALETTE[color_indices].ravel()` for bulk RGBA expansion
   - `np.where(has_section_v, 4.0, 2.5)` for radii
   - `np.isin(decision_ids_v_arr, imported_id_arr)` for imported flags

**Correctness**: All vectorized paths produce identical output to baseline (verified by new tests). Edge cases handled: empty positions, empty clusters, missing bbox.

### 3.2 WebGLRenderer — GPU Frustum Culling & Vectorized Prep (`webgl_renderer.py`)

**Vertex Shader Additions**:
- `u_frustum_culling` boolean uniform
- `u_viewport_min`, `u_viewport_max` vec2 uniforms (alternative to frustum planes)
- `u_lod_level` float uniform for LOD-aware radius scaling
- `u_point_size_min`, `u_point_size_max` for clamping
- **Frustum culling logic**: Discards vertex early (`gl_Position = vec4(2.0, 2.0, 0.0, 1.0)`) if outside planes

**Fragment Shader Improvements**:
- Anti-aliased circle rendering using `smoothstep` on `edgeDist = 0.5 - dist`
- Proper `discard` for transparent fragments (enables point picking)
- Diamond shape for imported points preserved

**Vectorized Python Prep Function** (`prepare_point_data_vectorized`):
- Single-pass extraction of `xs, ys, cluster_ids, has_section, decision_ids` into numpy arrays
- `positions_array[0::2] = xs`, `positions_array[1::2] = ys` — no Python loop
- Pre-parsed `parsed_colors` (N_COLORS × 4) → expanded via `color_indices` fancy indexing
- `np.where(has_section, 4.0, 2.5)` for radii
- List comprehension for imported flags (set membership not easily vectorized for object dtype)

**Equivalence Guarantee**: New test `test_vectorized_vs_baseline_equivalence` asserts `np.testing.assert_array_equal` on all output arrays.

### 3.3 Frontend — GPU Frustum Integration (`static/index.html`)

- Adds `u_frustum_culling`, `u_frustum_planes[4]` uniform locations to cache
- Passes `frustumPlanes` from server response to `renderPoints()`
- Sets uniforms conditionally: `gl.uniform1i(u_frustum_culling, 1)` + 4× `gl.uniform3f`
- Falls back to `u_frustum_culling = 0` when no planes provided
