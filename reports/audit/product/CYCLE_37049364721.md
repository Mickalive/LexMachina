## Changes Under Audit

### 1. `product/app/map_loader.py` — Graceful Degradation for `true_hierarchical_leiden`

**Location**: `_load_true_hierarchical_leiden()` method, lines 781–784 (producer workspace)

```python
# Graceful degradation: skip this representation if igraph/leidenalg unavailable
if hierarchical_labels is None or coarse_labels is None:
    print("INFO: true_hierarchical_leiden skipped — igraph/leidenalg not available")
    return
```

**Root Cause**: The `_run_hierarchical_leiden()` helper returns `(None, None, {})` when `igraph`/`leidenalg` imports fail (line 926). The caller previously proceeded to subscript `hierarchical_labels` (line 787), causing `TypeError: 'NoneType' object is not subscriptable`.

**Fix Assessment**: ✅ **Correct and Minimal**
- Guard placed immediately after the call site, before any subscript operations
- Clear INFO message distinguishes intentional skip from unexpected failure
- Returns early without adding the representation to `self.maps`
- All other representations load normally (38 representations loaded in test)
