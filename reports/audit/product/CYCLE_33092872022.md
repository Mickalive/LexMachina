## Critical Issues Requiring Fix (Required Fixes)

### 1. **Startup Performance — True Hierarchical Leiden Computed at Load**
- **Location:** `MapLoader._load_true_hierarchical_leiden()` (lines 512-734)
- **Issue:** Runs full hierarchical Leiden (igraph + leidenalg) on 1000×768 embeddings at every server start. Test suite takes **~89 seconds**.
- **Impact:** Unacceptable for production restarts; blocks horizontal scaling.
- **Fix:** Precompute and persist true_hierarchical_leiden artifacts (labels, metadata) to disk in fractal-map lane; load from disk in product.

### 2. **Startup Performance — Debiased Citation Blended Computed at Load**
- **Location:** `MapLoader._load_debiased_citation_blended()` (lines 842-1062)
- **Issue:** Runs PCA, NetworkX random walks (5×20 steps), SVD, and blending on 1000 decisions at every start.
- **Impact:** Adds ~10-15s to startup; same precompute concern.
- **Fix:** Precompute debiased_citation_blended embeddings and 2D projection in evaluation/fractal-map lane; persist to disk.

### 3. **Missing Dependencies in requirements.txt**
- **Current:** numpy, networkx, scikit-learn, scipy, python-igraph, leidenalg
- **Missing:** `python-igraph` and `leidenalg` were missing until cycle 33044908711 fix (now added). **OK now.**
- **But:** The true_hierarchical_leiden and debiased_citation_blended computations require these at **runtime**, not just test time. Document as hard runtime deps.

### 4. **Test Count Discrepancy**
- **Product state:** "total_tests: 91, tests_passed: 91"

- **Fix:** Update metrics_summary in product.json

### 5. **Coarse Purity Mismatch in product.json**

## Non-Blocking Concerns (Advisory)

### A. "14/14 Benchmarks PASS" — External Dependency
The default representation (`debiased_citation_blended`) claims 14/14 benchmark PASS but this validation is not reproducible from mounted artifacts. Recommendation: either (a) persist the benchmark results alongside the representation, or (b) run a lightweight validation at load time and log results.

### B. Language Purity Dominance in Baseline
Baseline and aligned representations show **language_purity > 0.96** at all resolutions (up to 1.0). This indicates clustering primarily by language, not legal substance. The concat_center_tfidf and debiased_citation_blended representations reduce this (language_purity ~0.62-0.76 at coarse, ~0.96-0.99 at fine). The evaluation loader correctly flags this via `language_dominance_warnings`.

### C. Section Mode Coverage Limited
Only 63/1000 decisions have true section-specific projections. The blended fallback works but the "section mode" UX implication (that zoom shows section-level structure) is partially fictional for 93.7% of decisions. Document clearly in UI.

### D. No Persistence for User Imports
User-imported corpus survives only in memory (written to JSONL but map positions not computed). Server restart loses imported decisions' map positions. Known limitation listed in product.json.

### E. HTML5 Canvas Only — No WebGL
Frontend uses 2D Canvas. Acceptable for 1000 points; will not scale to TF-2000+ (100k+). Documented as known limitation.

## Architecture Review

### Strengths
- **Clean separation:** CorpusLoader, MapLoader, NavigationAPI, SectionModeLoader, CitationLoader — each single-responsibility.
- **Multi-representation support:** 6 map representations (baseline, concat_center_tfidf, hdbscan, hierarchical_leiden, true_hierarchical_leiden, debiased_citation_blended) + 6 section modes.
- **Evaluation integration:** EvaluationLoader surfaces benchmarks, zoom coherence, boilerplate resistance to API.
- **Frontend richness:** Temporal slider, language filter, zoom breadcrumb, imported corpus markers, evaluation badge, proximity explanation, cross-language neighbors, TF-IDF similarity — all wired to API.
- **Reproducible evidence:** All core claims trace to frozen fractal-map/evaluation artifacts.

### Structural Debt
- **MapLoader does too much:** Loads 6 representations, computes 2 at runtime (true_hierarchical_leiden, debiased_citation_blended), mixes loading logic with computation. Should be: load-only in product; compute in upstream lanes.
- **NavigationAPI is a God object:** 924 lines, 40+ methods, handles corpus, map, sections, citations, proximity, zoom coherence, language analysis, TF-IDF, temporal, import. Consider splitting.
- **Global singletons:** `_nav_api`, `_eval_loader` module globals — fine for single-process dev server; not for production.
- **No caching layer:** Cluster coherence, zoom coherence, language analysis computed on-demand per request.
