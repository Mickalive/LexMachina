### 2.2 Clickable Map Generation

The map component (`product/query/qmap.py`) produces:
- **2D coordinates** (`x`, `y` ∈ [-1, 1]) via TruncatedSVD on query-conditioned TF-IDF
- **Cluster assignments** (`cluster_id`) via KMeans with deterministic `random_state=42`
- **Cluster labels** from top TF-IDF terms per cluster
- **Relations** via shared citation detection (Swiss citation patterns: `BGE \d+ [IVX]+ \d+`, `ATF \d+ [IVX]+ \d+`)
- **Outlier flags** (`is_outlier`) for top 10% by distance to cluster centroid

All geometry is deterministic in one numeric stack (NumPy/scikit-learn with fixed seeds).
