### Critical Evidence Gaps

#### 1. Clustering Purity = 0.0 at All Levels
From `cited_outcome_hybrid_0.5_174k/metadata.json`:
```json
"clustering_results": {
  "n_coarse_clusters": 31,
  "n_fine_clusters": 85188,
  "coarse_overall_purity": 0.0,
  "fine_overall_purity": 0.0,
  "overall_improvement": 0.0,
  "nesting_score": 1.0
}
```

From `zoom_coherence.json`:
```json
"summary": {
  "total_improvements": 0,
  "total_deteriorations": 0,
  "total_no_change": 85188,
  "improvement_rate": 0.0
}
```

**Interpretation**: The hierarchical clustering produces **zero legal-area purity** at every resolution. The "nesting_score: 1.0" is a structural property (perfect parent-child containment by construction), not a quality metric. The clustering fails to separate decisions by legal topic.

#### 2. Placeholder Decision IDs
The `metadata.json` lists 175,440 decision IDs, all of format `bger_placeholder_XXXXX`. These are synthetic placeholders, not real Swiss Federal Supreme Court decisions. The actual local metadata subset (`metadata_174k_full.json`) contains only 21,228 real decisions.

#### 3. Scale Leakage
The JP=0.799 and LangDom=0.491 metrics come from the **1,000-decision evaluation** (v15b-audit, frozen harness v3, seed=42). The 174k representation has **never been evaluated** on jurist pairwise preference or language dominance benchmarks. Presenting 1k metrics as 174k metrics is benchmark gaming.

#### 4. No 174k Evaluation Artifacts Exist
The evaluation directory contains results for the 1k representation. No `evaluation_results.json` or equivalent exists for `cited_outcome_hybrid_0.5_174k`. The product integration report (CYCLE_174k_TFIDF_PRODUCT_INTEGRATION.md) explicitly states: "Run evaluation suite on 174k TF-IDF representations (citation_heritage, adversarial, multilingual, etc.)" under **Pending Work**.
