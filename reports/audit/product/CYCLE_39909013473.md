## Defects Found

### D1: `language` field is `null` for 5 decisions (not a string)
- **Location**: `bundle_summary` shows `"languages": {"null": 5, ...}`
- **Impact**: UI language filter "Toutes langues" includes them; `langFilter` select only has de/fr/it — these 5 become unfilterable.
- **Severity**: Low (data quality, not contract violation). `REQUIRED_DECISION` requires `language` key present (it is), but not non-null.
- **Repairable in same cycle**: Yes — default to `"und"` or `"?"` in `_candidate_to_product`.

### D2: `canonical_url` uses `mcp.opencaselaw.ch` (MCP proxy) not raw OpenCaseLaw
- **Observation**: URLs point to `https://mcp.opencaselaw.ch/entscheid/...` which is the MCP gateway, not `https://entscheide.opencaselaw.ch/...`
- **Impact**: Still a valid, resolvable source link; user reaches the decision.
- **Severity**: Informational. Not a defect — the MCP proxy is the intended product access layer.

### D3: Fixture answer prose is not a real legal answer
- **Observation**: `"Fixture grounded answer [sz_gerichte_ZK1_2023_26] [bge_BGE_118_II_50]"`
- **Impact**: In fixture mode, the answer is a synthetic placeholder. This is **by design** — `fixture_generation=True` uses `fixture://generative-audit` provider.
- **Severity**: Not a defect — honestly labelled.
