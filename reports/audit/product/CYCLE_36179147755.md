## Adversarial Review

### 1. Regression / Data Loss
**CRITICAL FINDING:** The 174k-scale `cited_outcome_hybrid_0.5` artifacts (built in previous cycle) were **deleted** and replaced with 7k-scale artifacts. This is a regression in the primary production deliverable.

- Previous cycle metadata: `n_decisions: 173963`, decision_ids included real IDs like `bger_4P.253_1999`
- Current cycle metadata: `n_decisions: 6988`, decision_ids from `bge_20*.jsonl` corpus only
- Root cause: Producer workspace only has `bge_20*.jsonl` files (6,988 decisions), not the `bger_20*.jsonl` files needed for 174k corpus
- The `/tmp/lex_accepted` mount referenced in build scripts **does not exist** in the producer workspace

### 2. Test Expectation Mismatch
The test `test_cited_outcome_hybrid_0_5` was written in the previous cycle expecting 174k artifacts. It was **not updated** when the artifacts were downscaled. This is a concrete, same-cycle repairable defect.

- The 1k slice (`bger_2000plus_slice_1000.jsonl`) is only used for map decision lookups
- No training on test data detected
