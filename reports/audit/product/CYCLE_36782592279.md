**Prior defect**: The flat hierarchical format (used by cited_decisions_tfidf_174k) has:
- Coarse clusters under `"coarse_X"` keys with `"is_coarse": true`
- Fine clusters under numeric keys with `"coarse_parent"` field

**Old code**: Only built 2 zoom levels (coarse + fine) from cluster_metadata, ignoring 5 resolution label files.

**New code (verified)**: Iterates `resolution_to_zoom` mapping, loads labels for each resolution, builds cluster assignments and groupings in **single O(n) pass**, extracts metadata from coarse_X (zoom 0) and finest res (zoom 6), computes centroids from positions.

**Impact**: cited_decisions_tfidf_174k now serves all 7 zoom levels (0-6) instead of 2, matching the 7-resolution hierarchical Leiden clustering that was computed.
