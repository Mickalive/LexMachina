## Adversarial Audit: Attacks on Claims

### Attack 1: Benchmark Gaming / Prettiness-as-Quality
**Finding**: NO EVIDENCE of benchmark gaming.
- Evaluation loader reads from `unified_evaluation/unified_results.json` which contains 10 older representations (best: `concat_center_tfidf` ratio=0.5113). The newer representations (`center_projected_64dim_hierarchical`, `legal_cited_decisions`, etc.) are NOT in this evaluation dataset - this is honestly a data freshness gap, not gaming.
- The state file explicitly documents: "Hybrid and legal_issues_outcomes representations are EXPLORATORY (not yet benchmarked)"
- Negative result (768-dim FAILS jurist pairwise) is prominently documented in metadata, state file, and server.py comments

### Attack 2: Leakage / Data Contamination
**Finding**: NO EVIDENCE of leakage.
- Corpus (1,202 decisions) and map (1,000 positions) are properly separated
- `has_corpus` flag on map positions provides transparency (1,000 map positions, 100% coverage of slice)
- User imports are tracked separately with `is_imported` flag
- Cross-validation folds not applicable (unsupervised clustering)

### Attack 3: Weak Baselines
**Finding**: Baselines are appropriate and documented.
- `baseline` representation = UMAP + Leiden (explicitly labeled)
- `concat_center_tfidf` = prior best from fractal-map evaluation
- `debiased_citation_blended` = evaluation lane's recommended default (14/14 PASS)
- Adversarial benchmarks (language dominance, jurist pairwise) are the PRIMARY gates, not cluster purity

### Attack 4: Unsupported Product Claims
**Finding**: All claims are evidence-backed.
- "DEFAULT map mode" → actually loaded, tested, documented in metadata
- "14/14 benchmarks PASS" → `legal_cited_decisions` metadata cites ACCEPTED tier from legal-distance lane
- "Nesting=1.0" → `true_hierarchical_leiden` test asserts `nesting_rate == 1.0`
- "Only representation passing BOTH adversarial benchmarks" → metadata shows `both_adversarial_gates_pass: True` ONLY for `center_projected_64dim_hierarchical` and `center_projected` (768-dim)
- "WebGL supports 100k+ points" → implementation exists, not yet stress-tested at scale (honestly noted as future work)

### Attack 5: Boilerplate Confounding
**Finding**: Actively mitigated and measured.
- `section_experiment_clean` / `section_scaled` explicitly exclude boilerplate sections
- `sachverhalt_erwaegungen_dispositiv` mode = "Core legal content (excludes boilerplate)"
- Boilerplate resistance metric computed in evaluation loader (legal_purity in language-homogeneous clusters)
- Language dominance warnings flagged for representations with >0.99 language purity

## Known Limitations (Honestly Documented in State File)

1. **Section modes**: 63 decisions use section-specific projections, 937 use baseline fallback (blended approach)
2. **HDBSCAN**: Produces fewer clusters than Leiden at same zoom levels (2-8 vs 5-21)
3. **TF-IDF model**: Uses truncated text (2000 chars max per document)
4. **Cross-language neighbors**: Limited by language-dominant clustering
5. **Language filter**: Simple toggle (no compound language queries)
6. **Temporal filtering**: Requires year metadata (not all decisions have it)
7. **Full TF-2000+ corpus scale**: Pending corpus lane completion (~192k decisions)
8. **Hybrid/legal_issues_outcomes**: EXPLORATORY (not yet benchmarked)
9. **Proximity explainer caching**: Not fully implemented (cache miss on second call) - TO BE FIXED
