### Structural Issues

1. **Scale regression without test updates**: Maps reduced 86% in decisions; tests still expect 6,988. No commit updated test expectations.

2. **State-file hallucination**: `state/product.json` claims PASS, 7,990 corpus decisions mapped, audit_ready=true. None are true.

3. **174k ID mismatch persists**: Cluster metadata uses `decision_indices` (integers) but the new map_loader code expects `decision_ids` (strings like `bger_...`). The 174k metadata has `decision_ids` arrays filled with `placeholder_*` strings. The fallback to `decision_indices` uses `all_decision_ids[i]` but `all_decision_ids` comes from the same placeholder-filled metadata. Result: 0 real decisions mapped.

4. **All maps collapsed to 1k slice**: The `cited_decisions_tfidf`, `hybrid_cited_decisions_*`, `linear_hybrid05_concat`, etc. — all 31 representations now show exactly 1,000 decisions. The 7k-scale bge_20* corpus is loaded by CorpusLoader but discarded by map construction.

5. **Recurring pathology**: This is the **third scale oscillation** in recent cycles:
   - Cycle 36171674988: Claimed 174k (was synthetic)
   - Cycle 36187035440 repair 1: Corrected to 7k (6,988 decisions) — **HONEST**
   - Cycle 36216349510: Regressed to 1k (1,000 decisions) — **REGRESSION**
