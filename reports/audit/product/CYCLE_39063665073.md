## 7. Findings

### F1 (material, product) — the new discovery ring overpaints the accepted "evidenced counter-authority" contour

`draw()` builds **one** path per point (`ctx.arc(s.x, s.y, cited?7:5)`) and strokes it up to four times. The new branch is
stroked **last, at the identical radius, with a thinner line**:

```js
if(counterEvidenced(p)){ctx.lineWidth=2.5;ctx.strokeStyle="#b72736";ctx.stroke()}
…
if(isAdversarial(p)){ctx.lineWidth=1.6;ctx.strokeStyle=ADV_RING;ctx.stroke()}
```

`canvas_probe.js` records only `(strokeStyle, dash)` per `stroke()` — not radius, not `lineWidth`. The auditor therefore
built an independent geometry probe recording `(x, y, r, strokeStyle, lineWidth)` at every stroke. Measured:

| bundle | evidenced red rings | of which **under** the cyan ring (same centre, same r) |
|---|---|---|
| fr-bail-entretien | 11 | **11 (100 %)** |
| de-kapitalverletzung | 24 | **15 (62.5 %)** |
| it-responsabilita-medica | 14 | **11 (79 %)** |
| LIVE_V2 / LIVE_V3 | 2 | 0 |

Sample measured stack (fr, identical `x=450 y=294.2088 r=5`): `{style:"#b72736", width:2.5}` then `{style:"#00b3c8", width:1.6}`.

A 1.6 px cyan stroke centred on a 2.5 px red stroke leaves ~0.45 px of red at each edge: on the fr bundle **every**
evidence-backed counter-authority contour is visually replaced by the discovery colour. The accepted v55 render contract —
whose legend entry reads *"contour rouge = contre-autorité étayée"*, whose numbers are pinned in
`product/tests/test_canvas_ring_strokes.py`, and which exists precisely because cycle 38885055655 *"silently removed 16 of 16
amber contours … while the frozen suite stayed green — the exact defect surface"* (`canvas_probe.js` header) — is **counted
as unmoved while its painted pixels are not**. The report discloses the one-directional guarantee it did implement ("drawn
last, so a row that is BOTH discovered and qualified never hides its discovery mark behind the counter/citation ring") and is
silent on the reverse. This is not an aesthetic demand: it is an additive, provenance-only marker degrading an
evidence-bearing visual contract that comes from the frozen counter-anchor reviewer — the one qualification the product
refuses to fabricate. Not CI-breaking (no CI job runs this module), but it is a real product defect on the shortest
user-visible surface, and it is fixable in this cycle.
