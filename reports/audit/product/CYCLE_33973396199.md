### 2.2 Structural Root Cause

1. Test data files (`user_corpus.jsonl`, `imported_positions.jsonl`) are NOT in `.gitignore`
2. Tests regenerate these files at runtime (test_corpus_import creates synthetic data)
3. The producer creates a commit that deletes them → next cycle recreates them → next cycle deletes them → infinite loop
4. `.gitignore` only ignores `__pycache__/` — these test artifacts are not ignored

The producer itself has documented this exact problem **multiple times** in repair_refs and verify reports. The recommended fix is trivial: add `user_imports/` to `.gitignore`. But this has never been applied, leading to the recurring cycle.
