## 4. Attack Surface Analysis

### 4.1 Data Leakage / Contamination
- **Frozen sample:** 1000 BGer decisions (2020-2024) used consistently — no leakage detected
- **Embeddings:** center_projected derived from multilingual_e5_small with PCA-1 projection — no label information used
- **Clustering:** Unsupervised Leiden — no legal labels used in clustering
- **Benchmarks:** Adversarial benchmarks (language dominance, jurist pairwise) computed independently — no circularity

### 4.2 Metric Gaming
- **Nesting = 1.0** is guaranteed by hierarchical construction (child clusters are strict subsets of parents). This is a **structural property**, not a learned metric. The success rule "Nesting = 1.0 AND purity >= concat baseline" is meaningful because purity is the independent variable.
- **Zoom coherence** computed as fraction of parent clusters where mean child purity > parent purity. This is a valid coherence metric.
- **Adversarial language dominance** (0.7593) and **jurist pairwise** (0.5215) are external validations not optimizable via clustering parameters.

### 4.3 Weak Baselines
- Concat baseline (0.9491 purity) is a legitimate strong baseline — it uses the same hierarchical Leiden method on enriched embeddings (center_projected + TF-IDF).
- Legal-distance modes provide 5 alternative baselines with different legal signal compositions.
- No trivial/random baselines presented as comparisons.

### 4.4 Boilerplate Confounding
- Legal-distance modes explicitly test boilerplate resistance (legal_cited_decisions_only, debiased_citation_blended both PASS adversarial_falsification).
- Center_projected uses pure embeddings with language component removed — inherently resistant to language boilerplate.

### 4.5 Scale Limitations
- **Validated on 1000 decisions only** (2020-2024 slice). Full corpus (2000-2024, ~192k decisions) not yet tested.
- State file documents this dependency: "Current validation on 1000 decisions; full 2000-2024 corpus scaling needed per corpus lane"
- This is a **known limitation**, not a defect — the lane correctly identifies scaling as a corpus-lane dependency.
