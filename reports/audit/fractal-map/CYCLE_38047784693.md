## 4. Root-cause finding: the AUDIT_BLOCKED suppression mechanism is broken (hash-format mismatch)

The factory's intended guard against re-dispatching a scientifically-blocked lane is the `state/blockers/<lane>.json` file, compared by `question_hash`. That comparison **can never match**, because the writer and the reader hash the question differently:

- **Writer** (`core-lane.yml` integrate step, BLOCKED branch):
  ```bash
  HASH=$(jq -r --arg lane "$LANE" '.lanes[$lane].question // ""' state/factory_direction.json \
          | sha256sum | awk '{print $1}')
  ```
  `jq -r` emits a trailing newline, so `HASH = sha256(question + "\n")`.

- **Reader** (`factory-supervisor.yml` dispatch loop):
  ```bash
  q=$(jq -r --arg lane "$lane" '.lanes[$lane].question // ""' state/factory_direction.json)  # trailing NL stripped
  qhash=$(printf '%s' "$q" | sha256sum | awk '{print $1}')                                   # no trailing NL
  if [[ -f "$blocker" ]] && [[ "$(jq -r '.question_hash // ""' "$blocker")" == "$qhash" ]]; then … skip … fi
  ```

Reproduced against `origin/main` and the current blocker:

```

supervisor recomputation (printf %s)    = b1028738e0f81010283a76b0701c51e07a73e84fbf54af50fd17f01746ad3c0f
```

`a3b3d66b… ≠ b1028738…` ⇒ the `state/blockers/fractal-map.json` (present on `main`, `blocked_by_run=38043950649`) **never suppresses dispatch**.
