## 5. Code & Implementation Review

### 5.1 Constrained Hierarchical Leiden (`test_constrained_hierarchical_leiden_174k.py`)
- **Correctness:** Two-level Leiden (coarse → adaptive fine within each coarse cluster) guarantees nesting=1.0 by construction
- **Adaptive sub-resolution:** Heuristic `sub_res = base * (20 / target_subclusters)^0.5` clamped to [1.0, 5.0] — reasonable and effective
- **Min cluster size enforcement:** Post-process merges tiny sub-clusters into nearest valid cluster by centroid distance
- **Remainder handling:** Clusters < min_cluster_size at coarse level become single "remainder" fine clusters
- **Evaluation semantics:** Matches v26 evaluator (ID-space zoom coherence, MIN_CLUSTER_SIZE=3 for parent/child validity)

### 5.2 v26 Evaluator (`zoom_quality_174k_all_modes_v26.py`)
- **Independent implementation:** Own purity/zoom/nesting code, recomputes from raw artifacts
- **Freeze-before-compute:** Spec written and hashed before measurement
- **Crosscheck mode:** Validates against v25 raw artifacts before v26 write (exact purity match, claim-level zoom equivalence)
- **Strict nesting from labels:** Recomputed independently from build-time `zoom_mappings.json`
