## 4. Attack Surface Analysis

### 4.1 Singleton Purity Inflation (MAJOR FINDING)

**Experimental Best Config (coarse_0.25_fine_3.0, 77 clusters):**

Coarse cluster 3 (size 42, dominant branch: zivilrecht, purity 1.0) splits into 34 sub-clusters:
- **28 singletons (size 1)** — purity = 1.0 by definition
- 3 clusters of size 3
- 2 clusters of size 2
- 1 cluster of size 1

**Impact:** 28/34 = 82% of sub-clusters in this coarse cluster are singletons. Since singletons have trivial purity 1.0, the hierarchical purity of 0.9561 is significantly inflated.

**Product Config (coarse_0.5_fine_3.0, 98 clusters):**
- Fewer singletons overall (coarse resolution 0.5 creates 8 more balanced coarse clusters)
- Coarse cluster 7 (analogous to above): 9 sub-clusters, only 1 singleton
- Still some singletons present (e.g., clusters 52, 66, 81, 87, 97 in full list)

**Assessment:** This is a **known limitation of high-resolution Leiden**, not a defect. The report honestly discloses:
> "Experimental best config (77 clusters) differs from persisted product config (98 clusters)"
> Negative result #7 in snapshot report.

The product config (98 clusters, purity 0.949) is more robust and correctly persisted for production use.
