## 6. Attack: Test Infrastructure Defect (SYSTEMIC, PRE-EXISTING)

**Critical finding:** All 31 tests in `test_cycle_v14.py` use a custom `_record()` function instead of `assert`. The `_record()` function logs PASS/FAIL but does **not raise an exception**. This means:

1. **Pytest always reports PASSED** for these tests regardless of internal assertion status
2. The "31/31 PASS" claim is **unfalsifiable** — the tests cannot actually fail
3. `test_canonical_dir_has_year_split_files` records FAIL when 0 `bger_*.jsonl` files exist, but pytest still reports PASSED

**Verification:** Running the test with 0 matching year files produces `[FAIL] test — found 0` in output but pytest reports `1 passed`.

**This is NOT a regression from this cycle.** The same `_record()` pattern has been used in every prior cycle. It is a systemic test-infrastructure defect requiring Factory Director intervention to replace with proper assertions.

**Impact on data integrity:** None. The actual data/artifact consistency is verified independently (section 2). The test suite is a convenience layer, not the sole source of truth.

## 7. Attack: Manifest Filename Mismatch (KNOWN, EXPECTED)

**Finding:** The manifest references `bger_YYYY.jsonl` filenames, but files on the audit-workspace disk are named `bge_YYYY.jsonl`. The `bger_*.jsonl` files are **gitignored** and absent in any workspace where `reproduce_full_corpus.py` has not been run.

**Root cause:** The `.gitignore` excludes `bger_[0-9][0-9][0-9][0-9].jsonl`. The reproduce script generates these files. In a fresh workspace without running reproduce, the year-split data files are absent.

**This is the same known pathology documented in 6+ prior cycles.** The producer correctly documents this in state notes and the verification report. The reproduce script with verifiable manifest is the canonical solution.

**Impact:** None on data integrity. The artifacts that ARE present (ingestion_metrics.json, manifest, validation_report, citation_graph_resolved.json, state) are all mutually consistent.
