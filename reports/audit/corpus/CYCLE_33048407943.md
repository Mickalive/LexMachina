## Attack Surface Analysis

### 1. Structure Extraction Claim (~89% has_structure)
**Claim in operational resume:** "~89% `has_structure=true`" (line 68)
**Reality:** Structure extraction (`erwaegungen` field populated) only exists in evaluation samples:
- `bger_eval_balanced.jsonl`: 67/73 (91.8%)
- `bger_eval_sample.jsonl`: 89/100 (89.0%)
- `bger_eval_structure.jsonl`: 89/89 (100%)
- `bger_test_structure_citations.jsonl`: 3/5 (60.0%)

**Main corpus has 0% structure:**
- Yearly core (250 decisions): 0/250
- Slice 1000: 0/1000
- Test slice: 0/10

**Assessment:** The claim is **misleading** when applied to "the corpus" generally. It accurately describes evaluation samples only. The cycle report correctly states "Structural fields extraction: ✅ ~89% has_structure=true" but the context makes it appear to apply to the main corpus. This is a **documentation accuracy issue**, not a pipeline defect — the pipeline *can* extract structure when the API provides it (eval samples used `include_structure=true`).

### 2. Statute Extractor Law Count
**Cycle report claim:** "50+ Swiss law abbreviations" (line 68)
**State file claim:** 43 laws mapped
**Actual count:** 43 (in `SWISS_LAW_ABBREVS` dict)
**Assessment:** State file is correct. Cycle report overstated by ~16%. Minor documentation drift.

### 3. Citation Graph Honesty
**State metrics:** `citation_graph_edges: 0`, `citation_graph_nodes_cited: 0`
**State note:** "citation_graph.json contains text-reference 'outgoing' data (2105 refs, 1628 unique targets) but no pipeline code builds resolved decision_id citation graph"
**Reality check:** `citation_graph.json` has `"outgoing"` object with 2,105 text references across 1,628 unique targets. No `"incoming"`, no resolved `decision_id` edges.
**Assessment:** **Honestly reported.** The graph is a text-reference index, not a resolved citation graph. The state correctly zeros the metrics with an explanatory note.

### 4. Parquet Ingestion Honesty
**State metric:** `parquet_validated: false`
**Cycle report:** "Parquet sample was not persisted — The test downloaded to a temp directory for validation. Full ingestion should write to `bger_full_parquet.jsonl`."
**Test behavior:** `test_parquet_download_and_inspect` and `test_parquet_sample_loading` download 785 MB to temp, inspect schema, load 9-10 rows, parse to canonical fields, validate schema — then delete temp files.
**Assessment:** **Honestly reported.** The code path works end-to-end; the artifact is not persisted. `parquet_validated=false` is correct.

### 5. Test Return-Value Pattern
All 23 tests use `return True`/`return False` instead of `assert`. This produces pytest warnings but does not affect pass/fail semantics. The `test_parquet_*` tests return `True` even on network failure (graceful skip). This masks potential CI failures but is documented in the test code.

### 6. Year Distribution Anomaly
`year_distribution_all` shows 2024: 1367, 2026: 10. The 2026 entries come from `bger_test_slice.jsonl` (10 test decisions with 2026 dates). This is test data correctly included in "all" metrics.
