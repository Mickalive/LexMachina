### 2.3 Root Cause Analysis

**The test `test_citation_resolver_graph_resolution` uses a FIXED `citation_graph.json` (250 decisions from 2020)** but the **test corpus `bger_test_2024.jsonl` was replaced with 2024-only decisions**.

When the test runs:
1. `CitationResolver.build_index()` indexes only `bger_test_2024.jsonl` (2024 decisions)
2. `resolve_citation_graph()` processes `citation_graph.json` which contains 2020 docket refs (e.g., `1C_704/2020`, `5D_314/2020`)
3. **No 2020 decisions exist in the test index** → all docket refs resolve to `null`/`unresolved`
4. BGE refs still resolve (BGE index is separate and populated from canonical BGE corpus)

**Evidence from diff:** In `citation_graph_resolved_test.json`, entries like:
```json
// Accepted base (GOOD)
{"target_decision_id": "bger_1C_704_2020", "confidence_score": 1.0, "resolution_method": "exact_docket"}
// Run 38062897700 (BROKEN)
{"target_decision_id": null, "confidence_score": 0.0, "resolution_method": "unresolved"}
```

### 2.4 Why Production Is Unaffected

The **production citation resolver** (`resolved_full/`) uses the **full canonical corpus** (174,113 decisions across 37 year-split files `bger_YYYY.jsonl`), which includes all 2020 decisions. The test regression only occurs in the **isolated test environment** where year-split files are absent and only `bger_test_2024.jsonl` is present.
