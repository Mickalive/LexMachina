## Negative Results / Limitations (Honestly Represented)

1. **API relevance ranking** — Empty queries return most recent first. Representative sampling requires date-range queries. (Documented)
2. **No bulk API endpoint** — 180k decisions = ~3,600 paginated calls @ 5 RPS. (Documented; local Parquet option identified)
3. **Citation parsing** — API returns cited decisions as strings; resolution to canonical IDs needs separate pass. (Documented)
4. **Cantonal decisions** — Current slice is BGer only. Schema supports all courts via `court` enum. (Documented)
5. **Outcome mapping gap** — `partial_approval` and `moot` not mapped. **NEW FINDING** — 60 decisions affected.
