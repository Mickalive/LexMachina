## 4. Frozen predicate and verdict classes

**disclosure_gap_predicate** (substring markers `concept`, `under_covered`, `undercovered`,
`query_concept`): fires iff the qid's own `measured.query_concepts_under_covered` is non-empty
AND `admissible` is true AND no finding/warning code contains a disclosure marker.
`warning_count` / `blocking_count` are published beside it but the predicate is the
finding-code test, because a count can be nonzero for unrelated reasons (an *unrelated* warning
code deliberately does **not** satisfy disclosure — pinned by
`test_unrelated_warning_codes_do_not_satisfy_disclosure`).

| Verdict | Exit |
|---|---|
| `DISCLOSURE_DEFECT_TRANSFERRED` | 1 |
| `DISCLOSURE_DEFECT_NOT_TRANSFERRED` | 0 |
| `NOT_MEASURED` (pin mismatch / vacuous control / environment) | 2 |

**never_a_pass:** a `NOT_MEASURED` run is never reported as `NOT_TRANSFERRED`; an empty
under-covered set is never a disclosure success; an unrelated `warning_count>0` never satisfies
the predicate.
