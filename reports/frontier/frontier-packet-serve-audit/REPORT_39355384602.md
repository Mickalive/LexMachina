## Method

The harness (`frontier_packet_serve_audit`, run as
`python -m frontier_packet_serve_audit.cli --packet <dir> --frozen-rules <dir>`)
reuses the accepted instruments byte-identically (REUSE-FIRST):

- **Label rubric** — the vendored accepted counter-label rubric
  (`vendor_label/`: extract / rubric / normalize / rules / injection), applied
  under the frozen `RULES_LABEL.json` (`4457e971…`), re-hashed before use.
- **Geometry** — a stdlib transliteration of the accepted `geometry_gate.py`,
  reading the frozen `RULES_GEOMETRY.json` (`a7452748…`) bars as written and the
  vendored `textgeo.py` primitives via AST extraction (no numpy).
- **Verdict contract** — the accepted `VERDICT_CONTRACT.json` (`b9cdb894…`)
  predicates, applied as written.

No threshold, bar, rubric or verdict contract is re-derived, re-tuned or
edited. The harness is offline, deterministic (byte-identical reproduction
demonstrated), stdlib-only, and writes only inside the team namespace.
