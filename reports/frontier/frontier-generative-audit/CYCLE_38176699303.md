Hardening highlights (each backed by a regression test):

1. **Citation parsing for live-model styles.** Real free models cite as
   `(CH‑2020‑FR‑001)`, `([CH-2020-FR-001])` and with unicode non-breaking
   hyphens. `extract_citation_ids`/`redact_unknown_citations` now normalize
   hyphens, accept `[ID]`, `(ID)`, `([ID])`, and only treat ID-like tokens
   as citations so `(2019)` and `[1]` in prose survive.
2. **Surfaced-answer redaction.** Unknown ID-like citations are not only
   rejected from `cited_decision_ids` but replaced in the prose with
   `[citation removed: not in retrieved set]`.
3. **Cited-but-contrary visibility.** A decision that is cited *and*
   limited/contrary keeps `candidate-limiting`/`candidate-contrary` instead
   of `cited`, because the product UI hides only `none`/`cited`
   (counter-authorities must stay discoverable).
4. **Provider fallback correctness** + recorded per-model attempts; total
   failure returns a structured failure instead of silence.
5. **Adversarial robustness:** unknown finding IDs rejected and recorded;
   one strict-format retry when a live model answers in prose; negative
   results preserved verbatim (`adversarial_info.raw_excerpt`).
6. **Injectable runners/attestors** so every live path is testable offline.
