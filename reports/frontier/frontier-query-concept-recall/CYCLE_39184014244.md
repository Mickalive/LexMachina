**The emitted patch is executed against a portfolio COPY in the test suite and

`frontier-team.yml:58` selector match **0**, preserve `.version`/`.teams`, and
leave the other 11 entries byte-identical, and survive apostrophes in the run

(21 tests):

1. `(.teams[] | select(...)) | (.status = …)` **replaced the whole document** with
   the matched team object, destroying `.version` and `.teams` — jq streams the
   selection. Fixed with an in-place `|= map(if … then … else . end)`.
2. `\"` inside a shell single-quoted jq program reaches jq literally and fails to
   compile. The closure note now carries no double quotes.
3. The proposed `run_history` was inlined as `--argjson hist '...'`. It is prose
   lifted from the team state and contains an apostrophe (*"the director's
   portfolio write"*), which terminated the shell's single-quoted string — the
   command failed with an unexpected EOF. The history now ships as its own JSON
   file and is read with `--slurpfile`, so no data passes through shell quoting;
   `build()` raises rather than emitting a program containing a single quote.

It also corrected an over-broad claim of mine: `cycle_status` **is** present in
`frontier-team.yml` (line 137). The diagnosis is now computed from the
