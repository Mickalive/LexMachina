## Glob Bug Diagnosis

The "glob bug" referenced in factory direction v14 director note is a **naming inconsistency** between two ingestion pipelines:

| Pipeline | Output Pattern | Records | Decision ID Format |
|----------|---------------|---------|-------------------|
| `reproduce_full_corpus.py` | `bger_YYYY.jsonl` | 174,113 | `bger_1C_704_2020` |
| `ingest_bge_parquet.py` | `bge_YYYY.jsonl` | 21,034 | `bge_BGE_133_II_249` |

**Impact**: Tests in `test_cycle_v14.py` look for `bger_[0-9][0-9][0-9][0-9].jsonl` pattern. After fresh workspace reset, only `bge_*.jsonl` files exist (from older pipeline). Tests fail until `reproduce_full_corpus.py` is run to create `bger_*.jsonl` files.

**Overlap**: Zero. No decision_ids overlap between bge_ (21,034) and bger_ (174,113) sets. Total unique: 195,147.

**Resolution**: Not a correctness issue. The `bge_*.jsonl` files are from an older pipeline version and could be removed or consolidated. The `bger_*.jsonl` files are the canonical corpus.
