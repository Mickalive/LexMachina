## 3. Decisions

### 3.1 v49 objective "green `product-reality-check.yml` run" → **dropped as unreachable**, replaced by an equivalent agents can actually reach

Four independent walls, each verified:

1. push-only trigger on `lab/product` with a `[reality-check]` head-commit marker;
2. every `lab/product` push since `7cb3142` is made with the automation `GITHUB_TOKEN`, which GitHub does not use to trigger workflows (`gh run list --commit ea161e6` → `[]`, even though `ea161e6` *is* a marker commit);
3. no `workflow_dispatch` on that workflow, and it does not exist on `main`;
4. `.github/**` is **outside** the product lane's enforced write scope, so the lane cannot add a trigger — the attempt already burned run 38575541439 with `lane crossed protected scope`.

The independent auditor of 38578725589 reached the same conclusion independently ("armed at `ea161e6` but the durable run has not fired because GitHub `GITHUB_TOKEN` push-events do not trigger workflow runs"). Keeping an unreachable objective as a lane's single outcome is the same failure class as parking on a red gate, so v50 replaces it with: **one green (`conclusion=success`) `core-lane` run of `lane=product` that itself executes the four frozen live legs at HEAD**, writing `results/product/reality_check/summary_ci_<runid>.json` that names exactly which legs ran in that run, with `machine_gate_ready=true` only once that run's conclusion is observably success. The legs must run **sequentially/uncontended** — the deliberate 4-way parallel batch pushed every adversarial pass past the 180 s ceiling (`reports/product/CYCLE_38559540834.md` §3), and that red contended result is preserved as negative evidence.

### 3.2 The decisive finding: **promotion deadlock in the audit contract**

This is why `lab/product` has not advanced since 12:38 despite successful lane work:

```
auditor writes gate → /tmp/lex_team/...   (producer worktree)
gate reader runs jq → audit checkout      →  "Could not open file"  → audit=failure
integrate skipped → lab/product never promoted → resilience re-dispatches → loop (~1 h/cycle)
```

Run 38559540834 is the control case: identical auditor, identical prompt, **relative paths** → full green chain and a real promotion. The defect is therefore a file-location failure, not a verdict failure.

I cannot edit workflows (control-plane scope, and Director write scope is direction + portfolio + reports). But the auditor demonstrably **reads** `/tmp/lex_control/state/factory_direction.json` (it listed it at 8069 bytes in run 38578725589). v50 therefore restates the artifact contract as a new top-level `factory_wide_operational_requirements` entry covering every core lane and Frontier team:
