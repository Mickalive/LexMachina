### RF-2 — `recall::retrieval_controlling_authority` measurability restated

Evaluation deliverable (c) said "Product must ship a full bundle per question for those to be measurable at all" — contradicting requirement (21)'s own final sentence that geometry/progressive gates are permanently not_measurable for a single bundle.

- **Mechanism:** `gates.py:224-230` returns the vacuous True branch when `required_retrieval_ids` is empty, BEFORE the `available` check.
- **Full bundles (7, all `question_independent_only`):** `passed=None` on all 7 (`gates.py:390-391`). The gate has NEVER been genuinely measured on any artifact in record 38934722443.
- **Geometry/progressive gates:** `gates.py:303-306` emit not_measurable "needs initial+final pair; single recorded bundle" on every bundle path. One bundle per question never makes them measurable.

**Fix applied.** Requirement (21) clause (b) restated with measured facts.
