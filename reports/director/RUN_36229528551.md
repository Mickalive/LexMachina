## Fix 3: FIX_ORCHESTRATION_DISPATCH

### Issue
Supervisor reads ephemeral `state/factory_direction.json` (fractal-map.status=RUN) instead of persistent `state/fractal_map.json` on lab branch (cycle_status=BLOCKED_ON_DEPENDENCY) — 60+ documented re-dispatch occurrences.

### Root Cause
In factory-supervisor.yml, the dispatch loop (lines 155-206) checked `factory_direction.json` for lane status, then only fetched lab branch state **after** deciding to dispatch (line 176-183), and only for `continue_recommended` check — not for `cycle_status`.

### Fix Applied
Modified factory-supervisor.yml: Added early fetch of lane state from lab branch **before** dispatch decision (new lines 163-184 in the edited file). Logic:
1. Fetch `state/<lane>.json` from `lab/<lane>` branch
2. If `direction_version` matches current DIRV AND `cycle_status` != "RUN":
   - Honor lane state; do NOT dispatch
   - Log blocked dependency if `cycle_status == "BLOCKED_ON_DEPENDENCY"`
3. Only proceed to dispatch if lane state confirms RUN or is unavailable

### Code Change
```bash
# NEW: Fetch lane state BEFORE dispatch decision
lane_state_raw=""
lane_cycle_status=""
if git ls-remote --exit-code --heads origin "refs/heads/lab/$lane" >/dev/null 2>&1; then
  lane_state_raw=$(gh api "repos/${GITHUB_REPOSITORY}/contents/state/${lane}.json?ref=lab/${lane}" --jq '.content' 2>/dev/null | tr -d '\n' | base64 -d 2>/dev/null || true)
  if [[ -n "$lane_state_raw" ]]; then
    lane_cycle_status=$(jq -r '.cycle_status // "UNKNOWN"' <<<"$lane_state_raw")
    lane_dir_version=$(jq -r '.direction_version // -1' <<<"$lane_state_raw")
    if [[ "$lane_dir_version" == "$DIRV" ]] && [[ "$lane_cycle_status" != "RUN" ]]; then
      echo "$lane: factory_direction says RUN but lab/$lane state/$lane.json cycle_status=$lane_cycle_status (direction_version=$lane_dir_version). Honoring lane state; NOT dispatching."
      if [[ "$lane_cycle_status" == "BLOCKED_ON_DEPENDENCY" ]]; then
        blocked_on=$(jq -r '.blocked_on // "unknown"' <<<"$lane_state_raw")
        echo "$lane: blocked on $blocked_on"
      fi
      continue
    fi
  fi
fi
```

### Expected Result
- Fractal-map lane (BLOCKED_ON_DEPENDENCY on legal-distance_174k_dense_embeddings) will no longer be re-dispatched
- Supervisor will log: "fractal-map: factory_direction says RUN but lab/fractal-map state/fractal-map.json cycle_status=BLOCKED_ON_DEPENDENCY (direction_version=27). Honoring lane state; NOT dispatching. fractal-map: blocked on legal-distance_174k_dense_embeddings"
- Eliminates the 60+ re-dispatch pathology
